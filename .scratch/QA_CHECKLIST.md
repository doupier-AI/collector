# Collector QA 测试用例清单

> 基于 PRD 2.0 验收场景 A–E，覆盖完整闭环。

## 前置条件

- [ ] 桌面应用已启动（`Ctrl+Shift+Space` 呼出悬浮窗）
- [ ] 浏览器扩展已加载（Chromium，右键菜单可用）
- [ ] API 服务运行在 `localhost:PORT`
- [ ] DeepSeek Key 已配置（设置页面）

---

## 场景 A：连续自由收集

### A1 – 网页右键采集
- [ ] 在任意网页选中一段文字，右键 → "收集到知识库"
- [ ] 采集成功后出现轻量通知（非弹窗确认框）
- [ ] 打开"全部材料"，确认该条内容存在，包含原文、URL、标题
- [ ] 检查采集来源信息（证据等级、时间戳）

### A2 – 无选区时采集整页
- [ ] 在网页不选中任何文字，右键 → 采集当前网页
- [ ] 材料库中出现该条目，标记为整页采集

### A3 – 悬浮窗粘贴文本
- [ ] `Ctrl+Shift+Space` 唤起悬浮窗
- [ ] 粘贴一段纯文本，`Ctrl+Enter` 提交
- [ ] 悬浮窗清空并自动隐藏
- [ ] 材料库中可见该条内容，证据等级为 D

### A4 – 悬浮窗粘贴 URL
- [ ] 粘贴一个公开文章 URL，提交
- [ ] 材料库中出现该条目

### A5 – 悬浮窗拖放文件
- [ ] 拖放一个 `.txt` 或 `.md` 文件到悬浮窗
- [ ] 提交后材料库中可见该文件内容

### A6 – Esc 保留草稿
- [ ] 在悬浮窗输入内容但不提交，按 `Esc`
- [ ] 再次唤起悬浮窗，草稿内容保留
- [ ] 提交后草稿清空

### A7 – 采集不阻塞
- [ ] 连续提交 3 条内容，每次均在数秒内完成反馈
- [ ] 无需等待 AI 处理即可继续采集

### A8 – 重复采集检测
- [ ] 提交一条与已有内容完全相同的内容
- [ ] 系统标记为重复，不创建新条目

### A9 – 编辑与删除
- [ ] 在材料库中编辑一条内容（修改文本）
- [ ] 确认版本历史可见原始内容和修改后的内容
- [ ] 软删除一条内容 → 出现在回收站
- [ ] 从回收站恢复
- [ ] 永久删除（确认弹窗）

## 场景 B：近期方向形成

### B1 – 触发近期整理
- [ ] 采集多条内容后，调用 `POST /v1/recent-organization/runs`
- [ ] 返回 run ID 和状态 `queued`

### B2 – 查看近期快照
- [ ] 调用 `GET /v1/recent-organization/snapshots/latest`
- [ ] 返回分组结果（聚类 + 未聚类材料）

### B3 – 不相关材料保持独立
- [ ] 快照中 `unclusteredMaterialIds` 包含无明显关联的材料
- [ ] 浏览分组不会自动创建永久专题

---

## 场景 C：专题文档生成

### C1 – 聚类提升为专题
- [ ] `POST /v1/topics/from-cluster` 将某个分组转为专题
- [ ] 专题包含该分组的所有材料
- [ ] 专题在列表中出现

### C2 – 手动创建专题
- [ ] `POST /v1/topics` 创建指定材料的专题
- [ ] workspace 返回正确的材料列表

### C3 – 生成专题文档
- [ ] `POST /v1/topics/{id}/documents` 触发生成
- [ ] 文档包含摘要、概念、主张、引用
- [ ] 每个关键陈述可追溯到原始 Fragment

### C4 – 文档核验
- [ ] `GET /v1/documents/{id}/verification-claims` 返回待核验声明
- [ ] 核验策略可配置（全部 / 高风险 / 关闭）

### C5 – 文档版本
- [ ] 多次生成文档产生多个版本
- [ ] 可获取最新版本文档

---

## 场景 D：持续更新

### D1 – 专题建议
- [ ] 新增相关材料后，专题显示建议
- [ ] `GET /v1/topics/{id}/suggestions` 返回候选材料

### D2 – 增量更新预览
- [ ] `POST /v1/topics/{id}/document-update-preview` 预览变更
- [ ] 显示新增、修改、删除的内容

### D3 – 确认/拒绝更新
- [ ] 接受更新 → 生成新文档版本
- [ ] 拒绝更新 → 保持当前版本

### D4 – 专题成员管理
- [ ] 可添加材料到专题
- [ ] 可从专题移除材料

---

## 场景 E：数据控制与成本

### E1 – AI 禁用
- [ ] 在设置中禁用某条材料的 AI 处理
- [ ] 该材料只进行本地解析，不发送到 DeepSeek

### E2 – 费用查看
- [ ] 设置页面显示本月 token 用量
- [ ] 显示美元费用估算
- [ ] 显示调用历史和失败次数

### E3 – 预算设置
- [ ] 可设置月度预算上限
- [ ] 可设置预警阈值

### E4 – 数据导出
- [ ] `POST /v1/backups` 创建完整备份
- [ ] `GET /v1/backups` 列出备份
- [ ] `POST /v1/exports` 导出 Markdown 格式
- [ ] `GET /v1/data-paths` 显示数据存储位置

### E5 – 模型失败不污染数据
- [ ] 模拟 DeepSeek 返回非法 JSON
- [ ] 原始材料和已有文档不受影响
- [ ] AgentRun 记录为 `failed`
