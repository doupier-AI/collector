OmniDocBench 不进入七份金集

它是 MinerU 官方采用的页面级公开基准，可补充复杂对象精度，但不替代 #122 对完整文档、失败边界和研究价值的裁决。

已确认

能补什么

只在独立研究环境比较复杂嵌套表格、密集公式、非常规版式、手写与历史页面；优先参考 v1.6 的 296 页 Hard 子集。

不能替代什么

它以页面图像为核心，不验证 DOCX 原生结构、完整文档连续性、损坏/加密/超限失败，亦不进入本页评分。

为什么分开

数据版权声明限定研究用途且不可商用；同时它与 MinerU 同属 OpenDataLab 生态，不宜成为裁决 MinerU 的唯一证据。

执行约束本原型不下载、不提交、不分发 OmniDocBench 数据。若以后单独运行，只能本地按固定 revision 获取，并与固定评测代码 commit 配对；结果另行报告，不改写这 7 份样本的分数。查看 官方数据卡与版权声明。

自由试验

每项状态只保存在当前页面内存中。你可以套用情景，再逐项改写证据结论。

为什么分两层

“研究价值”回答一篇文档能不能被读、被导航、被复核；“证据锚点”回答具体的题注、表格、脚注或扫描页有没有如实落地。前者不能替后者打掩护，后者也不能替代整篇阅读。
