为什么是这 7 份

每个核心风险只设置一个主要承载样本；办公文档不参与“研究材料代表性”的证明。

样本权重
  • 中文单栏教材式 PDF、英文双栏论文式 PDF、扫描实验记录：合计 70%。
  • DOCX：10%，只防办公文档回归，不替代论文/教材。
  • 损坏、加密、超长：合计 20%，只评失败是否诚实且不可伪造。
  • 每份样本用同一组六维检查点，候选之间才可横向比较。
