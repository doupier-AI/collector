# apps/web 实施基线

最后更新：2026-08-07

本文件定义 `apps/web` 当前路由、用户路径、客户端状态、安全、可访问性和验证契约，面向前端开发者。产品定义与当前能力状态见 `docs/PROJECT.md`，决策留痕见 `docs/adr/`，历史实现过程从 Git 提交与 GitHub Issues 追溯。

## 1. 当前边界

Collector WebUI 使用 React 19、TypeScript、Vite 8 和 React Router 7，通过本机服务同源读取页面、HTTP API 和渐进事件。浏览器不直接访问 SQLite、文件系统或模型供应商。

当前已接入的用户能力包括：

- 从 Chat 或 TXT、Markdown、DOCX、文本型 PDF 导入开始研究；
- 在统一节点页阅读连续正文并多轮追问；
- 选中文字后使用选区上方浮动胶囊，明确【引用】后在此追问或深入研究生长子节点，或直接【标记】并添加笔记；
- 从来源条、引用或标记列表返回原内容和原选区；
- 使用顶栏「研究地图」按钮或快捷键 `t`（专注）/ `g`（关联）打开统一研究地图；专注模式查看当前节点的祖先、直接子节点与同级，关联模式使用桌面网状画布或窄屏关系列表；
- 查看父子、语义相关、融合来源三类边并筛选关系；
- 查看 AI 弱标记的流式预览，点击或键盘操作后复用预览内容生长子节点；
- 对每次主动提问单独决定是否允许联网，默认关闭；
- 在模型设置页管理供应商、模型、凭证状态和任务分配；
- 在运行记录页查看模型、搜索、耗时、重试、错误和脱敏摘要，并导出当前筛选范围。

阶段 I 的 D1/D2/D3、E1/E2/E3、F1 已实现。#40 已把 `t` 树与 `g` 关系导航收敛为统一研究地图的专注 / 关联模式；#41 已交付关联模式显著度、模式转场锚点与焦点保持；#42 已交付融合依据回跳（依据条目 + `?fragment=` 深链定位语义卡片 + 短暂强调，accepted 提案只读依据入口）；#43 已移除旧切片组成正文契约；#44 已交付统一视觉令牌、卡片五态、研究地图状态容器、画布组合编码与像素回归基线（详见 §4.3/§4.5/§10）。确认式融合（#31）与自动融合（#32）均已实现。

## 2. 阅读优先级

每次实施先读取：

1. 根目录 `AGENTS.md`；
2. `docs/PROJECT.md`；
3. 与任务相关的 `docs/adr/` 决策；
4. 本文相关章节；
5. 受影响源码、共享契约和测试。

产品、实现状态和验证证据发生冲突时，按项目根规则区分：产品文档定义目标与现役产品边界，源码和自动化证明实现，实际界面证明运行态。旧里程碑、测试数字和 Issue 状态不能替代当前证据。

## 3. 页面与路由

现役路由由 `src/app/router.tsx` 定义：

| 路由 | 当前职责 |
| --- | --- |
| `/` | 恢复最近研究；没有可恢复内容时显示开始页 |
| `/research/new` | 新研究开始页；文字提交或文件导入后创建真实研究 |
| `/research/:sessionId/node/:nodeId` | 统一研究节点页；支持消息、连续正文、选区、来源条、标记、树与关系导航 |
| `/research/:sessionId/reading/:contentSnapshotId` | 导入内容阅读页；支持选区、提问、标记与来源返回 |
| `/run-records` | 本地运行记录列表与筛选 |
| `/run-records/:runId` | 指定运行记录详情 |
| `/settings/ai-model` | AI 模型、凭证状态、模型发现和任务分配设置 |

兼容路由：

- `/research/:sessionId` 重定向到对应根节点页；
- `/research/:sessionId/branch/:branchId` 重定向到对应节点页；
- 重定向保留 `?sel=<selectionId>`，用于返回并恢复来源高亮。

无效会话、节点或内容快照必须显示明确的不存在 / 已清理状态并提供安全返回，不自动创建同名对象掩盖错误。

## 4. 当前用户路径

### 4.1 开始研究

开始页同时提供文字和真实文件导入：

- 文字提交后进入根节点；
- 支持的文件是 TXT、Markdown、DOCX 和文本型 PDF，单文件上限 20 MiB；
- 上传先创建并保存研究与导入任务，再进入解析和阅读；
- 上传文件后再输入文字不得重复创建研究会话；
- 扫描 PDF、OCR、图片和 HTML 不在当前范围。

请求结果未确认时保留用户文字和文件选择状态，不把操作显示为已保存。文件选择只存在浏览器内存，若页面在服务端确认前关闭，无法恢复尚未上传的本地文件。

### 4.2 提交与渐进回答

一次提交遵守以下顺序：

1. 保留输入文字，直到服务端确认持久化；
2. 服务端保存用户消息、AI 占位、任务、联网选择和幂等身份；
3. 成功后清空草稿，并在当前节点显示已保存内容和生成状态；
4. 客户端消费 `snapshot`、`delta`、`completed`、`failed` 等持久事件；
5. 断线时携带事件游标重连，超过重试边界后查询任务最终状态；
6. 完成或失败后以服务端返回的完整消息和任务为准。

网络结果不确定时复用同一个幂等键和首次联网选择；只有用户明确再次提交才创建新键。真实模型当前可能等待完整结构化结果后才写入渐进事件，前端不得用定时器伪造更早的模型输出。

### 4.3 连续正文与语义切片

用户始终阅读连续正文。当前新生成回答同时产生正文和经过结构校验的正式切片，旧消息按既有消息块边界提供临时切片兜底。WebUI 必须：

- 按稳定顺序将切片合成为连续内容；
- 保持内容块 ID、可读文本投影和来源锚点稳定；
- 不让分隔装饰进入选区文字或屏幕阅读器内容；
- 不把切片渲染成打断阅读的碎片卡片；
- 在结构化生成失败时呈现可重试失败，不展示半有效内容。

#35–#43 完成前，正文和切片仍属于兼容中的双契约。前端不能假定“正文已经是唯一事实源”，也不能新增继续依赖旧切片组成正文的长期接口。#35 已为节点视图附加可选 `bodyVersions` 字段（正文版本与语义片段，expand 阶段），前端暂按原切片/消息渲染，不消费该字段。

### 4.4 选区、引用与标记

消息正文和阅读快照中的非空文本选区都有效：

- 选中后在选区上方出现轻量浮动胶囊；
- 胶囊在横向与纵向都钳制在视口安全边距内：矮视口（如 568px）下选区贴底时，上方放不下、翻转下方又顶出底缘，此时钳到「视口底 − 胶囊高 − 边距」，任何选区位置都不溢出（横向钳制早有，纵向钳制 2026-08-10 补齐，窄屏钳制验收在并行高负载选区偏底时暴露 615>568）；
- 只有点击【引用】才进入输入框引用态；聚焦输入框不得清除原选区；
- 引用态提供“在此追问”和“深入研究这段”；前者留在当前节点，后者保存来源选区并生长子节点；
- 点击【标记】立即在本机保存选区，可填写一句笔记；不依赖模型；
- 点击选区以外区域取消浮动胶囊；Escape 不承担取消选区或关闭胶囊的职责；
- `?sel=<selectionId>` 恢复高亮和浮动胶囊，但不得自动进入引用态；
- 精确锚点失效时使用 exact、prefix/suffix 和粗粒度位置降级，始终保留已保存原文。

根会话页从 `⋯ → 查看标记` 打开居中模态弹窗，背景模糊且只列当前会话标记；支持关闭 / Escape、逐条勾选、全选、删除所选和直接编辑笔记。点击标记先关闭弹窗，再按来源类型返回消息节点页或导入阅读页，并携带 `?sel=<selectionId>` 定位原选区。标记条目显示选区摘要、笔记、来源节点和时间；旧“稍后再学”的星级、AI 概括和待学 / 完成切换不再显示。标记删除经 `DELETE /v1/research-later-items/:id` 彻底完成（无回收站），不存在返回稳定 404。

### 4.5 研究地图：专注与关联模式

根节点和子节点使用相同页面与能力。父子血统不可由前端重写；语义相关和融合来源是附加关系。

- 顶栏「研究地图」按钮（或快捷键 `t` / `g`）打开统一覆盖层；首次打开默认专注模式；
- 快捷键 `t` 直达专注模式、`g` 直达关联模式；已打开时按同键切换模式；
- 专注模式以当前节点为锚点：面包屑祖先路径、祖先链、当前节点（明确高亮与「当前」徽标）、直接子节点与必要同级；底部低强调「关联」区列出语义相关与融合来源邻居（默认展开、可折叠），弱化但不删除；
- 关联模式在桌面端显示网状画布，窄屏显示同源关系列表；
- 专注与关联模式消费服务端同一图投影（`GET /graph`，以当前节点为中心），不在 WebUI 拼装第二份图；WebUI 不再整树拉取 `/nodes`（该读取路径保留未删）；
- 关系筛选（父子、语义相关、融合来源）是模块级共享状态：一份筛选结果同时喂给画布渲染、键盘候选、窄屏列表分组与专注脉络；筛选只改变呈现，不改底层数据；
- 筛选后的键盘候选只包含相关节点；全部关闭时保留当前节点和明确空态；
- 画布支持平移、缩放、逐层展开 / 收缩、打开节点、打开父节点和返回当前页面；专注模式提供打开父节点与回到当前节点；
- 局部焦点（画布聚焦、专注 roving）不产生路由；只有显式进入节点才导航到另一份正文；
- 覆盖层由 Escape 或遮罩点击关闭并将焦点还给入口按钮；减少动态效果时不依赖动画表达状态；
- 专注模式的祖先链以投影深度为界（`maxDepth=2`，约两级祖先）；更远的祖先不出现在脉络中，属当前产品范围。

#44 起研究地图三视图（专注脉络 / 画布 / 关系列表）的加载、空与错误态统一使用 `.research-map__state` 状态容器（虚线框 + 居中 muted，`--error` 变体危险色边框，对齐 `.run-records__state` 先例）。画布组合编码：边 = 线型（实线/虚线/双点划线）+ 颜色 + 粗细 1.5 + 方向端点（父子边 父→子、融合边 来源→当前 同色箭头，语义相关无向不加箭头）+ 语义边中点类型标签；节点 = 尺寸（当前节点 +4）+ 填充（当前实心/其他空心）+ 描边粗细 + 当前节点光晕（`--graph-node-halo`）+ 透明度通道（非焦点节点 0.92、边 0.85，焦点回归时提升）；颜色不是唯一通道（延续验收 3 与 27）。专注脉络当前行带 `aria-current="location"`（读屏可判定当前锚点）。

F1 的相似性提议允许接受或拒绝。接受只建立语义相关边，拒绝进入冷却；当前不创建融合节点。

### 4.6 AI 弱标记

回答中的部分术语会显示低注意力标记；流式生成期间标记即随正文出现并可交互（ADR-0029）：

- 鼠标悬停约 400ms 意图确认后打开弹层并开始生成预览；键盘聚焦只打开弹层，按 Enter / Space 或点击才开始生成；
- 弹层通过持久事件流展示进度，离开后后台任务继续，再次打开可恢复；
- 首次点击标记或按 Enter 会记录生长意图：预览未生成时启动并等待同一份预览完成，然后直接生长子节点，复用该预览作为首轮内容，来源锚定用户实际点击的提及；
- Escape 关闭预览弹层并把焦点恢复到触发标记；窄屏钳制在视口内；减少动态效果时关闭非必要过渡；
- 模型未配置、生成失败或标记结果无效时只隐藏 / 降级增强层，不影响正文、手动选区、引用和来源返回。

普通回答、长文分节与续写、深入研究、供应商原生联网、Agent 联网和融合正文都消费消息上持久化的流内结构化标记；新 AI 消息即使没有合法标记也携带明确空数组，客户端不得调用词法检测补标。词法回退只适用于没有持久化标记字段的旧开发数据。四类对象为知识概念、命名实体、缩写、符号与技术标识。每个流内提及携带只在当前回答有效的隐藏对象身份：同一对象共享身份，同名异义对象分离；前端不按文字或相邻 DOM 临时拼接实体。同一节点跨消息复用由服务端完成语境核验，客户端只把返回的既有预览映射到当前提及。首次点击会等待预览完成后直接生长，不要求用户再次点击。

### 4.7 联网与引用

Chat、节点页和阅读页的主动提问都提供逐次联网开关：

- 默认关闭；
- 关闭时不得请求供应商原生联网或 Agent 搜索；
- 开启时才允许当前模型与搜索配置执行联网；
- 每次提交保存本次选择，不从上一轮隐式继承；
- 选区分析始终不联网；
- 供应商不支持、搜索失败或没有取得来源时显示诚实状态，不生成虚假来源卡片。

AI 返回的行内引用使用经过净化的来源记录。供应商原生引用位置已由服务端从原始模型输出校正到清洗后的正文；无法诚实校正时不提供错误的精确落点。Agent 与融合正文中的 `[来源n]` 在弱标记控制信息清洗后解析。外部链接明确标示来源，并使用安全新窗口属性；来源标题、摘要和 URL 都视为不可信内容。

### 4.8 模型设置与运行记录

模型设置页管理 ProviderProfile、模型发现、启用状态、当前激活配置和按任务分配。API Key 与普通 Profile 数据分离：

- 列表和普通响应只显示 `credentialConfigured` 等状态；
- 编辑时通过专用认证接口在组件内存中回填暗文输入；
- Key 不进入 URL、浏览器存储、日志、截图或普通导出；
- 当前使用中的配置不能停用；失效任务分配回退到可用激活配置。

运行记录页从本机读取模型与搜索轨迹，可按当前界面支持的条件筛选并查看详情。导出只包含当前筛选范围的脱敏 NDJSON；空结果不创建文件。界面不得显示认证头、Cookie、会话令牌、API Key、供应商原始敏感响应或带敏感参数的 URL。

## 5. 客户端状态与恢复

- 服务端是研究、消息、任务、附件、快照、节点、边、切片、标记和运行记录的事实来源；
- 路由保存当前研究、节点或内容快照身份；
- React 本地状态只保存草稿、抽屉、筛选、画布视口和瞬时交互；
- 不在组件间复制完整领域对象，不用数组下标作为持久内容 key；
- 网络重试复用稳定幂等键，用户新操作创建新键；
- `delta` 只服务渐进体验，事件携带的完整消息和最终查询结果用于收敛状态；
- 刷新后重新读取服务端视图，不依赖内存或 localStorage 还原业务事实；
- 页面关闭不取消已经提交的本机任务；重新打开后查询并恢复；
- 服务重启后按任务契约恢复排队项，将中断任务标记为可重试失败；
- 401 停止自动重试并提示重新打开 Collector；404 显示对象不存在；403 不绕过来源安全检查；
- 离线或本机服务停止时保留当前页面与未提交文字，并提供重新连接路径。

## 6. HTTP、事件与错误契约

前端直接导入 `packages/capture-contracts` 的共享类型，不复制近似接口。API 客户端统一处理：

- 同源 `/v1/...` 请求；
- Bearer 或 HttpOnly `collector_session` Cookie 认证；
- `Idempotency-Key`、输入上限和稳定错误码；
- 会话 `ResearchSessionRecord.isFavorite` 为正式布尔字段（默认 false），`PATCH /v1/research-sessions/:id` 接受 `isFavorite`，列表与详情均返回；该字段只表达收藏，不改变归档/回收站语义；
- `DELETE /v1/research-later-items/:id` 在本机认证后彻底删除单条标记，成功返回 `{ deleted: true }`，不存在返回 `not_found`；
- SSE 的事件游标、去重、退避重连、终态确认和连接关闭；
- 上传任务的取消、失败重试、刷新和重启恢复；
- 可重试模型错误与不可重试输入 / 安全错误；
- 用户可理解的错误分类，不显示堆栈或供应商原始响应。

凭据不能拼入事件 URL。同源 Cookie 由浏览器自动携带。页面隐藏时可以降低轮询频率，恢复可见时立即同步一次。

## 7. 安全边界

- 只请求当前页面同源 API；自定义模型 `baseUrl` 由本机服务校验，浏览器不得自行跨域调用；
- 不读取或展示 HttpOnly Cookie；
- Bearer token、Cookie、API Key、认证头不得进入 localStorage、sessionStorage、URL、日志、运行记录导出或错误上报；
- AI 内容、导入内容、来源、文件名、标题和错误文字均视为不可信输入；
- Markdown 使用受控渲染管线和严格白名单清理，禁止组件直接注入未净化 HTML；
- 外部链接使用 `noopener noreferrer`，不通过跨域备用请求绕过服务端限制；
- 上传 MIME、文件大小、文件名和内容合法性以服务端结果为准；前端检查只用于提前反馈；
- 自动化使用隔离数据目录、假凭证和确定性假模型，不调用真实云模型或真实网站。

## 8. 可访问性与响应式

每项用户可见交互都同时满足：

- 使用原生按钮、输入和语义化标题；可访问名称不只依赖图标或 placeholder；
- Enter 发送、Shift+Enter 换行，并提供可发现说明；
- 生成状态使用克制的 `aria-live="polite"`，不逐片段朗读全部流式文字；
- 临时抽屉、研究地图覆盖层（专注脉络 / 画布 / 关系列表）和预览弹层具有明确焦点进入、键盘操作、关闭和焦点回归；
- 颜色不是三类边、错误、选中或任务状态的唯一编码；
- `:focus-visible` 清楚可见；
- 主题入口以可访问名称直接宣布当前选择（如「主题：跟随系统」），三态使用原生单选组支持 Tab/方向键，Escape 关闭并把焦点还给入口；
- 320、768、1024、1440 像素以及 200% 缩放下，主要操作不被遮挡且无意外横向溢出；
- 窄屏导航使用覆盖层或同源列表，不缩小成不可操作的桌面画布；
- `prefers-reduced-motion: reduce` 下关闭非必要过渡、呼吸和画布动画；
- 长文保持舒适阅读宽度，不把每条消息或语义片段做成厚重卡片。

选区胶囊的 Escape 规则是产品特例：点击选区外区域取消；不要为追求通用弹层行为而改成 Escape 清除原生选区。

## 9. 前端结构约束

- 路由、数据请求、持久事件处理、表单状态和展示组件分离；
- AppShell 负责全局导航与侧栏边界，不承载领域生成逻辑；
- API 客户端统一认证、错误和事件处理，不在页面组件中散落 `fetch`；
- 当前内容渲染与 Chat 输入分离，以便节点消息和导入快照共用选区、引用和来源能力；
- 图导航与专注脉络只消费共享图投影，筛选、模式和视口属于客户端呈现状态；
- 来源锚点、选区、引用和切片使用稳定领域 ID，不以 DOM 路径作为唯一依据；
- 新能力通过明确契约和领域身份进入，不在单一消息组件堆叠大量布尔开关；
- 不为未来功能预先显示空白面板、无反馈按钮、假数据或假进度。

- #44 已落地：统一视觉令牌（tokens.css 分组）、语义卡片五态、研究地图状态容器（`.research-map__state`）、画布组合编码补强（父子/融合边箭头端点、语义边中点标签、透明度通道）、专注脉络 `aria-current`、`z-visual-baseline.spec.ts` 像素回归基线（8 张 png 入库，含深色主题阅读面——原为浅色，后由 ADR-0019 改整站深色，详见 §10）；ADR-0017（2026-08-09）已落地 B+A 视觉方向（衬线显示字阅读面、生长时刻徽记、彩虹按钮退役、rail 真实导航，详见 §4.3）；ADR-0019（2026-08-09）全套对齐产品取色板（浅/深底座暖化、主色回规格原值 `#c96442`/`#d97757`、深色整站统一深色化，取色源 `CONTEXT.md`「产品取色板」，详见 §4.3）；
- #31 已落地：确认式融合——「融合为节点」按钮（同一事务建语义边 + 融合来源边 + 无父链融合节点 + 任务），跳转融合节点页生成融合正文（自由正文 + `## 共同核心/## 差异/## 综合推导` 固定章节 + `[来源n]` 引用）；融合节点页顶部 `FusionSourceBar` 来源条（来源节点可点击）+ 正文 `FusionCitationMarker` 行内引用（点击 `?fragment=` 深链回来源语义卡片）；`fusion-compose-v1` 独立提示词版本与记账；ADR-0013；
- #32 已落地：自动融合——设置页 `settings/fusion` 开关（默认关闭，`/v1/settings/fusion` 持久化）；开启后节点页挂载自动扫描（`scan` 响应为 `{ proposals, autoFused }`），高置信（同一实体/共享概念）自动融合并标记「自动生成」（`isAutoFusionNode` + 回链 `triggerFusionProposalId`），节点页顶部 `AutoFusionNotice` 提示条可点击跳转，融合节点页标题旁「自动生成」徽章；低置信（类比/对比）保持逐条确认弱提示；ADR-0014。

迁移必须保持历史研究、引用和来源返回可用。生产调用方未全部迁移前不得删除旧读取路径；新前端也不得继续任选两套事实源。融合必须纯增量，不能修改来源节点、原文、父子血统或既有语义关系。

## 12. 禁止事项

- 不在后端确认前显示“已保存”；
- 不把研究业务事实只存在浏览器存储；
- 不把模型输出当可信 HTML；
- 不以轮询替代全部渐进事件而不记录原因；
- 不通过 token URL、浏览器持久化密钥或跨域绕过解决认证问题；
- 不在自动化测试中调用真实云模型或真实搜索；
- 不自动开启或继承联网授权；
- 不让语义边改写父子血统，不在 WebUI 维护第二份图；
- 不用切片卡片破坏连续阅读，也不让装饰边界进入选区文字；
- 不把候选方案或未验证的增强写成已实现能力（确认式 / 自动融合均已实现，其余融合增强如流式融合正文仍为后续项）；
- 不使用大面积紫色渐变、泛滥圆角卡片、装饰性统计或模板化英雄区；
- 不隐藏具体失败状态，也不用“出错了”作为唯一说明；
- 不把用户未提交的草稿、未授权内容或多余上下文发送给外部服务。

## 13. 阶段记录要求

每个完成的 WebUI 阶段在对应 GitHub Issue 与 Git 提交中记录：

- 用户现在能完成什么，以及与目标是否有偏差；
- 真实改动的路由、组件、契约、事件、数据和恢复行为；
- 所选验证级别、实际运行项、结果和按规则跳过项；
- Playwright 的相关视口、键盘、焦点、可访问性、控制台和网络证据；
- 刷新、重新打开、来源返回和服务重启边界；
- 临时兼容、已知缺陷、风险和未完成项；
- 若用户主动触发人类拟真测试，再记录触发模式、功能区、独立复核和基线变化。

长期产品、架构和验收约束同步到各自权威文档（`docs/PROJECT.md`、`docs/adr/`、`docs/ARCHITECTURE.md`）；测试数字、里程碑和提交历史不回填到本文形成平行时间线。
