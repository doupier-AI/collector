# Collector WebUI 布局共识

状态：2026-07-17 已确认的结构初稿。视觉尺寸、动效和小屏细节通过交互原型继续校准。

## 布局原则

Collector 采用自适应研究画布：

- 当前内容始终是视觉中心；
- Chat、导入文档、AI 回答和研究分支使用同一块主画布；
- 内容导航、AI 伴读和稍后再学按当前场景出现；
- 宽屏支持用户固定侧栏和来源对照；
- 来源线贯穿选区、研究分支和来源返回。

该布局吸收 Codex 的工作项导航效率与 DeepTutor 的伴读体验，并以沉浸阅读作为默认状态。

│                    │ █████░ AI 正在理解       │                  │
│                    │                          │                  │

默认状态保留四类常驻信息：

- 左上“内容”入口；
- 右上“稍后再学”入口与数量；
- 中央当前内容；
- 当前阅读位置和来源身份。

用户向下阅读时，顶部控件可以降低视觉强度；向上滚动或键盘聚焦时恢复完整显示。

## 内容导航

点击“内容”打开左侧抽屉：

```text
内容
├─ 开始 Chat
├─ 导入文档
├─ 继续最近内容
├─ 当前内容目录
└─ 当前研究路径
```

在宽屏中，用户可以把抽屉固定为工作项导航：

```text
┌────────────┬─────────────────────────────────────────────────────┐
│ 工作项     │ 当前内容                                            │
│            │                                                     │
│ ＋ 新建对话│ Transformer.pdf                                    │
│ ＋ 导入文档│                                                     │
│            │ ……正文……                                           │
│ 今天       │                                                     │
│ ▾ 主会话   │                                                     │
│   ├ 文档 A │                                                     │
│   └ 分支 2 │                                                     │
└────────────┴─────────────────────────────────────────────────────┘
```

Chat 和导入文档在导航中保持同级。研究分支显示在产生它的内容下面。选择任何条目后，中央画布切换为对应当前内容并恢复上次位置。

## AI 伴读区

阅读文档时，用户可以从画布右侧打开 AI 伴读区：

```text
┌────────────────────────────────────────┬─────────────────────────┐
│ 当前内容                               │ AI 伴读                  │
│                                        │                          │
│ 神经网络中的 激活函数·· 会为网络……    │ 围绕当前内容提问          │
│              ↑ 弱标记                  │                          │
│                                        │ [问当前内容的问题……]      │
└────────────────────────────────────────┴─────────────────────────┘
```

伴读区读取当前内容、当前阅读位置和用户明确引用的选区。用户可以收起伴读区，也可以在宽屏中固定宽度。纯 Chat 场景使用完整主画布呈现对话。

## 选区智能窗口

窗口优先贴近选区，并保持原文可见。屏幕空间较小时，窗口转换为底部抽屉。

固定字段、加载占位和主要操作立即显示。AI 内容优先逐段流式补入，稳定方案可以采用逐字段完成后显示。

## 深入研究与来源线

用户点击一次“深入研究”，随后看到轻量二选一：

- **沿当前内容研究**：建立依附于当前内容的研究分支；
- **开启独立研究会话**：建立新的研究空间并保存来源关系。

确认去向后，选区智能窗口扩展为研究画布：

```text
┌──────────────────────────────────────────────────────────────────┐
│ ← 返回原文「多头注意力允许模型……」       [预览原处]  稍后再学 6 │
│                                                                  │
│          ○ 原文 · 第 12 页                                      │
│          │                                                       │
│          ● 当前研究：为什么需要多个注意力头？                    │
│                                                                  │
│                    AI 研究内容……                                 │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

来源线显示研究起点、上一级和当前位置。用户可以返回原文、临时预览原处，或继续从研究内容中的新选区建立下一层分支。

宽屏可以临时并排显示来源和研究分支：

```text
┌────────────┬──────────────────────────┬──────────────────────────┐
│ 内容导航   │ 来源文档                 │ 深入研究分支             │
│            │ 原文与选区               │ 连续研究与引用           │
└────────────┴──────────────────────────┴──────────────────────────┘
```

用户可以把研究分支放大为完整画布，来源关系持续保留在顶部和来源线中。

## 稍后再学

“稍后再学”从右侧打开弱重现抽屉，当前内容和阅读位置持续保留：

```text
┌──────────────────────────────────────────────────────────────────┐
│ 当前内容                                  ┌─────────────────────┐ │
│                                           │ 稍后再学            │ │
│ ……正文……                                 │                     │ │
│                                           │ 此刻适合重看        │ │
│                                           │ · 多头注意力 ★★★    │ │
│                                           │   当前内容再次涉及   │ │
│                                           │                     │ │
│                                           │ [查看] [延后]        │ │
│                                           └─────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

抽屉说明每个项目出现的原因，并提供查看、延后、调整频率和仅手动查看。用户打开项目后，系统先返回来源，再进入选区智能窗口。

## 响应式状态

- 常规笔记本：主画布 + 按需左右抽屉；
- 宽屏：左侧导航、中央内容与临时来源/研究对照；
- 窄窗口：单画布，选区窗口和伴读区使用底部抽屉；
- 键盘操作：内容导航、选区窗口、伴读区、稍后再学和来源返回均具有清楚的焦点顺序。

## 视觉方向

- 主画布使用舒适阅读宽度和安静中性色；
- AI 使用低饱和靛蓝语义色；
- 稍后再学使用克制的琥珀色；
- 弱标记采用细点线或浅色底纹；
- 来源线是主要识别元素；
- 阴影集中用于临时浮层，固定区域使用边界和留白建立层级；
- 加载骨架保持窗口尺寸稳定，流式内容按段落自然增长。

## 原型需要校准的细节

- 左侧导航固定后的默认宽度；
- AI 伴读区的默认宽度与打开入口；
- 选区窗口转换为底部抽屉的屏幕阈值；
- 来源与研究分支并排时的比例；
- 来源线的层级折叠方式；
- 弱重现抽屉一次展示的项目数量；
- 动效速度、键盘焦点与减少动态效果设置。
