# 弱标记密度目标与上游已覆盖概念去重

2026-08-16 确认（真实模型使用反馈驱动）：

1. **密度目标改为每段应标尽标**。full 密度（节点深度 0–1）下，每个段落中首次出现的重要概念——专业概念、理论、机制、方法、关键技术名词、重要人物/组织/作品、难懂的缩写与记号——都应当输出弱标记，一段通常 2–4 个、概念密集的段落可以更多；提示词附正面示例，并要求论文/书籍/产品等完整标题作为一个整体标记，不得拆成碎片。深度 2–3 减量（≤4）与深度 4 停止的收敛规则不变。
2. **上游已覆盖概念不再重复标记**。生成子节点回答时，父链上下文携带每个祖先节点的主题与该祖先已持久化的弱标记概念清单（去重、有界：每祖先 ≤24 个、单词 ≤40 字，计入父链总字符预算且优先级最低）；提示词去重规则指示模型：祖先主题与已标记概念在正文可以自然提及，但不再为它们输出弱标记、不重复展开解释，只标记当前回答真正新引入的对象。

**Why:** 原 full 密度指令只有「只标记少量、宁缺毋滥」的限制性措辞，小模型（deepseek-v4-flash）依从结果是概念密集回答只标 1–2 个，弱标记对用户近乎不可见。同时，子节点不知道父节点已经讲过什么：同一概念（如父节点主题 Transformer）在子节点被重新标记、点击后再生长一个重复节点，沿父链向下形成内容重复的坏循环。「提及过但未展开」与「已充分解释」不同：前者仍可正常标记生长，后者必须去重；祖先标记清单 + 节点主题是该区分在当前数据下的可行近似。

**Consequences:** 回答内隐藏身份（ADR-0028）、预览跨节点重新生成（ADR-0027）与流式交互（ADR-0029）不变；去重只抑制「标记与重复解释」，不禁止正文自然提及上游概念。父链组装因此读取祖先消息的持久化标记，但不触发词法回退（无标记字段的旧数据清单为空即可）。弱标记生长的子节点首条回答（预览内容直接落库）显式持久化空标记数组，声明「本条无标记」，不再被节点视图当作旧数据退回词法检测。密度指令使 thinking 模型的推理占用显著增加：注入弱标记指令的正文路径默认输出预算由 8_000 提高为 16_000（`RESEARCH_BODY_DEFAULT_MAX_TOKENS`），融合正文预算由 ADR-0013 的 4_000 提高为 8_192（`FUSION_COMPOSE_TOKEN_BUDGET`）——thinking 推理与正文共用 max_tokens，预算不足时推理耗尽预算、正文为空（#86 真实探针两次复现空正文，提高预算后同提示词正常完成且标记密度达标）。真实模型对密度指令的依从仍需通过真实模型验收持续观察。

2026-08-17 真实验收（#86 场景九）追加验证：融合正文路径在 8_192 预算 + 思考模式下**推理不收敛**——直连探针 8192 与 16384 预算均 `finish_reason=length`、推理 token 全部耗尽、正文 0 字（77.9s / 154.8s），融合提示词（密度标记指令 + 固定章节 + `[来源n]` 引用 + 来源材料）使 flash 思维链反复咀嚼指令不进入正文；进一步加大预算只会拉长推理，不改变结果。融合是给定来源材料的整理任务（结构、引用与材料范围均已固定），故**固定关闭思考模式**（`thinking: false`）：同探针 10.5 秒产出 1_871 字契约合规正文（三个章节、12 个弱标记、`[来源n]` 引用、双来源逐字可追溯），`finish_reason=stop`。同一取证还发现任务记录缺陷：融合任务在 claim/retry 时被通用研究版本 `research-slices-v1` 覆盖（实际生成由 fusionPlan 驱动、提示词仍是 `fusion-compose-v1`，纯记录失真），已修复为融合任务保留 `fusion-compose-v1`。

同一验收还暴露并收口了两个同链路的既有缺陷（均不影响 ADR-0027/0028/0029 边界）：

1. **术语预览不再注入弱标记指令**。预览生成与追问共享 `answerResearchConversation`，此前无条件携带标记指令；旧指令措辞限制性极强，短小预览实践中很少带标记，问题潜伏未发。密度指令正向化后，预览内容必然携带 `[[category:id:text]]`，而预览链路不解析该语法——原始控制串原样落库并渲染进弹层（#86 真实验收截图复现），还会随生长进入子节点正文。预览是「可独立阅读的解释片段」这一产品契约不变，故从源头解决：生成请求显式关闭标记指令（`mentionMarkup: false`），模型不知道语法就不会输出；关闭时父链去重规则同步省略标记措辞，保留「不要重复展开解释」的内容约束。
2. **预览弹层按实测高度定位，保证完整落在视口内**。弹层为 fixed 定位、不随页面滚动；原定位把高度硬编码估为 240px，标记靠近视口底部且预览内容较高（完成态可达 420px 上限）时，底部的「进入这个概念」按钮被推出视口且永远无法滚达（#86 场景六真实验收中 Playwright 点击重试 3154 次直至 30 分钟超时）。现按弹层实测高度选择朝向（下方→上方→贴底钳制），并在预览状态/内容变化后重新锚定。
