# 统一上下文装配、证据汇合与供应商适配边界

2026-08-23，用户经 #116 逐项确认：Collector 为每一次模型调用设置供应商无关的统一上下文装配层。统一的是调用前的准入、选择、预算、来源记录和供应商转换，不是把全部信息拼成一份大提示词；任务用途先决定需要什么、允许看什么和必须产出什么，再选择模型。所有模型调用都经过装配层，并按用途采用最小必要准入，最终写作、搜索取证、标题提炼、旁路增强和术语预览等任务不共享同一份完整上下文。主流 Agent 产品的现行做法与取舍见[上下文管理调研](../research/ai-harness/agent-context-management.md)，它为决策提供证据，不代替 Collector 自身边界。

装配输入保持三种语义通道：**行为规则**回答“可以怎样做”，**事实证据**回答“根据什么回答”，**用户适应**回答“怎样更适合当前用户”。三者不做跨通道线性排序：事实证据不能因用户偏好而失真，画像或记忆不能取得指令权，材料中的命令式文字永远只是证据内容。产品硬边界与任务硬契约不可覆盖；其下依次尊重本轮明确要求、项目指令、全局用户指令和仅在用户未指定时生效的任务默认/风格。同层冲突时，作用范围更具体、时间更新且由用户明确表达的内容优先。用户要求总结、解释、翻译或改写指定材料时，忠实表达材料并把未经核验的主张归属于材料；用户要求判断真假、比较或研究现实结论时，按来源质量、直接性、时效和可追溯性选择证据并呈现重要冲突。

任务判定优先使用用户明确选择的操作、本轮文字和当前对象。只有低风险语义仍含糊时，模型才可基于当前请求与必要局部语境辅助判断；联网、记忆写入、删除、敏感信息和其他高影响行为不得由模型推断代替用户授权。用户适应可以调节解释深度、术语密度、示例、结构顺序和复习提示，但不能改变事实结论、证据标准、安全、工具权限或任务目标，也不能仅凭画像或掌握假设省略理解结论所必需的条件、风险与反例。本轮表达和当前表现可以立即推翻旧适应信息；知识掌握假设在 #117 确认其证据与生命周期前不默认注入。

各来源使用受限作用域，而非共享一套全局/项目/会话/节点/单轮矩阵：产品规则作用于全局或当前任务；用户指令和回答风格支持全局、项目与本轮覆盖；画像只属于用户级，项目中的临时身份属于项目指令；项目、节点、会话、选区和附件按原归属作为事实证据，不自动升级为画像、指令或记忆；本轮内容结束后不自动长期化。长期记忆、聊天历史和知识掌握的写入、过期、删除与总开关由 #117 决定。RAG 只在获准的资料范围内召回，联网搜索逐次授权，联网结果默认不进入 RAG、长期记忆、画像或知识掌握；未来只有用户明确保存或导入后，才经过独立知识摄取流程长期化。

在 #116 当前边界内，各来源的默认准入与用户控制如下：

| 来源 | 权威性与作用域 | 默认准入、生命周期与撤销 | 敏感性处理 |
| --- | --- | --- | --- |
| 产品硬边界、任务硬契约 | 行为规则；全局或当前任务 | 随适用调用启用，用户内容不能关闭或覆盖 | 只向用户展示规则类别/版本，不展示原始系统提示 |
| 当前问题、本轮明确要求、用户明确选中的对象 | 本轮指令与事实证据；仅当前任务 | 默认纳入且受预算保护；用户可在调用前改写、取消选择或改换任务，结束后不自动长期化 | 只传递任务所需片段，保留原来源权限和敏感性 |
| 全局/项目用户指令与回答风格 | 行为规则或用户适应；仅在各自范围内 | 仅用户已配置、已启用且与任务匹配时准入；用户可查看、修改、关闭或删除，后续调用随即不再采用 | 作为用户私有设置处理，不转成事实证据或公开来源 |
| 项目、节点、会话、选区与附件内容 | 事实证据；保持原归属 | 只有任务对象和允许范围需要时才成为候选，不整库或整段历史默认注入；撤销选择或来源权限后，后续调用不再采用 | 继承原内容权限、敏感性与可见范围 |
| 可追溯 RAG | 事实证据；获准的知识范围与当前任务 | 任务需要本地证据时才检索，召回结果仍须经过装配；排除资料范围后不再召回 | 继承被摄取资料的权限、版本和定位 |
| 联网搜索 | 事实证据；当前搜索运行与本轮 | 默认关闭、逐次授权；结果默认不长期化，材料中的命令式内容不取得指令权 | 作为外部内容保留来源和完整性状态，不升级为用户画像或内部规则 |
| 用户画像、长期记忆、聊天历史与知识掌握 | 只能进入用户适应或事实证据，不能取得指令权 | #117 明确证据、写入、过期、删除和总开关前不默认注入；#116 不替它预设生命周期 | 视为需要独立用户控制的私有数据，不因历史存在而自动获得准入资格 |

“从后续调用撤销”不等于追溯改写已经生成的正文或历史记录；是否以及如何回溯处理，由相应来源的生命周期决策另行规定。

所有输入先成为**上下文候选项**，只有装配结果可以进入供应商调用。候选项使用共同治理外壳表达稳定身份、三通道类别、来源与定位、允许用途和作用域、生命周期、敏感性、可靠性、预算估算及用户控制，同时保留分类内容的原义，不压平成无身份字符串。装配另行产生供应商无关的**本轮装配结果**，记录采用项、排除项、理由、预算与降级路径，不反向修改候选。供应商适配层只把装配结果转换成目标模型支持的 system、developer、user、tool 或等价形式；不得重新检索、排序、增加供应商记忆、扩大作用域或改变权威性。供应商无法忠实承载边界时，拒绝该路径或明确降级。

**证据候选**是上下文候选项的事实证据子类。可追溯 RAG、Agent 联网搜索、供应商原生联网及未来工具保持独立的上游获取、权限、缓存、失效和失败语义，只在共同证据交接处汇合。证据候选保留原始来源身份与类型、实际内容和必要语境、版本/抓取时间/校验身份、可达到的定位精度、原文/部分抓取/摘要等完整性状态、取得问题与授权范围、可确认的作者和时间信息、召回信号、完整语义范围、预算与失效条件。RAG 相似度、网页排名和供应商 grounding 分数只在各自路径内有意义，不能横向比较或充当事实置信度；装配层负责跨来源去重、冲突保留、预算选择和采用理由，最终写作只引用实际参与结论的来源。网页无法稳定精确定位时诚实降级为页面级引用，不伪造精确位置。

预算先保护产品硬边界、任务硬契约、当前问题、本轮明确要求、用户明确选中的核心材料以及最低可用的正文/结构化输出空间，再按任务必要性、作用域、直接性、来源质量和时效选择完整语义范围。预算不足时依次舍弃无关画像与风格细节、低置信适应、重复材料、旧且低相关的历史和次要证据；不得从中间粗暴截断候选，也不得静默删除当前问题、核心证据或最低可用回答。仍无法容纳时使用更大窗口、分阶段处理或明确说明限制。具体 token 数、阈值和摘要格式由实施切片以不同模型和真实用户路径校准。

权限、数据准入、作用域、敏感信息、工具协议和结果结构由 Collector 程序强制；产品提示词只解释模型必须理解的任务和语义边界。存在个性化、历史召回、项目指令、重要降级或冲突时，产品提供克制、可展开的**本轮上下文说明**，展示采用类别和安全的排除原因；用户自建内容可进入查看、修改、删除或关闭入口。事实依据仍由正文引用和来源区域承载；原始系统提示、隐藏推理、候选分数、供应商内部字段及无权/敏感内容不展示。更详细的装配记录只保存在本地脱敏运行轨迹中。

本决策不引入新的 Agent 框架，不决定 TypeScript 字段、数据库、检索算法、向量库、重排模型、网页快照存储、具体模型分配或 UI 布局。#109 继续负责知识摄取、解析、索引、检索与重排；#117 继续负责记忆、画像和知识掌握生命周期。当前分散的父链/语义范围预算、调用用途与运行记录只是迁移接缝，不表示统一装配和个性化已经实现。
