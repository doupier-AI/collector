# 研究地图生命周期筛选始终至少保留一种状态

2026-08-20 用户确认。

## 决策

- 研究地图的生命周期筛选包含“活跃”和“已归档”，支持只看活跃、只看归档或两者同时查看。
- 两项不能同时关闭。用户尝试关闭最后一个已选项时，界面阻止该操作并保持当前结果，不产生生命周期全空的地图状态。
- 省略生命周期条件等同于同时包含活跃和已归档；显式条件必须是去重后的非空集合。
- 生命周期与项目、节点创建时间及永久关系组合成同一份观察输入，由统一观察模块计算范围、边界、桥接和连通分类。
- 筛选只改变当前观察，不归档、恢复或改写任何会话、节点、正文或关系事实。

## Why

用户需要分别回看正在进行的研究和已归档成果，但“活跃与归档都不看”没有可理解的观察对象。允许全空还会迫使产品另行规定焦点节点、范围边界和返回现场是否例外保留，形成一个没有用户价值却容易产生多套结果的特殊状态。

阻止关闭最后一项让筛选始终有明确含义，也让画布、窄屏列表、键盘候选和刷新恢复共享同一个非空不变量。

## 与既有 ADR 的关系

- 本 ADR 与 ADR-0036 的节点创建时间和 ADR-0037 的未分类项目筛选共同完成 #66 的范围筛选产品语义。
- ADR-0026 允许永久关系类型全部关闭是专注模式的独立决定，不类推到生命周期；关系全空仍保留焦点并置灰其余节点，生命周期则始终至少命中一种状态。

## Consequences

现有 `includeArchived` 只能表达“全部”或“仅活跃”，不能表达“仅归档”，因此不再作为正式产品接口。共享契约应改用非空的生命周期集合；HTTP 必须拒绝空集合、重复值、非法值和旧 `includeArchived` 参数，不能静默显示全部。此决定不需要 SQLite schema migration，现场状态仍只保存在当前浏览器 history entry。
