# 提及→实体→预览模型

2026-08-03 访谈确认弱标记（提及）与实体预览的关系模型。

**决策：**
- 弱标记即"提及"：以 `[[type:text]]` 内联标记形式与正文在同一次模型流中产生；短语闭合即显示；用户永不见控制符；格式错误丢标记保正文；保存干净正文 + 独立范围；预设类型少量稳定；公式复用 Markdown/LaTeX。
- 同一稳定内容版本内，同一实体的多个提及共享一份预览与同一次流式生成任务。
- 跨节点/跨文档复用预览必须先经实体核验（此条复用范围由 ADR-0027 收紧为仅限同一节点）。
- 服务端负责稳定实体身份。

**Why:** 重复生成同一概念的预览浪费且可能不一致；但未经核验的跨上下文复用会把不同实体错误合并。

**Consequences:** 提及→实体→预览是三级结构；预览生成一次、按实体复用。复用的现行最外层边界与节点内核验规则由 ADR-0027 进一步收紧。
