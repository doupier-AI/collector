# 干净正文、独立最终写作与旁路增强

2026-08-23 用户确认：Collector 把搜索/工具取证、最终写作、可读正文、旁路增强和推理展示拆成供应商无关的责任边界。搜索与工具阶段只产出带来源证据；普通非工具回答本身就是最终写作，联网或工具工作流由独立最终写作阶段生成用户正文。供应商原生联网只有在适配器能确认最终回答通道时才可直接进入正文，否则先由 Collector 定稿；缺少可追溯证据时，在用户已开启联网的前提下明确切换到 Agent 搜索，两条路径均不可用时诚实失败。

正文继续逐字流式，是唯一可读事实源，只保存用户可阅读、复制和普通导出的自然 Markdown。弱标记、引用定位和章节候选不再依靠正文内控制串，而是在段落闭合后通过绑定正文版本与稳定范围的旁路增强产生；范围校验成功后才能显示和交互，全文完成后再做整体校验。旁路失败只减少增强，不能改写或阻塞正文。已有 Markdown 标题可直接形成导航；无标题长文可在完成后获得锚定真实段落、但不写入正文的章节标签，无法形成有意义章节时不显示导航。长文仍可先做内部大纲规划，但不再强制每节首行使用固定 `##` 模板。

弱标记保留 ADR-0031 的密度与深度规则。标注器在当前回答范围内区分同一对象与同名异义；身份不跨回答、节点或正文版本继承。标记一旦显示并可交互，就不得静默移动、合并或改指其他对象；最终校验只能补充新标记或丢弃尚未展示的候选。

原始供应商 reasoning 不展示，也不进入普通消息持久化、正文、搜索、模型上下文或普通导出。供应商明确提供可展示摘要时，摘要可与回答分开保存、回看、单独复制并随回答删除；否则界面只显示运行状态。ADR-0035 的思考开关、暂停/继续/停止与消息版本语义继续有效，但“原始思考过程完成后可回看”由本决策取代。

显式协议污染必须在污染片段展示前终止；此前已确认干净的前缀保留为失败的部分回答，但不进入搜索、未来上下文或完成态增强。用户主动停止时仍保留干净正文与已校验增强。重启只恢复已确认正文和已校验旁路，未完成增强重新计算；无法验证的精确引用降级为章节级或回答级来源。安全保证采用结构隔离：搜索/工具内容在架构上不能进入正文，显式控制协议可确定性拦截；对任意自然语言自述不宣称绝对识别，“零泄漏”以规定的匿名污染夹具和真实验收场景为发布硬门。

本决策 amends ADR-0009、ADR-0028、ADR-0032 与 ADR-0035。具体事件字段、标注模型、调用次数和段落增强延迟由后续原型决定；当前实现仍使用流内弱标记、固定长文章节标题和原始 reasoning 回看，必须在独立实施切片验证完成前如实标为未迁移。
