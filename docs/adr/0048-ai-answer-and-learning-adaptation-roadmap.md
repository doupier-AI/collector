# AI 回答与学习适应按可回滚切片分阶段交付

2026-08-24，用户经 #120 逐项确认：Collector 把 AI 回答与学习适应蓝图分成“现在 / 下一阶段 / 远期”三个交付窗口。窗口不是一次性大版本；每个窗口由可独立验收、可独立回滚的纵向切片组成，只有窗口内全部退出条件满足后才能进入下一窗口。文档决定不代表功能已经实现，实施期间继续按 `docs/PROJECT.md` 四态能力表如实记录。

本决策编排 ADR-0044 至 ADR-0047 已确认的责任边界，不改变正文唯一事实源、三通道上下文治理、三类用户适应数据的独立生命周期或来源图片协议。它不冻结 TypeScript 字段、SQLite 表、事件 wire schema、模型、token 数、索引、解析器或 UI 布局；这些由对应实施切片在本决策的依赖和验收边界内确定。

## 已完成前置：取证与最终正文隔离

#129 已完成搜索/工具取证与最终正文的结构隔离、供应商原生联网终态确认、统一正文准入和协议污染失败语义，并已进入本决策基线。#120 不再派生或重开“联网草稿泄漏”实施票。未来若出现同类回归，修复必须恢复取证与正文写入权的类型和流程隔离；不得采用关键词删除、宽泛正则或正文事后改写来猜测并清除工作草稿。

## 现在：收口回答底座

“现在”是多个独立切片组成的交付窗口，不是一个大版本。严格顺序为：原始 reasoning 先独立退役；完整 Markdown 文档解析与稳定定位、统一上下文装配并行建设；两者稳定后再分别迁移引用、弱标记和章节旁路。丰富 Markdown 呈现在稳定定位后交付，可以与旁路迁移并行，但也是本窗口退出条件。

### N1：退役原始 reasoning

- **用户可见结果**：思考区域只显示运行状态，或供应商明确提供、允许向用户展示的摘要；回答、复制、搜索、导出和历史版本都不再携带供应商原始 reasoning。
- **前置与数据变化**：沿用 #129 的最终正文准入；停止新 reasoning 进入普通消息、版本快照、事件、API 和 WebUI，按 ADR-0007 清理开发期存量，不保留秘密备份或兼容双写。
- **明确不做**：不调用另一个模型自动生成“安全推理摘要”，不改变思考开关和暂停/继续/停止的运行控制语义。
- **迁移与回滚**：删除原始 reasoning 是有意且不可逆的安全收缩；代码回滚只能退化为运行状态，不能恢复已删除内容或重新开始写入。
- **退出条件**：普通回答、长文、深入研究、供应商原生联网、Agent 联网和融合，以及暂停、继续、停止、重试、重启恢复和旧版切换，均证明原始 reasoning 不进入正文、普通持久化、API、日志、搜索、上下文或导出。

### N2a：完整 Markdown 文档解析与稳定定位

- **用户可见结果**：一条回答始终作为一份完整 Markdown 文档阅读；跨空行代码围栏、松散列表等结构不再被拆坏，选区、引用、弱标记、章节和来源返回仍落到正确文字。
- **前置与接口变化**：正文继续是唯一自然 Markdown 字符串；从同一完整文档语法树及源码位置派生段落身份和稳定范围，正文版本、语义片段、深链和现有选择锚点只消费该派生结果，不建立正文副本。
- **明确不做**：不迁移统一内容块，不改变消息正文事实源，不在此切片引入来源图片或 AI 图片。
- **迁移与回滚**：开发数据可按 ADR-0007 重建派生定位；旧正文版本缺少新定位时诚实降级到较粗位置。回滚只切回旧呈现，不改写正文字符串；禁止同时维护两套可写定位事实。
- **退出条件**：围栏代码跨空行、松散列表、标题、表格、公式源文本、流式未闭合结构和重启恢复均保持正文逐字一致；选区、引用、弱标记、章节、复制、语义片段、深链和来源返回通过同一位置模型验证。

### N2b：丰富 Markdown 呈现

- **用户可见结果**：标题、段落、强调、引用、普通与只读任务列表、链接、GFM 表格、行内和围栏代码、分隔线及受限 TeX 公式均可自然阅读和复制；失败时保留可读源文本。
- **前置与接口变化**：依赖 N2a 的完整文档解析与位置；表格局部横向滚动，代码永不执行，公式使用不信任输入的本地排版并保留可复制 TeX 与可访问 MathML。
- **明确不做**：不开放 raw HTML、MDX、脚本、iframe、主动嵌入、模型 `data:` 图片或可执行 SVG；不把普通 Markdown 图片链接命名为来源图片。
- **迁移与回滚**：正文和持久化不变，渲染器可以独立回滚；公式或复杂结构解析失败时原样显示，不吞正文。
- **退出条件**：320px、常用桌面视口、200% 缩放、键盘、读屏、减少动态效果、复制、选区、引用高亮、流式和重启恢复均通过专项浏览器验证；危险输入和资源上限通过负例验证。

### N2c：统一上下文装配覆盖全部现行模型用途

- **用户可见结果**：每次 AI 调用都按当前任务使用最少必要信息；当前问题、用户明确选中的核心材料和最低回答空间不会被静默挤掉，发生个性化、历史召回、项目指令、重要降级或冲突时可查看克制的本轮上下文说明。
- **前置与接口变化**：把现有当前问题、任务硬契约、父链、语义片段、选区、附件、联网证据和其他已获准来源包装为 ADR-0045 的上下文候选项；统一执行准入、作用域、冲突、预算、去重、脱敏和采用理由，再产生供应商无关的本轮装配结果。供应商适配器只转换结果，不检索、扩权或重新排序。
- **明确不做**：不提前创建 RAG 专属 chunk/schema，不统一不同上游的相关性分数，不实现画像、长期记忆或已掌握知识点，也不把所有用途塞进一份大提示词。
- **迁移与回滚**：按任务用途逐个迁移并保持用户行为等价；每个用途切换时不得双发模型请求。未迁移用途可以暂时走旧适配，但整体能力保持“部分实现”；普通日志不保存候选正文或敏感排除内容。
- **退出条件**：以实施领取时共享契约和调用入口清点出的全部现行模型用途为门禁，至少覆盖普通回答、长文规划与写作、联网取证与最终写作、深入研究、融合、标题、导入章节、选区分析、弱标记/增强、术语预览与核验。每个用途都具有明确用途、准入来源、预算、装配结果、脱敏运行记录和供应商转换测试；存在任何绕过入口时本窗口不得退出。

### N3：引用、弱标记与章节分别迁入旁路

N3 的三个切片互为兄弟，均依赖 N2a 和 N2c；它们可以独立验收和回滚。段落闭合后产生的候选只有经当前生成尝试和稳定正文范围校验后才能显示，只有经正文版本复核后才能持久化。暂停可保留已验证增强，未完成候选在恢复或重启后重算；增强失败只减少增强，不改写或阻塞正文。

#### N3a：引用旁路

- **用户可见结果**：引用仍紧邻实际陈述并可返回来源，但自然 Markdown 正文不再包含 `[来源n]` 控制串。
- **前置与数据变化**：引用绑定正文版本、稳定范围和来源身份；原生联网、Agent 联网和未来 RAG 保留各自来源身份与可达到的定位精度。
- **明确不做**：不由旁路拥有搜索、RAG 检索或最终证据选择，不伪造网页精确位置。
- **迁移与回滚**：采用 additive sidecar；旧正文没有对应旁路时只显示来源区域或粗粒度引用。禁止为回滚同时向正文写回 `[来源n]`。
- **退出条件**：六类生成路径、流式段落、暂停/重启、停止、重生成和旧版本均能保持引用与正文版本匹配；确认所有消费者改读旁路后删除模型输出和正文解析中的 `[来源n]` 协议。

#### N3b：弱标记旁路

- **用户可见结果**：已闭合段落可逐步出现经校验的可交互弱标记；失败时仍显示完整正文，正文不再包含 `[[…]]` 控制串。
- **前置与数据变化**：继续遵守 ADR-0031 密度/深度和回答内身份规则，标记绑定正文版本与稳定范围；旁路标注调用必须经过 N2c。
- **明确不做**：不恢复词法补标，不让身份跨回答继承，不因增强失败阻断回答。
- **迁移与回滚**：旧版本无旁路时保持干净正文并明确无标记；禁止双写控制串和旁路。已展示标记不得被最终校验静默移动、合并或改指。
- **退出条件**：普通回答、长文、深入研究、供应商原生联网、Agent 联网和融合覆盖流式、失败、暂停、重启与旧版本；所有消费者改读旁路后删除模型提示、清洗器和正文中的弱标记协议。

#### N3c：章节旁路与自然长文

- **用户可见结果**：模型可自然使用 Markdown 标题；有标题时直接形成导航，没有标题时完成后可生成锚定真实段落的章节标签，无法形成有意义章节时不显示导航。
- **前置与数据变化**：标题和无标题章节标签均从 N2a 的稳定位置派生；章节增强模型调用经过 N2c。
- **明确不做**：不把章节标签写回正文，不恢复一节一卡，不要求所有回答都有章节导航。
- **迁移与回滚**：旧正文继续按现有可验证标题读取；新增旁路缺失时只损失导航。禁止通过兼容双写继续强制固定标题模板。
- **退出条件**：长文计划、逐节写作、截断续写、暂停/重启、旧版本和来源返回均保持正文与导航一致；确认消费者迁移后删除强制 `##` 标题和对应清洗/补写协议。

### “现在”窗口退出门

N1、N2a、N2b、N2c、N3a、N3b、N3c 全部完成并各自通过风险匹配的自动化和用户可见浏览器验证后，“现在”窗口才可退出。任何一项未完成时，对应能力继续保持“部分实现”或“未实现”，不得因底层接口、原型或文档存在而升级状态。

## 下一阶段：学习适应、可追溯证据与来源图片并行

“现在”退出后，学习适应、RAG 证据适配和来源图片成为互不阻塞的并行分支。它们共同消费统一上下文或稳定引用边界，但不互相写入：画像、记忆和已掌握知识点不进入 RAG；RAG 和联网结果不自动进入画像、记忆或已掌握知识点；回答侧不反向规定解析、索引、召回或重排。

### A1：个性化控制中心、回答方式与显式用户画像

- **用户可见结果**：轻量引导可跳过；用户能分别管理“关于你、回答方式、常用要求、项目目标与要求、长期记忆、学习适应”，可总暂停、逐类关闭、删除，并可选择“本轮不使用个性化”。无配置用户保持平衡、中性体验。
- **前置与数据变化**：依赖 N2c；画像只由用户显式 CRUD，回答方式和用户指令保持各自语义。关闭不等于删除，删除只影响后续调用。
- **明确不做**：不自动推断或推荐画像，不创建账号、访客模式或多人数据隔离，不把当前研究目标长期化。
- **迁移与回滚**：新数据保持本机私有并可由旧版本忽略；回滚停止读取而保留用户数据，旧提示词路径不得绕过总开关或本轮关闭。
- **退出条件**：默认关闭/中性、跳过与一次提醒、总开关、原子开关、本轮关闭、查看/编辑/删除、敏感身份负例和单用户边界均有端到端证据；实际采用时只显示安全类别说明。

### A2：已掌握知识点

- **用户可见结果**：用户完整、正确地用自己的语言复述稳定知识后，Collector 可形成最小“已掌握”成果，并在真正相关的新知识中自然连接；用户可查看来源、删除，并分别关闭记录和使用。
- **前置与数据变化**：依赖 A1 的学习适应控制与 N2c；使用独立生命周期和严格费曼式复述核验，不与画像或长期记忆共用通用容器。
- **明确不做**：不建立等级、分数、置信度、衰减、未掌握清单或复习周期；阅读、点击、选区难度分析、关键词命中、助手陈述和“我懂了”都不是掌握证据。
- **迁移与回滚**：回滚停止记录和使用但保留可删除成果；误判按质量问题纠正，删除来源不暗中保留原文，衍生数据按用户选择清除。
- **退出条件**：正确与错误费曼样例、关键遗漏、复述助手原句、宽泛学科标签、自然连接、记录/使用分控、来源删除、误判纠正和衍生删除均通过自动化及真实模型验收。

### A3：长期记忆

- **用户可见结果**：明确开启后，Collector 可在不阻塞回答的后台从用户本人原话形成最终记忆文档；用户可查看、编辑、明确保存、暂停、删除，并分别控制继续形成和在回答中使用。
- **前置与数据变化**：依赖 A1 和 N2c；最终记忆单元、来源、状态、适用条件、替代关系和可重建索引保持独立生命周期。A2 与 A3 语义独立，A2 先交付是风险顺序，不是数据依赖。
- **明确不做**：不建立用户可见候选审批队列，不从助手、网页、工具、导入材料、阅读或点击形成个人事实，不保存秘密；敏感内容只有用户明确要求或亲自编辑才可进入。
- **迁移与回滚**：后台处理原子化，失败保留上一稳定结果；回滚停止读取和后台形成但保留用户文档。删除后同一历史来源受抑制，不能自动复活。
- **退出条件**：单次稳定陈述、明确“记住”、重复合并、补充细化、明确纠正、模糊冲突暂停、时间过期、来源删除、遗忘抑制、生成/使用分控、敏感和秘密负例、后台失败与重启恢复均通过自动化及真实模型验收。

### R：可追溯 RAG 的单向证据适配

- **用户可见结果**：当本地知识中存在相关材料时，回答可使用并引用能返回原文位置的证据；索引或检索不可用时如实降级，不影响无 RAG 的正常回答。
- **前置与接口变化**：等待 #125–#128 确认解析资源、稳定文档块、索引/失败/隐私/证据交接和 RAG 自身阶段蓝图；RAG 适配器只把正式证据契约映射成 ADR-0045 的证据候选，保留来源、版本、位置、完整性、授权、健康和失效语义。
- **明确不做**：回答侧不拥有解析、索引、召回或重排，不横向比较不同上游分数，不把联网结果自动摄取，不把现有研究地图语义搜索冒充回答 RAG。
- **迁移与回滚**：适配器可独立关闭；索引由 RAG 侧重建，正文和统一装配不承担索引恢复，也不复制第二份正文。
- **退出条件**：来源权限、删除、重解析、版本失效、定位精度、部分抓取、冲突证据、索引失败和适配器关闭均有证据；RAG 只交付候选，装配层独占采用与预算，最终写作只引用实际参与结论的来源。

学习适应与 RAG 在统一装配之后并行、互不作为对方前置。RAG 尚未准备好时 A1–A3 可以交付；学习适应尚未准备好时 RAG 也可以交付。

### M1：联网来源图片先行

- **用户可见结果**：N3a 稳定后，当前回答实际引用的联网证据图片可以有说明、有来源、可访问地内联；图片失败时正文、说明和来源入口继续可用。
- **前置与数据变化**：依赖 N3a 的正文版本、稳定引用位置和来源身份；按 ADR-0047 使用公网校验、逐跳重定向复验、MIME/字节/像素上限、内容哈希、同源鉴权预览、版本绑定与引用回收。
- **明确不做**：不热链模型 URL，不接受装饰图、普通 Markdown 图片或没有证据记录的图片，不称为“图片回答”，不默认捆绑权利未知的缓存字节导出。
- **迁移与回滚**：缓存可删除并有界重取，删除缓存不删正文；旧版本没有匹配图片时诚实显示不可用，不复用新版本图片。
- **退出条件**：SSRF/DNS/重定向、实际 MIME、下载字节、解码像素、CSP、alt、复杂图表摘要、作者/许可原文、权利未知、链接失效、版本错配、回收与无图降级均通过自动化和浏览器验证。

### M2：导入材料图片等待解析边界

- **用户可见结果**：当受支持的导入材料经正式解析能力提供图片资源时，图片可在相关正文位置以内联说明、来源和可访问替代文本呈现，并在可用时返回原文件页码、区域或块位置；解析或图片失败时，导入正文和阅读路径继续可用。
- **前置与接口/数据变化**：等待 #125 明确解析器提供的图片资源契约、页码/区域/块身份、重解析稳定性和本地部署边界，再把正式资源身份、文档快照/版本、可达到的原文位置与正文版本/稳定位置绑定到 ADR-0047 的来源图片旁路。#120 不反向规定 #125 的输出格式，也不改变正文唯一事实源。
- **明确不做**：不因 M1 已交付而把导入图片记为完成，不在 #120 扩张输入格式、OCR、扫描件或自包含导出范围，也不把解析器临时产物变成第二份正文事实。
- **迁移与回滚**：资源和旁路采用 additive 数据；重解析使旧绑定失效并按 #125 的稳定身份规则重建，原材料删除时清除相应派生资源和缓存，不暗中保留原图片。回滚可关闭图片解析/呈现并保留原文件与正文，不能让旧图片错配到新文档版本。
- **退出条件**：在 #125 批准的输入与运行时范围内，图片提取、原文件来源、页码/区域/块返回、重解析、原材料删除、资源缺失、版本错配、alt/复杂图表摘要、缓存回收和导出边界均有自动化及浏览器证据；失败路径均诚实降级且不影响正文。

## 远期：满足条件后重新裁决一等非文本成果

AI 原创图、解释图或其他非文本成果只有在具备独立生成进度、排序、重试、版本、删除、复制/导出和重启恢复生命周期后，才触发新的产品与架构决策。届时必须另立 ADR，裁决版本化多模态消息协议并检查共享契约、SQLite、SSE、消息版本、引用、搜索、上下文、融合、删除和导出；在此之前不创建统一内容块实施票，不把 Markdown 图片、来源图片或远程链接称为 AI 图片回答。

## 可直接进入实施规划的验收矩阵

| 验收面 | 必须覆盖的正向结果 | 必须覆盖的负向、恢复与回滚结果 |
| --- | --- | --- |
| 正文与 reasoning | 六类生成路径只保存自然 Markdown；供应商可展示摘要与正文分离 | 原始 reasoning 在 API、普通持久化、日志、搜索、上下文、导出和旧版中均不可见；暂停/重试/重启不复活 |
| Markdown 与定位 | 完整文档结构、稳定源码位置、选区/引用/标记/章节/深链/复制同源 | 未闭合流式、危险 HTML/SVG、公式失败、跨空行结构、旧版本缺定位诚实降级；正文逐字不变 |
| 统一上下文装配 | 全部现行模型用途声明用途、候选准入、预算、采用/排除理由和供应商转换 | 权限越界、候选冲突、预算不足、敏感排除、供应商能力不足、无候选和适配器回滚；不得双发或绕过 |
| 旁路增强 | 段落闭合后逐步显示、完成后全篇复核，范围与正文版本匹配 | 增强失败不阻塞正文；暂停保留已验证项，重启重算未完成项，旧版本不借用新旁路，控制串零残留 |
| 个性化与画像 | 可跳过引导、显式画像、回答方式、总/分项/本轮控制和采用类别说明 | 默认中性；系统不推断画像；关闭不等于删除；删除只影响后续；敏感身份与单用户边界 |
| 已掌握知识点 | 正确费曼式复述形成最小成果，相关新知识自然连接 | 错误/遗漏/助手复述/阅读/点击/选区分析/关键词/宽泛标签均拒绝；无评分、衰减或未掌握推断 |
| 长期记忆 | 用户原话形成、来源追溯、合并/细化/纠正/过期/遗忘、生成/使用分控 | 助手/网页/工具/材料不得写入，秘密禁止，敏感内容需明确授权；冲突暂停、失败原子、删除抑制和回滚保留文档 |
| RAG 证据交接 | 证据候选保留来源、版本、位置、完整性、授权和健康；实际采用证据可引用返回 | 来源删除/重解析/索引失败/部分抓取/冲突/适配器关闭诚实降级；不跨来源比较分数、不反向拥有检索 |
| 来源图片 | 实际引用图片经同源预览显示，具备 alt、说明、来源、作者/许可原文和正文摘要 | SSRF、DNS、重定向、MIME、字节/像素、CSP、失效、版本错配、权利未知、缓存删除与无图降级 |
| 远期多模态触发 | 独立生命周期条件全部成立后才进入新决策 | 条件未满足不出票、不改消息协议；未知块和旧字符串正文的降级必须在新 ADR 中裁决 |

涉及共享契约、迁移、跨端事件、数据库或构建配置的实施切片按四级门禁验证；用户可见 Markdown、旁路、个性化与来源图片变化增加相关视口、键盘、读屏、控制台、网络和视觉审阅。真实模型验收按专项规则在其明确触发的切片执行，不能用模型自报替代契约与持久化证据。

## 实施票据边界

- N1、N2a、N2b、N3a、N3b、N3c、A1、A2、A3、R、M1 和 M2 分别是独立候选实施票；N2c 可按模型用途拆成多个纵向实施票，但只有全部现行用途迁移后才满足窗口退出。
- 每张实施票必须重述用户可见结果、原因、目标行为、明确不做、前置依赖、数据一致性、安全/回滚风险和验证命令，不得只引用本 ADR 的编号。
- #129 是已完成前置，不再派票。#125–#128 继续拥有解析、索引、检索、失败与证据契约；#120 只规定它们与回答侧的单向交接和顺序。
- 当前任务只形成决策和实施规划输入，不创建业务实现提交、数据库迁移、共享契约或新实施 Issue；后续规划任务按依赖逐张创建并领取。

## Consequences

- Collector 先稳定回答输入、正文和定位，再让个性化、RAG 和来源图片接入，避免每项能力各自拼提示词或绑定旧空行坐标后重复迁移。
- 学习适应按“控制中心与画像 → 已掌握知识点 → 长期记忆”推进；这是用户确认的风险和产品价值顺序，不表示已掌握知识点与长期记忆存在数据依赖。
- 学习适应、RAG 证据适配和来源图片在“现在”退出后并行，互不写入、互不作为对方前置。
- 当前所有相关能力状态不因本决策升级；只有对应实现、自动化和实际用户路径共同验证后才能变更 `docs/PROJECT.md` 四态能力表。
