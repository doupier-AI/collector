# 流内提及携带回答内实体身份

2026-08-13 确认：模型在生成正文与提及时，同时为每个提及分配只在当前回答内有效、用户不可见的实体身份；同一对象的重复提及共享该身份，同名异义对象使用不同身份。服务端不得再以“类别与规范化文本相同”直接认定同一实体；控制信息格式错误时仍丢标记保正文。跨消息与跨节点边界继续遵守 ADR-0027。

**Why:** 生成阶段拥有完整论述语境，能够在不增加事后模型调用的情况下区分同名异义和别名；每次提及都独立生成预览虽然安全但重复，事后逐项核验则增加延迟与调用成本。

**Consequences:** 回答内实体身份不能跨消息、跨节点或跨正文版本继承；流内控制契约需要同时表达对象类别、回答内实体身份和可见文本，并由服务端校验数量、范围与格式。具体控制串语法属于实施设计，不改变用户可见正文。
