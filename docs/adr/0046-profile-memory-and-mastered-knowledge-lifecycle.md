# 用户画像、长期记忆与已掌握知识点使用独立生命周期

2026-08-24，用户经 #117 确认：Collector 不把全部个性化信息放进同一个“记忆”容器，而是分别管理用户主动维护的**用户画像**、系统从用户原话中形成的**长期记忆**，以及经费曼式复述核验形成的**已掌握知识点**。三者只通过 ADR-0045 的用户适应通道参与回答，不能取得指令权、改变事实标准或代替当前请求；用户提示词继续承担主动控制回答方式的职责。

## 语义归属

| 对象 | 形成者与事实含义 | 作用域与回答作用 |
| --- | --- | --- |
| 用户画像 | 只由用户主动选择、添加、编辑或删除的身份与背景标签；系统不推断、不推荐、不从对话自动补写 | 只属于用户级，用于选择合适的术语、例子和默认背景，不是行为指令 |
| 长期记忆 | 从用户本人明确陈述中形成、没有用户提示词/画像/项目事实/已掌握知识点等更准确归属的可复用个人事实与上下文 | 由用户级拥有，可携带时间和适用条件；只作低权重参考，不建立项目级个人记忆 |
| 已掌握知识点 | 用户围绕明确、稳定的知识事实，用自己的理解完成正确费曼式复述后形成的学习成果 | 只属于用户级，在相关新知识确有准确联系时作为解释锚点；不属于研究节点或研究地图关系 |

同一信息只进入一个最准确的语义归属。用户在对话中提到画像属性不会触发画像写入，也不能绕道进入长期记忆；项目限定的身份、决定和材料继续留在项目指令或事实证据中；外部资料可以帮助核验知识，但不能证明用户已经掌握。当前会话可以临时使用用户本轮明确提供的信息，本轮使用不等于长期化。

## 用户画像

用户画像没有自动形成流程。首次引导可以跳过，用户后续可以直接查看、添加、修改或删除；具体入口与渐进式引导由 #118 决定。保存后即可作为用户适应候选，删除后后续调用立即不再采用。画像不保存回答风格和行为要求；这类主动控制进入用户提示词。系统发现对话中出现可能属于画像的内容时保持安静，既不自动写入，也不生成推荐或待办。

## 长期记忆

### 形成与可见性

自动记忆默认关闭。用户明确开启后，Collector 才可在对话闲置后使用用户选择并授权的 AI 服务做不阻塞当前回答的后台处理；“继续生成新记忆”和“在回答中使用已有记忆”分别控制。关闭生成只停止新的自动处理，关闭使用只停止后续注入并保留现有文档。用户明确说“记住这件事”属于直接保存授权，即使自动生成关闭也可以形成最终记忆，但仍须通过语义归属、敏感性与秘密信息检查。

合格来源只包含用户本人在对话中的明确陈述；一条清楚、稳定且可复用的陈述即可，不要求跨会话重复。相邻助手内容只能帮助消解指代，助手陈述、工具结果、网页、导入材料、阅读或点击行为不能成为用户个人事实。健康、财务等敏感内容不自动保存，只有用户明确要求或亲自编辑时才可进入；密码、令牌、API Key、私钥等秘密始终禁止进入长期记忆。

内部流程使用“用户来源 → 内部整理 → 最终记忆单元 → 用户可见记忆文档 → 可重建检索索引”。内部整理不是产品候选，不形成“待审阅记忆候选”，没有用户可见队列、确认待办或独立生命周期；不确定、来源不合格或处理失败时不形成记忆。后台失败保留上一份稳定结果并可稍后重试，不产生半成品，也不阻塞回答。

用户只管理已经形成的最终记忆文档。文档以自然方式呈现，但内部保持独立记忆单元、来源、状态、适用条件和替代关系；它不是原始提示词文件。用户可以查看、增加、编辑或删除最终记忆，编辑作为新的明确用户来源立即在记忆层生效。编辑属于高级操作，界面提示其可能令后续回答失准，并引导希望调整回答方式的用户改用用户提示词；系统记错仍是产品质量问题，不能转嫁为用户维护责任。写入文档的命令式文字也不能因此取得指令权。

### 合并、矛盾与过时

同一事实重复出现时只增加来源佐证，不复制条目；补充细节时细化原条目；用户在相同范围内明确纠正时，新表述立即支配当前回答，后台以新记忆取代旧记忆；适用范围不同的表述可以并存。系统无法确定两条表述是否真正冲突时，暂停旧记忆且不把新表述固化为长期事实；只有当前任务确实依赖该差异时，才按普通任务澄清，而不是要求用户维护记忆。

有明确时间范围的记忆在范围结束后停止使用；稳定事实不因长时间未重复而自动衰减。只有有效、相关、作用域匹配且未暂停的记忆可以进入本轮装配。用户删除最终记忆后立即停止检索和注入，同一批历史来源不得自动把它重新生成；用户以后重新明确陈述时可以形成新记忆。自动记忆的唯一来源被永久删除后，该记忆失效；存在其他合格来源或用户已经亲自编辑形成独立来源时继续保留。

## 已掌握知识点

已掌握知识点采用严格准入，而不是持续估计掌握程度。用户明确启用学习适应前，“记录已掌握知识点”和“在回答中使用已掌握知识点”均关闭；首次明确启用时两项同时开启，之后可以分别控制。记录关闭时不形成新成果，使用关闭时已有成果不进入回答。

启用后，普通对话中出现完整的费曼式复述即可静默核验，当前 MVP 不主动打断对话发起考试。形成门槛同时要求：对象是明确、稳定且适用范围清楚的知识事实；用户用自己的语言表达了关键含义或关系；复述正确且没有关键遗漏或误解。只说“我懂了”、复述助手原句、阅读或点击内容、说出关键词、猜对一道题、表达个人观点，或只完成部分解释都不形成记录。一轮成功复述即可形成一个最小且可独立复用的概念或关系，不建立“掌握数据库”之类宽泛学科标签。

形成后只存在“已掌握”这一正向事实：没有等级、分数、置信度、未掌握清单、时间衰减、复习周期或因新知识出现而降级。准确记录的适用范围保证更复杂的新知识不会反向推翻原成果。若系统当初误判，按产品质量问题纠正或删除，不增加中间掌握状态。

用户在独立的已掌握知识清单中查看知识点及可用来源并删除，但不能手工新增或改写成“已掌握”，否则会绕过费曼式核验；纠正错误记录后，需要时通过新的正确复述重新形成。删除已掌握知识点后立即停止使用。删除原会话默认不抹掉已经形成的学习成果，清单显示来源已删除且不暗中保留原文；删除入口同时提供清除相关衍生个性化数据的选择。

回答只在已掌握知识点与当前新内容存在准确且有帮助的关系时自然说明连接，例如“你已经理解 A，B 可以从 A 的相反方向理解”。不得机械播报掌握记录、为了展示个性化强行类比，或因清单中没有某知识点就推断用户不懂。关系本身仍须由当前事实证据支持。

## 上下文使用与用户控制

画像、有效长期记忆和已开启使用的已掌握知识点只作为 ADR-0045 的用户适应候选；当前明确要求、用户提示词、事实证据和安全边界继续按各自语义治理。存在个性化注入时，本轮动态运行状态或安全推理摘要可以显示“用户画像、长期记忆、已掌握知识点”等采用类别及安全汇总，不展示隐藏推理、原始系统提示、敏感原文或内部整理过程。

删除画像、记忆或已掌握知识点只影响后续调用，不追溯改写已经生成的正文。所有对象保持本机私有、可查看、可删除和可分别停用；具体页面布局、后台间隔、模型提示、TypeScript 字段、数据库表和检索阈值由实施切片决定。

## Why

画像是用户主动声明，长期记忆是会变化的个人事实，已掌握知识点是经严格验证的稳定学习成果。共享候选审批、置信度或衰减模型会把三种不同责任混在一起：用户被迫替自动记忆做质检，模型推断可能绕过画像控制，稳定学习成果也会被误建成能力评分。分开生命周期后，系统负责自动记忆正确性，用户保留主动控制，学习适应只使用正向且已验证的认知锚点。

[ReMe](https://github.com/agentscope-ai/ReMe) 的来源层、内部整理层、最终记忆层、可重建索引、来源追溯以及创建/佐证/细化/纠错动作证明了分层长期记忆的可行性。Collector 借鉴这些边界，但增加“不形成、暂停、过期和遗忘”，拒绝含义不清时倾向写入、混合助手与外部资料形成用户事实、用户可见候选审批，以及把文件或 ReMe 的 Python 运行时直接引入现有 Node.js/TypeScript 产品；最终记忆文档是用户界面形态，不预设文件系统为唯一内部事实源。

## 与既有 ADR 的关系

- 本决策完成 ADR-0045 留给 #117 的用户画像、长期记忆与知识掌握生命周期，并以“已掌握知识点”取代其中的“知识掌握假设”。
- 用户提示词、三通道治理、任务优先级、预算和本轮上下文说明继续由 ADR-0045 负责。
- #118 继续负责渐进式首次引导、风格与用户控制面的交互组织；#120 负责把已确认蓝图拆成可集成实施阶段。
- 本决策不改变研究节点、正文唯一事实源、可追溯 RAG 或研究地图关系语义，也不把任何个性化对象并入研究地图。

## Consequences

- 后续实施必须为三类对象提供独立契约、来源与删除语义；不得以一张通用 memory 表或一段自由提示词抹平产品边界。
- 长期记忆需要可恢复的后台处理、来源核验、冲突合并、状态与删除抑制；已掌握知识点只需要严格形成核验和正向检索，不需要评分、衰减或复习模型。
- 验收至少覆盖：助手或网页内容不得变成用户事实、画像属性不得绕道写入记忆、明确纠正与模糊冲突、记忆过期和遗忘抑制、敏感与秘密信息、生成/使用分控、费曼式成功与失败样例、宽泛掌握拒绝、已掌握知识的自然连接、来源删除和衍生数据删除。
- 当前代码尚未实现上述能力；文档确认不能作为已实现证据。
