# 生长图谱扶正与手稿阅读面：B+A 视觉方向、彩虹按钮退役、信号绿调色板

2026-08-09 UI 优化方向确认（用户对 ADR-0016 重构后的界面仍不满意：Manus 外壳与彩虹按钮是借来的语言， Collector 自身没有记忆点；阅读面平淡、界面不告诉用户"我在哪"、图谱藏在覆盖层后）。经 A（手稿研究室）/ B（生长图谱）/ C（清晰仪器）三方向讨论，确认以 **B 为主轴、吸收 A 的阅读面质感、C 作为贯穿地基** 的合并方向，在 `ui/refresh` 分支分切片落地。

**决策：**

- **「生长图谱」扶正为全站空间语言（B 主轴）**：研究是生长的知识图谱这一产品本质，从「顶栏按钮后的覆盖层」升级为可见的空间身份。全站唯一奢侈动画给「生长时刻」——显式生长（选区深入研究、弱标记生长、融合确认）创建子节点后，新节点以生长动效入场并给出入跳转口；研究地图画布与节点造型向"活"的方向重设（非本轮全部完成，按切片推进）。彩虹签名按钮（ADR-0016）退役：签名从「开始研究」（每个用户必经的普通动作）移到生长（Collector 独有、最能打动人的动作）；`AiRainbowButton` 组件与 `ChatComposer rainbow` prop 随切片删除。
- **「手稿阅读面」作为正文质感层（A 吸收进 B）**：节点页正文阅读区引入衬线显示字（系统字体栈：Songti SC / Noto Serif CJK / SimSun 兜底，不引网络字体、不加加载成本）用于节标题与会话标题，排印层级拉开；正文容器给更明确的纸面留白与呼吸感，仍遵守「不用厚重卡片打断连续阅读」与「装饰不进入选区文字」的既有约束（IMPLEMENTATION §8/§12）。深色主题下正文阅读区保持浅色阅读面的既定决策（ADR-0016）延续不变。
- **「清晰仪器」作为贯穿地基（C，先行切片）**：先于风格改动修复导航硬伤与位置感——rail 四个设置/工具图标（AI 模型设置/融合设置/运行记录/回收站）从「只展开详情栏」改为真实导航并给当前页激活态；侧栏「内容」标题正名；节点页头部补会话 › 节点位置行；研究地图覆盖层按钮墙收敛为有序工具区。这些是缺陷修复而非风格选择。
- **信号绿调色板**：品牌主色从 `#435A73` 蓝灰改为生长信号绿系（深绿主色 + hover 变体），取自已有的 `--color-difficulty-low` 绿色族谱——从现有体系"生长"出身份，不另起炉灶；深色主题暖金保留、与绿协调；选区黄调同步向绿族谱靠拢。改动集中在 `tokens.css` 令牌层，全局 `color-mix` 引用不逐处改。禁用事项（不引 Tailwind/shadcn/WebGL、不大面积紫色渐变、不泛滥圆角卡片、装饰不污染选区）全部延续。

**Why:** ①产品核心路径终点就是研究地图，"图谱优先导航"是早已确认的产品方向（ADR-0002 统一对话空间、地图只读投影），B 是扶正而非新增；②ADR-0016 的彩虹按钮证明诉求是"呼吸感"而非"更多颜色"，生长动画把呼吸感安在产品最有意义的动作上；③A 的纸面质感与 B 不冲突——正文是手稿、结构是生长，两者共同构成"安静但不平淡"的研究室气质；④rail 图标无响应等硬伤与风格无关，先修后换皮，避免把缺陷带进新视觉。

**Consequences:** 全站视觉变更需重拍受影响像素基线（7 张，win32 + Chromium，按 ADR-0012 纪律单独 `--update-snapshots` 人工审 diff）；建议借机补深色主题基线（当前仅浅色）。`docs/PROJECT.md` 四态能力表「统一视觉系统」证据随切片更新；`apps/web/IMPLEMENTATION.md` §12「不使用大面积紫色渐变」等禁令保留，彩虹按钮相关描述移除。生长动画的 reduced-motion 降级（静态出现，不依赖动画表达状态）为验收必查项。滚动决胜的章节导航（SliceRailNav scrollspy）与侧栏布局耦合脆，任何布局改动须重验章节高亮跟随。
