# 统一对话空间取代聊天/研究双模式

> **部分由 ADR-0022 取代（2026-08-10）**：统一对话空间和“显式生长才创建父子结构”继续有效；“只有显式生长出结构的对话才进入研究地图”不再有效。全部未进入回收站的现存研究节点都属于研究地图的全局数据范围，归档不改变归属；显式生长只决定父子关系。

Collector 曾计划区分"聊天模式"与"研究/学习模式"两个入口。2026-08-03 访谈确认取消该区分，统一为单一对话空间。

**决策：**
- 产品只有一个对话空间，打开即说话，无模式选择入口。
- 弱标记在所有对话中行为一致：显示、悬停预览、可生长子节点。
- 一段对话只有在被用户显式生长出结构（子节点、语义边、融合关系）后才出现在研究地图上；研究地图只是只读投影，生长动作不依赖地图上下文，只需父容器、来源锚点和明确用户动作。
- 不再引入话题守卫、偏题软提示或意图分类器。
- 底层只有一种对话容器与消息模型。

**Why:** 双模式的三条理由全部被更近源头的机制吸收——多轮话题污染由"使用时按需语义筛选"解决；意图识别负担由"保存时少判断、使用时再判断"解决；能力开关差异被用户确认会扰乱心智且无技术必要。当底层机制已覆盖需求时，不保留只剩心智成本的上层概念。

**Considered Options:** 保留显式双入口（曾被确认）——被本决策替代；聊天模式禁用生长能力——拒绝，行为不一致扰乱用户心智，且筛选机制存在后无意义。

**Consequences:** 普通对话是默认状态，研究结构只由显式生长产生；Collector 定位为具备自然普通对话能力的研究与学习工作空间，不是通用 Agent。
