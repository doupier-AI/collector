# 品牌色调色板收敛为 Claude 暖橙/琥珀：选区与标记色协调（ADR-0017 信号绿 supersede）

2026-08-09（#53，#51 UI 反馈收口拆分票 B）。ADR-0017 落地后用户真实使用中反馈：信号绿品牌主色不是用户选择（#51 反馈 #4），且选区文字高亮与标记数量徽标仍残留旧黄色、与新主色不协调（反馈 #3）。本轮把品牌色收敛到**用户选定的 Claude 暖橙/琥珀系**，一次性取代 ADR-0017 的「信号绿调色板」条目。

**决策：**

- **品牌主色 `--color-ai` 由信号绿改为 Claude 暖橙/琥珀**：浅色主色 `#C4532F`（规格目标约 `#C96442`，为在米白画布 `#F5F6F3` 上达到 WCAG AA 普通文本对比度 ~4.8:1 而略压深，规格 `#C96442` 仅 ~3.9:1）、hover 变体 `#A8431F` 更深；深色主题强调色取同族暖橙亮变体 `#EB9464`（近黑外壳上 ~6:1）、hover `#F2AB84`。**废弃深色芽绿 `#6FB08B` 与更早的深色暖金**。
- **选区高亮与标记徽标去旧黄、与暖橙协调**：`--color-selection` 浅色 `#E7D8A6`→`#F6D9BC`、深色 `#5A4E26`→`#7A4530`；`--color-selection-line` 浅色 `#C9B26A`→`#D99268`、深色 `#8A7A3F`→`#B26B45`；`--color-later`（标记徽标）浅色 `#9A6A24`→`#B04A2A`、深色 `#D9A441`→`#E08A63`。深色选区仍作浅色文字底（~3.5:1，与既有深色选区可接受水平一致）。
- **改动集中在 `tokens.css` 令牌层**：品牌色/选区/徽标色全部经 `var()` 消费（118 处），`--color-ai` 同时喂给 `--ring-focus`/`--ring-locate` 别名，下游 `color-mix` 引用与全部消费点随令牌自动更新，不逐处改；正文浅色阅读面令牌 `--color-reading-ai` 同步暖橙（深色阅读面内链接协调）。不引网络字体、不动结构。
- **保留事项**：`--color-on-ai` 保持 `#FFFFFF`（白字压暖橙主色按钮，深浅两主题）；`--color-difficulty-*` 难度色与 `--color-edge-*` 网状图边色不随品牌色改动（各自承担独立语义，非品牌表达）；深色主题「正文阅读区保持浅色阅读面」既定设计（ADR-0016/0017）不受影响，仅其内链接色 `--color-reading-ai` 协调。

**supersedes：** ADR-0017 的「信号绿调色板」条目（浅色 `#35604A` / 深色 `#6FB08B` 及配套选区黄调）。ADR-0017 其余决策（生长图谱 B 主轴、手稿阅读面 A 吸收、清晰仪器 C、彩虹按钮退役让给生长时刻、衬线显示字、rail 真实导航）**不受影响、继续有效**。

**Why:** ①品牌色是用户身份认同的核心表达，用户明确选定暖橙/琥珀而非被强加的绿色（#51 反馈 #4「我想让品牌主色是我认可的 Claude 暖橙/琥珀」）；②选区/徽标残留旧黄与新主色冲突，破坏视觉一致性（反馈 #3）；③沿用 ADR-0012 令牌层唯一来源架构，改动零散落硬编码、可单点回滚。

**Consequences:** 全站链接、按钮、当前节点圆点、研究地图选中态、选区高亮、标记徽标、焦点环/定位光环均为暖橙协调色系。受影响像素基线按 ADR-0012 纪律 `--update-snapshots all` 强制重拍并人工逐张审 diff：8 张中 6 张因帧内品牌色元素（Collector 圆点、来源条边框、章节导航激活态、地图选中环/当前行、深色强调色）超出 1% 容差而更新为暖橙，其余 2 张（slice-card 常态/悬停特写）帧内无品牌色、逐字节不变（防自证基线：默认 `--update-snapshots` 仅更新超容差帧，对品牌色这类小面积局部变更会漏更新，故本变更用 `all` 强制全拍）。`docs/PROJECT.md` 四态能力表「统一视觉系统」证据、`apps/web/IMPLEMENTATION.md` §4.3/§11 同步更新；ADR-0017 信号绿条目标注被本 ADR 取代。难度色与图边色保持不变属既有语义，不在本轮调整。
