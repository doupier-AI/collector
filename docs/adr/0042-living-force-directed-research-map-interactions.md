# 研究地图采用活体力导向交互、自然聚拢、微曲线与显示层入场

2026-08-22 用户确认。研究地图需要从“节点被单独移动、邻居一次性结算、专注节点排成规则圆环”的机械反馈，升级为接近 Obsidian / graphify 的柔性图谱：拖动会搅动相连区域，松手后可见回弹并自然稳定；专注时支撑关系自然聚拢；连线保持轻微曲率；首次打开和新增节点柔性展开。

## 决策

- **拖动使用逐帧局部力导向**：被拖节点固定跟随指针，参与节点保存位置与速度；连线以拖动开始时的边长作为弹簧静止长度，近距离节点互相排斥，速度经阻尼积分并限制单帧位移。一、二、三跳关系节点响应逐级衰减；松手后每个 `requestAnimationFrame` 只推进一步，直到动能低于阈值或达到约 240 帧上限，再把位移超过阈值的关系节点和无关系被动节点写入当前 Map Scene。reduced-motion 与 Shift+方向键微调使用同一模型同步结算，Esc 取消本次交互产生的全部位移。
- **附近无关系节点是被动碰撞体**：每次交互先为最多 180 个关系传播节点建立确定性空间网格，再动态纳入距任一参与节点 128 世界单位内、最多 60 个与当前关系子图没有直接边的节点，总参与量不超过 240。节点即使在另一个关系簇中有边，只要与本次子图无边仍可作为被动碰撞体；当前子图因预算被截掉的直接邻居不会被错误降级。被动节点只受 64 世界单位内的近距离斥力、惯性和阻尼，不建立弹簧，力强约为直接关系节点的 70%，并可在稳定过程中继续推动其他被动节点；这种物理接触绝不创建关系事实。
- **影响范围按规模自动收窄**：默认模拟三跳 BFS 子图；关系节点超过 180 时依次尝试二跳、一跳，以更小的局部响应换取大图交互流畅。关系传播与被动碰撞共用 240 节点总预算。范围收窄只影响一次交互的物理传播，不改变图谱的数据范围、关系事实或未参与节点的持久坐标。
- **专注使用自然聚拢**：焦点保持固定，直接关系节点受朝焦点的距离带弹簧与节点间斥力逐帧演化，形成不规则、有间距的有机环簇，不再使用等半径、等角度规则圆环。聚拢仍属于显示层临时编排；退出专注约 300ms 复原，不写入持久坐标。
- **连线与入场属于稳定显示语法**：全部永久关系主线、方向流动线和 reduced-motion 静态方向线使用按边 ID 确定弯曲方向的轻微二次曲线。首次挂载与之后新增的节点从自身持久坐标附近、按节点 ID 确定的方向柔性展开约 350ms；入场动画只改变显示坐标，并向自动化验收暴露完成状态，不进入 Map Scene。

非交互路径（筛选、关系开关、专注切换）继续不得重排持久坐标；缩放平移、点击抑制、pointer capture、双击/Enter 打开和既有键盘导航保持不变。实现继续使用项目内纯函数模块，不引入第三方物理库。

本决策取代 ADR-0041 的“规则圆环编排”“一跳锚点传导”和“松手后一帧有界结算”条款；ADR-0041 关于三层坐标、预览不持久化、主动拖动/键盘移动是持久坐标合法来源、Esc 取消和非交互路径稳定的条款继续有效。本决策同时结束 ADR-0041 中“连线曲线化未实施”的状态。

## Why

一次性平移和规则圆环能让局部关系变清楚，却无法传达图结构本身的弹性，也会让专注状态显得像固定排版。局部、确定性的逐帧力场可以保留空间记忆和 Map Scene 恢复能力，同时让用户的直接操作产生连续、可理解的结构反馈。按跳数、空间距离与总量预算限制参与范围，可以让相邻但尚无关系的节点产生可信接触，同时把动画成本约束在当前交互附近，无需把整图重新布局或后台常驻模拟。

## Consequences

- `mapInteractions.ts` 负责确定性的 BFS 选区、空间网格被动节点发现、弹簧/斥力/阻尼步进、同步结算、聚拢、入场起点与曲线路径；React 组件只负责 rAF 调度、显示层合成和最终提交。
- 地图继续使用持久层、交互层、编排层三类坐标；入场是额外的显示过渡，序列化仍只读取持久层。
- 拖动会合法持久化多个关系节点和被动碰撞节点，测试不得再假设一次拖动只改变被拖节点；测试同时证明被动位移不增加关系，专注和入场不污染 Map Scene。
- 大图性能首先由 BFS 自动收窄和参与子图快照控制。只有代表性浏览器测量证明 SVG 全节点逐帧渲染仍是瓶颈时，才进一步拆分或 memo 节点渲染。
