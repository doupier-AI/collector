# 丰富 Markdown、来源图片与远期图片回答分阶段演进

2026-08-24，用户经 #119 确认：Collector 近期继续以一个自然 Markdown 字符串作为正文唯一可读事实源，分别补齐**丰富 Markdown**和**来源图片**；AI 原创图、解释图等一等非文本成果等到拥有独立生命周期时，再单独裁决版本化多模态消息协议。当前阶段不得把 Markdown 图片语法、远程图片链接或来源图片称为“图片回答”。本次决策任务不修改代码、共享契约、数据库或用户界面；后续来源图片旁路增强可以在不改变字符串正文事实源与正文流式语义的前提下新增独立存储和接口，具体形态由实施切片决定。

## 丰富 Markdown

一条消息按一份完整 Markdown 文档解析。标题、段落、强调、引用、普通列表、只读任务列表、链接、GFM 表格、行内代码、围栏代码、分隔线，以及 `$…$` / `$$…$$` TeX 公式扩展，都属于同一正文的阅读表达，不成为独立内容块。段落身份、旁路增强、选区、弱标记、引用和导航所需的位置从同一棵语法树及其源码位置派生；不得先按空行把正文拆成若干互不相干的 Markdown 文档。

表格只在自身容器内横向滚动。代码永不执行，未知语言按纯文本显示。公式在本机以不信任输入的模式排版，禁止可信命令，并设置和验证输入、展开次数、渲染尺寸与处理资源上限，具体数值由实施量测；同时保留可复制 TeX 与可访问 MathML，解析失败时原样显示公式文本。raw HTML、MDX、脚本、iframe、主动嵌入、模型给出的 `data:` 图片和可执行 SVG 保持禁用。实现完成前必须验证窄屏、200% 缩放、键盘和读屏、选区、弱标记、引用高亮、复制、流式未闭合结构与重启恢复。

## 来源图片

只有两类图片有资格成为内联候选：用户导入材料经独立解析能力提供的图片资源，或当前回答实际引用的联网证据图片。普通 Markdown 中出现的图片 URL、模型声称相关但没有证据记录的图片，以及装饰性填充图均不具备资格。#119 不交付导入图片提取；该能力等待 #122 的基准验证、#125 的解析边界裁决及后续实施，本决策不规定解析器输出格式。

来源图片通过绑定正文版本、稳定正文位置和来源记录的来源图片旁路增强展示。正文必须在没有图片时仍可独立阅读；图片获取、缓存或呈现失败只移除增强，不改写、不阻塞正文，也不能把整条回答变成失败。旧正文版本没有自己的匹配媒体时，显示说明、来源入口和诚实的不可用状态，不复用新版本图片。

浏览器不直接请求模型给出的外部图片地址。Collector 本机服务只以公开、无 Cookie、无认证头的方式获取候选资源，并验证公网地址、DNS 结果、每次重定向、实际 MIME、下载字节和解码像素上限；初期只接受 PNG、JPEG 与 WebP。来源图片预览经同源鉴权提供；生产 CSP 继续拒绝第三方网络图片，模型提供的 `data:` 图片仍不具备展示资格。预览按内容哈希去重，绑定正文版本与来源；最后一个引用删除后可回收，缓存损坏或原链接失效只做有界重取，最终失败则回到文字说明与来源入口。

每张来源图片必须有描述其信息价值的替代文本、可见说明和来源入口；复杂图表还要在邻近正文中提供可理解的文字摘要，图片不得成为结论的唯一载体。记录原始图片 URL、来源页面、抓取时间、能够发现的作者与许可原文，以及权利已知或未知状态；未发现许可不能推断为可自由使用。权利未知时可以在本机阅读，但现行消息复制以及未来若提供的普通 Markdown 导出，只保留正文、替代文本、说明、来源与权利状态，默认不捆绑联网缓存字节。用户原始导入文件中的图片和自包含导出另行决定。

## 远期图片回答与多模态协议触发条件

只有当 AI 原创图、解释图或其他非文本成果成为一等回答结果，并具备独立的生成进度、排序、重试、版本、删除、复制或导出以及重启恢复语义时，才启动多模态消息协议决策。届时至少需要可辨别的 Markdown 与图片资产类型；二进制只通过资产身份引用，不写入 Markdown URL，也不通过 SSE 传 Base64。供应商格式只在适配器层归一化；旧字符串正文具有确定性文本投影，不能与内容块双写成两个事实源；未知块必须诚实降级，不能令整条回答消失。

该远期变化会同时影响共享契约、SQLite、流式事件、消息与正文版本、引用、搜索、上下文、融合、删除和导出，必须另立 ADR、迁移、架构复审并通过四级门禁。本决策不实现导入图片提取、AI 图片生成或统一内容块。

## Why

选择“Markdown 正文 + 来源图片旁路增强”，是为了在保留正文、定位、搜索、引用和恢复不变量的同时提供可追溯图片。只显示图片链接最安全且成本最低，但链接失效、离线阅读和证据理解较差；现在迁移统一内容块会同时冲击几乎所有正文消费者，而当前尚无一等非文本成果支撑这项成本。直接放宽 CSP 热链任意远程图片不属于可接受方案，因为它会产生第三方请求、追踪、链接替换、签名 URL 失效和来源不可证明等问题。

#119 的隔离原型证明底层解析器能产生标题、列表、GFM 表格和围栏代码，危险 URL 与原始脚本会被清洗；也证明现行“先按空行分块、再逐块解析”的路径会破坏含空行的围栏代码和松散列表。原型生成的 HTTPS `<img>` 仍会被生产 CSP `img-src 'self' data:` 阻断，且公式仍是字面文本，因此这些证据只证明边界和缺口，不证明产品已经实现。完整研究、风险和替代方案见 [#119 决策包](https://github.com/doupier-AI/collector/issues/119#issuecomment-5387851525)，可复现探针见提交 [`a529f4f`](https://github.com/doupier-AI/collector/commit/a529f4ff0067a076f9b25dd96c3a9a229cc03a89)。

本决策 extends ADR-0044 的自然 Markdown 正文与旁路增强边界，不改变 ADR-0045 / ADR-0046 的上下文装配和用户适应语义，也不改变正文唯一事实源。当前代码、共享契约、数据库和用户界面尚未实现本决策，必须继续标为“未实现”。
