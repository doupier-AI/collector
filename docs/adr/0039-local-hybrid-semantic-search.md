# 跨会话搜索使用本地双档 BGE、混合召回与诚实关键词降级

2026-08-20 用户确认。Collector 的跨会话搜索需要支持“记得含义、不记得原词”，同时除内容生成大模型 API 外不产生第三方模型调用费，因此语义特征、本地重排和索引都在用户设备上运行。

## 决策

- 搜索事实源包含节点标题、用户提问、已完成的当前 AI 正文、导入正文与正式融合正文；各字段保持独立身份。回收站、历史重新生成版本以及 streaming、paused、stopped、failed 等未完成 AI 正文不进入普通索引。
- 语义召回与本地关键词召回合并后按节点归并；同一节点只显示一次，相关搜索单元作为命中范围保留稳定原文定位。范围内结果正常突出，范围外结果单独分组或弱化。
- 标准档使用 BGE-M3 与 bge-reranker-v2-m3；轻量档使用 bge-small-zh-v1.5 且不执行 Rerank。资源不足、模型缺失或失败不得静默换档。
- 模型免费开源并在本机运行。安装包不捆绑模型，启动和首次搜索不自动下载；用户在独立语义搜索设置中查看体积与资源说明后，显式下载并启用。下载支持进度、取消、重试、固定 revision 与哈希校验、删除。
- 模型或完整匹配的向量索引不可用时，搜索仍可明确降级为纯关键词，并提示意思相近但用词不同的内容可能找不到。残缺、过期或 embedding key 不匹配的向量不得参与搜索。
- embedding 模型、revision、tokenizer、pooling、量化格式、维度或索引格式变化后，新 generation 在后台完整重建并原子激活；半成品不得对查询可见。
- 聊天/研究内容生成模型配置不承担语义搜索能力。未来平台化可以为同一内部推理接缝增加自建服务适配，但多租户、订阅、云部署与容量设计不属于 #67。

## Why

纯关键词搜索无法完成已确认的语义目标；付费 Embedding/Rerank API 又违反成本边界。把本地推理封装为独立搜索模块，可让桌面版免费运行，也让未来平台在不改搜索产品契约的前提下迁移到自建推理服务。

数 GB 模型若在首次搜索时自动下载，会造成不可解释的等待、流量和磁盘占用。显式下载让用户理解成本；明确的关键词降级则保证模型未就绪时仍有基本搜索能力，又不把受限结果伪装成完整语义搜索。

## Consequences

正式自动化使用确定性推理替身，不在 gate 中下载真实模型；真实 BGE 由独立探针验证 Windows x64、Node 24、固定模型资产、效果、耗时和峰值内存。生产推理使用 `@huggingface/transformers` 的 Node/ONNX 路径并禁止远程模型回退；标准档固定为量化 BGE-M3 与量化 bge-reranker-v2-m3，轻量档固定为 bge-small-zh-v1.5。每份资产清单固定仓库 revision、字节数与 SHA-256，完整清单以 `apps/api/src/semantic-search/model-manifests.ts` 为唯一技术事实源。

SQLite 保存关键词索引、向量、模型安装状态、索引 generation 与可恢复任务。索引投影只保存派生搜索单元与定位，不取得正文事实权；完整 generation 原子激活，失败或退役 generation 同步清理。推理以隔离子进程顺序执行，避免标准档 embedding 与 rerank 同时常驻放大内存峰值。不引入付费向量数据库、付费 Embedding/Rerank API 或第二套 Python 应用栈。
