# 生成控制与思考体验：思考开关、思考过程展示、暂停/继续/停止与消息操作

2026-08-19 用户确认。触发：用户报告 AI 回答「一次性全部出现」，违背 ADR-0009 的逐字流式用户可见结果。诊断实测：deepseek-v4-flash 思考模式默认开启（网关 `thinking ?? true`，Resolver 不传 thinking），弱标记指令下推理不收敛——132 秒思考耗尽 16000 token 预算、正文 0 字（finish_reason=length）；用户实际提问等待 3 分 16 秒才见第一个字，随后 7 秒内正文一次性刷完。关闭思考后同问 0.8 秒开始逐字输出、正文完整。

**决策：**

- **思考模式默认关闭 + 用户开关**：所有用户可见生成路径（普通回答、长文、深入研究、联网回答）默认不开启思考；模型设置每个配置提供「深度思考」开关（默认关闭，持久化）。融合路径维持固定关闭（#86）。仅 deepseek（`thinkingMode: "deepseek"`）发送 thinking 参数，其他供应商零影响。
- **思考过程流式展示且完成后可回看**：开关开启时，思考内容（reasoning）同样逐字流式——回答上方默认折叠的思考区，点击展开实时显示；回答完成后折叠区保留，思考内容随消息持久化，刷新后可回看。思考内容与正文分开存储，不进入正文与弱标记清洗管线。
- **暂停/继续/停止**：生成中可暂停（AbortController 中止 provider 流，已生成正文与断点保留）、继续（复用 streamCheckpoint/resumeFrom 断点续传）、停止（终态 stopped，不自动重试）。任务状态扩展 paused/stopped。
- **重新生成保留旧版、左右箭头切换**：同一问题重新生成，旧回答保留为历史版本，回答旁一左一右箭头切换查看（仅重新生成场景提供）。**重新编辑直接替换**：修改已发送问题后生成，新回答替换旧回答，不保留旧版（用户裁决：编辑后生成不支持查看旧版本）。
- **复制**：AI 回答一键复制为纯文本（推荐值，实施前确认）。

**Why:** 用户可见结果——提问后立即逐字生长（默认路径不再有思考期空窗），想深度思考的用户可自行开启并看见思考过程；生成过程可控（暂停/继续/停止）；回答可复制、可重新生成、问题可修改重问。

**Consequences:** 传输契约扩展 reasoning 增量事件（provider → 网关 → 任务事件/SSE → 前端）；思考内容持久化带来存储增量；消息版本是新的数据模型概念，需 SQLite 迁移与迁移重放链通过；暂停/继续依赖 #38 既有断点机制（ADR-0010 有界可靠规则不变）。默认关闭思考改变模型行为——弱标记密度与去重规则（#86/ADR-0031）的真实验收在关闭思考的默认路径上重新验证。实施按 #100 父规格与 #101（T01 思考开关与展示）、#102（T02 暂停/继续/停止）、#103（T03 消息操作）执行；T01 含流式失效修复，先行。
