# 弱标记流式期间即可交互，生长来源锚定实际点击的提及

2026-08-14 确认：弱标记在回答流式生成期间（消息尚未 completed）即可交互——悬停沿用约 400ms 意图确认启动预览，首次点击记录生长意图、等待同一份预览完成后直接创建子节点，不要求等待整篇回答结束。服务端同步放开"只有 completed 消息才能启动预览"的限制；失败消息仍不提供标记与预览入口。同一对象在节点内多条回答中被提及、预览跨消息复用时，点击生长出的子节点来源锚点指向用户实际点击的那次提及，而不是预览最初生成时的首次提及；未提供点击提及的旧客户端回落为预览原始锚点。

**Why:** 标记随流显示的初衷是"不必等待整篇回答结束"；可见但悬停无响应的标记是可交互假象，属于误导性体验。提及闭合后正文只往后追加，其上下文已经固定，流式启动预览不牺牲解释质量。来源返回应回到用户当时阅读并操作的位置，首次提及可能是用户从未读过的位置。

**Consequences:** 预览与生长的提及校验接受流式中与已完成消息，拒绝失败消息；流式中正文持续重渲染会替换标记元素，交互层需按数据属性重新解析弹层锚点，解析失败诚实关闭弹层。生长请求可携带点击提及，服务端校验其为该消息真实弱标记且与预览同文同类后，按锚点复用或新建来源选区；生长幂等仍以预览为粒度（`term-growth:{previewId}` 与来源选区双重防重），快速重复操作不产生多个子节点。预览跨消息复用的实体核验边界不变（ADR-0027），回答内身份规则不变（ADR-0028）。
