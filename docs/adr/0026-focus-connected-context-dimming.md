# 专注模式保持全局布局，以完整连通脉络着色并将其余图谱置灰

ADR-0022 曾把专注模式定义为以焦点节点的完整后代生长树为主体、祖先与来源分层展开的独立查询。继续讨论视觉目标后，用户明确选择在同一张全局地图上直接聚焦节点：保留空间位置，通过明度与色彩区分当前完整脉络和其余知识。专注模式因此不再拥有独立树形布局，也不把祖先、后代或融合来源拆成不同空间层。

## 决策

- **点选即进入专注。** 用户在 A 面点选节点，或直接打开 `/map/focus/:nodeId`，都以该节点作为当前观察中心；两条路径产生同一种专注状态。
- **完整连通脉络保持正常。** 从焦点节点出发，沿当前启用的永久关系类型能够到达的全部节点和连线保持正常色彩与可读强度，不设置用户可见的层数或距离上限。父子关系与融合来源可以共同组成路径；连通判断允许从关系两端进入，关系方向仍解释“谁生长出谁”和“谁支撑了谁”。
- **未连通区域保留并置灰。** 不属于当前连通脉络的节点和连线继续留在原位置并保持可交互，但统一降低明度和饱和度成为灰色背景；焦点节点最突出。用户可以直接点选灰色节点，把它设为新的观察中心。
- **专注不重新布局。** 进入、切换或退出专注只改变视觉强调，不重新排列节点，不强制把焦点拉到画布中心，也不改变缩放和平移。生长树通过父子关系的结构、方向和当前路径强调表达，不通过另一张树形画布表达。
- **关系筛选重新计算专注范围。** 改变父子或融合来源筛选后，以启用的关系重新计算完整连通脉络，但不重新布局。所有永久关系都关闭时，只保留焦点节点正常突出，其余图谱置灰。选中融合节点时，直接来源只有在“融合来源”关系启用时进入正常脉络；筛选范围仍不得截断已启用关系所需的跨范围桥接节点。
- **置灰不是状态语义。** 灰色只表达“当前不在专注脉络中”，不能单独表达归档、来源暂不可用、来源不完整或键盘焦点。形状、标识、文字、读屏名称和焦点环继续承担这些状态，减少动态效果时使用静态方向渐变和文字说明。

## Why

用户需要在不丢失全局方位的前提下看清某个节点的全部关系，而不是在全局图和树形专注图之间重新学习两套空间。保留所有节点并弱化非连通区域，可以同时提供上下文和焦点；稳定坐标让用户沿节点连续探索时形成空间记忆。父子方向继续展示生长路径，但不再强迫所有关系适配树形排版。

## 与既有 ADR 的关系

- 本 ADR 修订 ADR-0022 的专注模式定义，取代“完整后代生长树为主体、祖先路径与直接来源分层展开”的查询和布局语义。
- 本 ADR 保留 ADR-0022 的统一观察系统、完整连通脉络、稳定地址、范围外桥接节点和关系方向语义。
- 本 ADR 不改变 ADR-0023 的临时关联提示，也不改变 ADR-0024/0025 的 A/B 面、临时融合节点、原位确认和正式成果固定规则。B 面仍是独立审查状态；本 ADR 描述 A 面的节点专注。

## Consequences

统一观察结果需要为每个节点和连接明确计算“焦点 / 当前连通 / 未连通背景”，画布、窄屏列表、键盘导航和深链必须消费同一结果。当前按 `maxDepth` 截断的会话内投影、同心圆布局和独立专注脉络呈现均需迁移。专注视觉必须验证浅色、深色、320/1024/1440 视口、键盘、读屏与减少动态效果，且选择节点前后已有位置不得整体跳变。
