# 实体预览只在节点内复用

2026-08-13 确认：同一稳定回答内的重复提及直接共享一份实体预览；同一节点的不同消息中，只有模型根据双方各不超过 600 字的局部语境核验为同一对象后才共享。模型不可用、核验失败或结论不确定时均不复用。不同节点即使出现同名实体，也始终结合新节点的会话、父链与当前内容重新生成预览，不读取或沿用其他节点的预览。

**Why:** 节点代表一次独立生长后的研究语境。节点内复用能减少重复生成并保持解释一致；跨节点复用则会抹平研究路径带来的语义差异，使一份在旧语境中正确的解释被错误带入新论述。局部语境核验只在用户触发预览时发生，且只发送完成判定所需的最小文本。

**Consequences:** 服务端以节点作为预览复用的最外层边界；文本相同本身不构成同一实体。预览文字的自然长短由当前解释需求决定，节点深度只通过内容收敛间接影响解释所需篇幅，不按深度机械截短。
