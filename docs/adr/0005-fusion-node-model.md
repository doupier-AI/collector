# 融合节点关系模型

2026-08-03 访谈确认融合节点的领域模型与触发策略。

**决策：**
- 融合节点是独立新增的研究节点，通过 `fused-from` 类型化边连接各来源节点；不改写来源节点内容、父子血统或既有语义边；融合纯增量。
- 最低结构 = 共同核心 + 来源差异 + 增量综合 + 可回溯依据（来源语义范围引用）。
- 无增量综合价值时不创建融合节点，只保留 `semantic-related` 边。
- 确认触发与自动触发复用同一融合契约，只是触发策略不同；自动融合默认关闭、只处理开启后新提议、低置信度回退为逐条确认、全程留痕。
- 融合撤销采用软撤回，不物理删除历史。

**Why:** 用户需要可追溯的综合结果，同时不能因融合而丢失原始学习路径；软撤回保证关系历史可审计。

**Consequences:** #31（确认式融合）与 #32（自动融合）共享同一实现契约，#32 在 #31 验证后开启；融合节点内容引用的是来源语义范围而非整节点，来源核验在融合触发时执行。
