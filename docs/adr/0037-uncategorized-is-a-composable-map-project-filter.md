# “未分类”是可组合的研究地图项目筛选项

2026-08-20 用户确认。

## 决策

- 研究地图的项目筛选把“未分类”作为一个可单独选择、也可与一个或多个真实项目组合的筛选项。
- 默认“全部项目”同时包含所有真实项目和未分类节点。
- “未分类”仍表示会话没有项目归属，不因此创建隐藏项目、项目记录或项目颜色；界面继续使用中性视觉。
- 只选择“未分类”时，当前范围只命中未归入项目的节点；同时选择真实项目和“未分类”时，两者按并集命中。
- 项目筛选只改变当前观察结果。范围外永久关系仍按 ADR-0022/0026 的边界与桥接规则诚实保留，不修改节点或会话归属。

## Why

用户需要专门查看尚未整理进项目的研究内容，也需要把这些内容与选定项目放在同一观察范围比较。如果“未分类”只被隐含在“全部项目”里，用户无法单独整理这部分内容；如果把它伪装成真实项目，则会引入不存在的项目身份和颜色事实。

## Consequences

统一观察输入必须能区分“没有项目过滤”和“明确包含未分类”，不能继续用空 `projectIds` 同时表达两种意思。项目列表、桌面画布、窄屏列表、键盘候选和现场恢复都消费同一个组合条件。无需 SQLite schema migration，也不得创建名为“未分类”的项目记录。
