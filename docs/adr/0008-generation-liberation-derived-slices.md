# 生成自由化：正文唯一事实源 + 确定性事后切片 + plan-then-write 长文架构

2026-08-04 用户确认：研究正文不再由模型一次性返回 `{"slices":[…]}` JSON 切片合成，改为"模型自由写连续正文，结构由确定性规则与小模型事后派生"。这是 ADR-0004"生成时输出完整语义切片不作为必经环节"在生成端的落地，完成正文唯一事实源迁移（#34–#39）。

**决策：**
- **生成自由化**：模型只产出连续 markdown 正文，不返回任何 JSON 切片结构、不拆切片。正文是唯一事实源。旧契约（模型返回 `slices[]` 并校验 `content===切片拼接`、片=段落块 1:1、禁片内空行）彻底移除，不留兼容路径。
- **确定性事后切片**：结构边界由 `deriveMessageBlocks`（唯一确定性切块规则，按空行段落）事后派生；派生切片落库供语义卡片、章节导航、融合（粗筛一级信号 + 来源核验）、生成上下文注入统一消费。这些功能只依赖"有切分边界"，不依赖"模型拆片"。
- **小模型事后标注**：每块标题/概念由单独配置的事后抽取模型在正文定稿后抽取（temperature=0，并发上限 4，单块失败降级为空标注），绝不影响正文与任务完成；标题可为空，空标题卡片只显正文（aria-label 退回正文摘要）。
- **plan-then-write 长文架构**：按预期长度自动判断（默认单轮自由写）。判定为长文（深入研究、显式长文指令、或预期 ≥ 2000 字）时先出 3–12 节有界大纲，再逐节串行扩写、逐节增量落正文；`bodyPlan` 持久化于任务 record_json，支持断点续扩（重试时已完成节不调模型秒级重建，从首个未完成节继续）；单节失败重试后判任务失败，已落部分保留。
- **`isProvisional` 语义重定义**：保留字段，新派生切片恒写 `false`；历史临时切片在新过滤下仍不显示卡片（与迁移前一致、无回归），物理删列另排。历史 provisional 数据不动，重派生另排。
- **grounding 失败**：维持判任务失败（输入保留可重试；agent 循环 throw 时无正文可落，部分结果带回属另一任务）。

**Why:** 实测与调研（arXiv:2408.02442《Let Me Speak Freely》等）共同证明：旧切片协议在"长文创作 + 逐片嵌套 schema + 每片多字段 + 片数上限"场景下压垮内容质量——用户要 1 万字实得约 2500 字、内容碎片化像短段落堆叠。机制有三：①切片协议把"语义单元"与"物理段落"锁成 1:1 且禁片内空行，逼模型写孤立单段；②生成期 JSON 包装 + thinking 共享 token 预算吃掉正文额度；③模型固有"默认短文墙"（单轮约 2000 字软上限）。结构化约束对"自由创作"有害、对"数据提取"有益，故正文走自由文本、大纲与事后标注走 JSON。

**Consequences:** 不再要求 `content === 模型切片拼接`；改为"正文唯一事实源，派生切片 = `deriveMessageBlocks(正文)` 段落块 + 事后注入的标题/概念"。传输层 `responseFormat` 改为可选、补 `temperature` 字段。长文能力通过 plan-then-write 突破单轮短文墙，支持 5000–10000+ 字。`RESEARCH_SLICE_PROMPT_VERSION` 语义随生成方式升级。GitHub #36–#39 中契约变化的子票据标 `needs-rebase`；#38 在 ADR-0004 质量检查退役后本就需重写，本次旧契约移除进一步确认其"只做契约安全解析"的方向已随契约移除而收敛。融合粗筛一级信号（normalizedConcepts）由小模型事后填充维持，空时回退术语/分词。

**决策纪律：** 卡片渲染/章节导航锚点与块对齐必须由共享派生（`deriveSliceCardTargets`）单一事实源产出，禁止渲染层与导航层各自手工对齐——两份独立计算不一致即点选漂移。
