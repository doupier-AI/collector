# 全局研究图谱采用沉浸式视口与边缘工具坞

2026-08-22 用户确认。稳定全局图谱已经承担跨会话观察、搜索、筛选、关系切换、专注与空间整理；把它继续放在普通页面顶栏和常驻侧栏之间会压缩画布，窄屏尤其难以操作。点选节点进入专注时，旧实现还会在新观察请求期间卸载画布并显示整页加载骨架，浏览器因此把文档滚动位置重置到顶部，随后重新播放入场动画。

## 决策

- **两个全局图谱路由独占浏览器视口**：`/map` 与 `/map/focus/:nodeId` 隐藏普通顶栏和侧栏，主区域固定为 `100dvh`，文档本身不滚动。加载、空态和错误态使用同一沉浸框架。它们是 ADR-0021“左侧栏常驻”的明确路由例外；节点页既有 `t`/`g` 研究地图覆盖层和其他产品页面不变。
- **功能收进始终可见的边缘工具坞**：桌面左侧竖向排列返回、搜索、筛选、关系、新建会话和更多；窄屏改为底部工具坞，并额外提供画布/列表临时切换。搜索、筛选、关系和更多面板一次只打开一个，以悬浮层覆盖画布而不改变地图尺寸、世界坐标或 Map Scene；重复点击、点击空画布和 Esc 关闭并恢复触发按钮焦点，直接操作节点或地图控件时关闭面板但保留操作目标焦点。所有图标保留可访问名称、键盘焦点、提示和低干扰状态标记。
- **窄屏默认显示可拖拽画布**：列表是当前打开期间的临时呈现选择，不跨刷新保存。搜索定位后关闭面板并聚焦目标；筛选和关系即时生效且面板保持打开；更多面板提供回收站、运行记录、设置、主题与地图操作说明。工具打开状态与画布/列表选择均不进入 Map Scene 或 localStorage。
- **专注导航保持同一画布实例**：点选节点发起专注请求时继续显示当前观察，只在局部显示更新状态；请求完成后更新地址与观察结果，不切换整页骨架、不重挂载画布、不重播入场。专注 PUSH、浏览器前进/后退和正文返回继续为每个 history entry 恢复各自 Map Scene，并在同一画布实例中显式更新现场。
- **返回遵循真实来源**：返回按钮优先使用当前浏览历史；没有可返回来源时进入会话首页。新建会话继续直接进入 `/research/new`。

## Why

图谱的主要工作对象是空间本身，常驻导航在这里占用的面积大于它提供的价值。沉浸式视口让画布、缩放与物理反馈得到完整空间，边缘工具仍保持可发现且不遮蔽大部分关系。保持画布 DOM 常驻同时修复跳顶、白屏和入场重播，也使 history entry 的现场恢复与用户看到的连续空间一致。

## Consequences

- `AppShell` 只按这两个精确路由启用沉浸模式；普通页面继续遵守 ADR-0021。
- `ResearchMapLandingPage` 负责临时工具状态、响应式工具坞和局部加载反馈；`GlobalResearchMap` 接收画布/列表呈现与 scene key，在不重挂载的前提下恢复现场。
- 悬浮工具需要自行管理互斥、Esc 优先级、焦点回归、内部滚动和窄屏无横向溢出；自动化覆盖 1440、1024、320px。
- 该变化不修改服务端 API、数据库、共享契约或 Map Scene V2 格式，也不把工具状态升级为业务事实。
