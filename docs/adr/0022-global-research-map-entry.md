# 全局研究图谱使用稳定入口与可替换实现

Collector 的研究地图当前是会话页内的上下文覆盖层，入口需要当前会话与当前节点。节点系统后续将独立探索全局图谱、搜索与新的专注模式，但左侧导航入口不应随节点模型或画布实现反复重写。

**决策：**

- `/map` 是全局研究图谱的稳定产品入口；左侧常驻导航在展开态与收起 rail 都使用普通链接进入该地址。
- 入口只知道 `/map`，不接收或推导 `sessionId`、`nodeId`、关系类型、专注深度和布局状态，也不直接调用当前 `ResearchMapModule`。
- 当前 `/map` 使用可删除的迁移期承接页：如实说明完整图谱正在独立迭代，并列出活动且未进入回收站的会话，用户可进入根节点继续使用现有会话内研究地图。
- 当前会话页顶栏地图按钮与 `t` / `g` 快捷键在迁移期保留；未来节点系统可以整体替换 `/map` 页面，并另行决定上下文入口如何迁移。
- 本决策不确定全局图谱的数据范围、节点模型、搜索语义、专注规则、布局算法或稳定节点短地址。

**Why：** 稳定地址是浏览器原生、可测试且足够小的接口。它把长期保留的导航资产与高概率变化的节点和画布实现分开；未来升级只替换 `/map` 后面的实现。事件总线、全局 Provider 或携带当前地图参数的按钮会把入口重新绑定到现状，增加没有第二个适配器支撑的间接层。

**Considered Options：** 把现有会话内地图直接扩展为全局模式——拒绝，因为当前投影、焦点和布局都以单会话为前提；先放置无响应按钮——拒绝，形成僵尸入口；默认跳进最近会话地图——拒绝，目标隐式且不可预测；为未来预设事件/Provider 接口——拒绝，目前只有一个真实实现，稳定路由已经满足替换需求。

**Consequences：** 导航按钮、激活态、响应式和可访问性测试可以跨节点系统迭代保留；迁移期承接页明确是可替换实现，不作为全局图谱已实现的证据。若未来需要从上下文直达某节点，可在独立决策中为 `/map` 增加可分享的焦点状态，不修改全局入口本身。
