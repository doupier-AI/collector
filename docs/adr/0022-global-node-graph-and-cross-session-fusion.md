# 研究地图全局模式与跨会话融合边界

Collector 的现有研究地图、候选扫描和融合归属仍以当前会话为主要边界，这与“让过去知识和当前学习发生联系”的产品目标冲突。本决策固定节点系统中不应随布局变化的语义边界：会话负责管理，研究节点负责关系，知识发现跨越会话，融合结果拥有独立生命周期。

## 决策

- **会话与项目不是知识边界。** 会话是从根研究节点开始的管理与生命周期容器，一个会话可以包含用户显式生长出的多个研究节点；项目只负责整理和筛选会话。研究节点是可容纳多轮对话和话题漂移的稳定关系对象；语义关联、关联提示和融合可以跨会话、跨项目发生。移动会话所属项目不改写既有关系。
- **全局模式包含全部未进入回收站的现存研究节点。** 归档节点以及没有生长出子节点的根节点仍属于研究地图的全局数据范围和全局搜索。归档节点与永久关系默认保留但弱化，选中后恢复正常可读强度并明确标识状态；用户可以组合筛选活跃与已归档。显式生长仍是创建父子关系的唯一方式，但不再是进入全局模式的资格门槛。是否同时渲染、如何聚类和抽稀属于可替换呈现。
- **研究地图是一套统一观察系统。** 全局、专注、搜索和筛选以观察中心、观察范围、关系类型、连通脉络和状态叠加的不同组合读取同一套节点与关系事实，不各自维护独立图谱。专注模式是一套稳定观察规则，不是另一套数据或画布。统一观察查询共同产生节点与连线结果，具体呈现不得各自重新解释范围和关系。
- **筛选不截断关系事实或连通路径。** 当前筛选范围内的节点构成主视图，跨到范围外的永久关系以边界提示保留；选中节点后的完整连通脉络可以经过一个或多个范围外桥接节点，再连接到范围内节点。桥接节点继续显示但保持弱化并标明范围归属，不取消筛选。选中融合节点时必须展开全部直接来源，即使部分来源位于筛选范围外。
- **选中节点观察完整连通脉络。** 产品不提供关系层数或距离设置。选中节点后，沿所选永久关系类型能够到达的全部节点都属于当前连通脉络；多种已选类型可以共同组成混合路径。父子关系与融合来源保留单向语义，但连通判断允许从关系两端进入，方向解释关系而不限制浏览。当前节点最突出，连通脉络保持可读，未连通区域和未命中的永久关系只弱化而不隐藏。若规模测量证明需要分批加载、聚合或裁剪，这些内部策略不得缩小或改写连通脉络的产品语义。
- **节点、实体、范围与卡片各自承担一种尺度。** 研究节点保留多轮思路与生长身份，语义实体固定概念身份，语义范围定位搜索命中与融合证据，语义卡片只负责可替换呈现。卡片边界不得反向决定节点、实体、搜索或融合边界。
- **专注模式是稳定查询，不是布局名称。** 焦点节点及其完整后代生长树是主体，祖先路径只说明来路，语义与融合邻居按需展开。焦点为融合节点时，其直接来源默认出现在独立来源层，不并入生长树；完整来源链可递归展开。
- **搜索保持节点粒度。** 搜索跨越全部会话，结果以研究节点归并；命中的语义范围只用于解释匹配、预览和精确定位，不成为独立图谱节点。当前图谱筛选范围构成搜索的主要结果范围，范围内结果正常突出；范围外结果仍可返回，但必须分组或弱化，不能与范围内结果混为同等优先级。
- **节点具有稳定内部定位。** 节点正文使用 `/nodes/:nodeId`，全局图谱使用 `/map`，以节点专注使用 `/map/focus/:nodeId`；三者分别表达阅读、全局观察和专注观察，不依赖会话、项目、布局、坐标或缩放。图谱负责观察，节点页负责完整阅读与对话，不长期并排显示。由图谱打开节点时，返回操作恢复当前标签页中的节点位置、视口、观察条件和临时路径；这些临时现场不构成节点身份或长期知识事实。该定位只服务 Collector 内部导航与恢复，不引入对外分享能力。
- **系统主动生成的关系首先是候选。** 未经用户保留的关联提示不属于永久图谱；用户明确保留后才形成语义关联。全局图默认不绘制候选节点与连线，只提示数量；用户主动开启候选观察后才强调候选，永久关系保留但弱化，每条候选明确显示未确认状态及理由、保留和忽略入口。现有“自动融合”开关改为“自动准备融合草案”：开启后 AI 可以主动发现机会并生成完整待审查草案，但草案不进入永久图谱。只有用户确认具体草案版本后，才创建永久融合节点和融合来源边；产品不提供自动创建永久融合节点的预授权模式。
- **保留关联不得丢失其具体含义。** 关联提示绑定当前与历史内容中实际相关的语义范围并解释“为什么有关”；用户保留后，永久语义关联继续保存该说明和两端语义范围，不能退化成只有两个节点地址的空连线。图谱仍以节点级连线呈现，具体理由与来源返回按需展开，语义范围不成为独立图谱节点。
- **明确忽略会抑制同一候选。** 用户没有点击或暂时离开只表示尚未处理；用户明确忽略后，同一关联候选不按固定冷却时间自动复活。只有新的实质证据使关联理由发生明显变化时，系统才能把它作为新候选重新提示。
- **关联候选层是动态候选池，不是永久待办箱。** 未处理的关联提示可以继续参与排序，但不会永久积压；来源内容变化、来源删除、证据失效、价值跌破门槛或更高价值候选替代时可以自动过期。用户只有明确选择“保留关联”，才把候选转为永久语义关联。
- **即时关联提示保持低频。** 当前回答完成且内容稳定后，系统才评估关联；当前学习过程一次最多突出一条最有价值、具有可回溯理由的候选，其余有效发现留在关联候选层。排序优先考虑候选能否补充、纠正、对比或扩展当前认识，而不是只按字面或语义相似度排列。
- **融合围绕一条新综合，而不是固定节点对。** 一项融合可以使用两个或更多来源；同一来源集合可以产生多条不同融合提议。没有新增综合价值时只保留语义关联。
- **融合草案就是待确认的融合节点内容。** 草案必须在确认前展示核心认识、来源、差异或冲突以及判断与证据的对应关系，不是只供预览的摘要。确认绑定一个已核验的具体草案版本，只把它从候选状态提升为永久融合节点；不得在确认时重新生成、自动扩写或改变侧重点，融合节点的初始内容与被确认版本一致。
- **草案修改通过对话产生版本。** 用户可以框选草案范围给出定向修改意见，也可以在普通对话框中给出整体验证或修改意见；只有明确修改意图才产生新版本，询问、讨论和意图不明的消息不修改草案。旧版本保留轻量比较与撤销能力。纯表达修改沿用核验结果；改变核心判断、来源或证据时，只重新核验受影响判断，核验完成前不得确认。
- **确认后的融合内容仍可版本化维护。** 最初确认版本永久保留，后续普通追问和生长不自动改写融合内容；用户通过明确修改意图产生修订版本，表达性修改沿用原核验，核心判断、来源或证据变化只重新核验受影响内容。用户确认后将修订设为当前版本，旧版本仍可查看、比较和恢复；修订不更换融合节点身份，也不重置其对话、生长树或未受影响来源关系。
- **融合节点是独立会话根节点。** 它不归属于任一来源会话，也不是任一来源的父子后代。直接来源通过“来源节点 → 融合节点”的融合来源边表达；融合节点拥有自己的多轮对话、生长树和生命周期。全部直接来源属于同一项目时，融合会话默认沿用该项目；来源跨项目时默认未分类。用户在确认时可以修改项目，之后移动融合会话也不改变来源边与证据关系。
- **融合不会替来源推导普通语义关联。** 确认融合只创建全部直接来源指向融合节点的融合来源边；多个来源参与同一次融合，不代表它们彼此之间已经形成一条适用于整个节点的语义关联。只有来源之间本身存在值得保留的语义联系，并经用户单独确认时，才创建普通语义关联边。
- **来源分为直接来源与来源链。** 图谱默认只直连本次实际使用的直接来源；更早来源通过递归展开来源链查看，不把所有祖先扁平直连到最终融合节点。
- **来源可见性是产品语义。** 全局模式必须让融合节点、直接来源和融合来源边可识别，不能把融合来源降级成普通语义关联。研究地图展示来源节点，融合内容中的具体判断再通过一个或多个语义范围返回证据。
- **删除来源不静默删除融合成果。** 来源会话进入回收站后，来源节点退出普通全局图与搜索，独立融合节点继续存在，来源位置显示“来源在回收站”，受影响判断标为可恢复的来源暂不可用；恢复会话后，原有来源边和证据引用自动恢复。来源被永久删除后，其原文和标题不保留，来源链改为不含原文的“来源已删除”标记，受影响判断改为来源不完整。永久删除确认默认只删除当前来源，列出直接受影响的融合节点并提示更深影响数量；产品不提供一键删除全部派生成果。用户只有进入独立审查、明确选择具体融合节点后才能继续清除，并必须同时看到删除该融合会话会影响其自身后代。
- **稳定语义与视觉呈现分离。** 节点身份、全局范围、搜索归并、专注查询、关系类型、来源链和证据状态属于稳定契约；布局算法、聚类、节点形状、视觉编码、动画和具体控件可以替换。

## Why

把节点拆到消息或卡片级会制造视觉碎片；要求节点概念纯净又无法抵抗真实对话中的话题漂移。相反，稳定的多轮对话级研究节点配合语义实体与语义范围，可以同时保留用户思路和概念级精度。跨会话候选让旧知识主动重现，用户确认再写入永久关系层则避免大图被模型推测污染。把草案本身作为待晋升内容，避免用户确认的是摘要、系统落盘的却是重新生成的另一份正文；对话式版本修改同时保留自然交互、可撤销性和证据有效性。独立融合节点和分层来源链既保留综合结果，也不抹掉形成它的推理顺序。

## 与既有 ADR 的关系

- 本 ADR 保留 ADR-0002 的统一对话空间和“显式生长才创建父子结构”，但取代其中“只有显式生长出结构的对话才进入研究地图”的范围限制。
- 本 ADR 重申 ADR-0003 的节点粒度、话题漂移容忍与语义范围定位，并补充会话不构成跨节点知识边界。
- 本 ADR 扩展 ADR-0005 / ADR-0013 的增量融合与来源回溯模型，明确多来源提议、独立会话归属、直接来源与来源链；确认融合只写入融合来源边，不替来源节点推导普通语义关联。
- 本 ADR 取代 ADR-0015 中会因来源会话归属而连锁删除独立融合成果的产品语义；当前删除实现仍需迁移。
- ADR-0014 继续记录现有默认关闭、可直接创建永久节点的自动融合实现，供迁移前核对；本 ADR 取代其目标产品语义，把开关改为只自动准备融合草案，不再授予自动创建永久节点的权限。

## Consequences

当前会话内图投影、同会话候选扫描、节点对唯一提议、来源会话归属、级联删除和会话依赖节点地址都不能直接支撑该模型。后续实施必须把全局查询、领域契约和持久化、融合任务与生命周期、WebUI 布局分层处理；仅替换画布不会完成本决策。完整范围、当前差距、用户场景和待确认事项见 `docs/NODE_SYSTEM_ITERATION.md`。
