# 全色板对齐产品取色板：底座暖化、主色回规格原值、深色整站统一（深色浅色阅读面 supersede）

2026-08-09（#53 后续深化，无独立票）。ADR-0018 只把品牌**强调色**收敛为暖橙，未动底座与深色外壳。用户随后提供两套完整的浅色/深色元素色号图，约定「**以后产品的颜色取色都从这里拿**」——这套色板登记为 `CONTEXT.md`「产品取色板」词条，成为全产品唯一取色源。本轮把 `tokens.css` **全套对齐**到该色板。

**决策：**

- **确立产品取色板为唯一取色源**：`CONTEXT.md` 新增「产品取色板」词条，登记浅色/深色两套共 20 个语义角色（Background/Card/Popover/Primary/Secondary/Accent/Muted/Destructive/Border/Input/Ring/Chart 1–5/Sidebar 系列）的色值。任何界面元素取色一律从板取、取色即取令牌（`tokens.css`），不另起新色、不散落硬编码；新增语义角色先登记词条再落令牌。
- **浅色底座对齐色板**：`--color-canvas` `#F5F6F3`→`#faf9f5`（Background）、`--color-surface` `#FCFCFA`→`#f5f4ef`（Card）、`--color-surface-raised` 保持 `#ffffff`（Popover）、`--color-surface-hover`→`#ede9de`（Muted）、`--color-line` `#D8DDD5`→`#dad9d4`（Border）。
- **品牌主色回到规格/色板原值**：浅色 `--color-ai` `#C4532F`→`#c96442`（撤销 ADR-0018 的对比度压深，取色板 Primary 原值）、hover `#A8431F`→`#b05730`（取色板 Chart1 暖橙族）；深色 `--color-ai` `#EB9464`→`#d97757`、hover `#F2AB84`→`#b05730`（深色 hover 取色板 Chart1——深色背景下亮主色 `#d97757` 上叠更深的暖橙 `#b05730` 形成可感反差，与浅色 hover 同源同值）。已知 `#c96442` 在浅底座（`#faf9f5`/`#f5f4ef`）上对比度约 3.5–3.7:1，低于 WCAG AA 普通文本 4.5:1——用户以取色板为准选定，记录为披露的取舍（大色块/图标/按钮不受影响）。
- **深色外壳暖化 + 整站统一深色**：`--color-canvas` `#0E0F0E`→`#262624`、surface `#161816`→`#2c2c2b`、surface-raised `#1D201D`→`#30302e`、surface-hover `#232723`→`#3e3e38`、line `#2A2E2A`→`#3e3e38`（冷绿黑→暖棕黑，对齐色板深色底座）。**正文阅读区整站深色化**：深色下 `--color-reading-*` 由浅色阅读面改为深色 Card 底 `#2c2c2b`、浅文字 `#F0F0EC`、链接 `#d97757`，`color-scheme: dark`，卡片 hover 用深色 hover——**supersede ADR-0016/0017「深色主题正文阅读区保持浅色阅读面」**（用户全套对齐决策，追求整站统一深色氛围）。
- **破坏性色对齐**：深色 `--color-danger` `#C25E55`→`#ef4444`（色板深色 Destructive）；浅色 `#A33B36` 保持（色板浅色 Destructive `#141413` 语义上是墨色，非警戒红，本项目破坏性用红色族谱，留待产品确认是否调整）。
- **不动**：选区/标记徽标沿用暖橙协调族谱（`#F6D9BC`/`#7A4530` 等，非色板独立角色）；`--color-difficulty-*` 难度色、`--color-edge-*` 网状图边色为独立语义，不在色板内；`--color-on-ai` 保持 `#FFFFFF`。

**supersedes：** ①ADR-0016 与 ADR-0017 的「深色主题正文阅读区保持浅色阅读面」条目（整站深色化取代）；②ADR-0018 中浅色主色 `#C4532F`、深色 `#EB9464` 等具体色值（由色板原值取代），ADR-0018 的"暖橙取代信号绿"方向与令牌层单点落地方式继续有效。色板语义角色见 `CONTEXT.md`，运行事实以 `tokens.css` 为准。

**Why:** ①用户以两张完整色号图明确「以后取色都从这里拿」，色板取代零散的逐次决策，杜绝颜色漂移与被强加的非用户选择色；②深色"黑底没变"是上一轮只改强调色、没暖化底座的直接后果，全套对齐治本；③整站统一深色是用户对深色模式的明确意图（选「整站深色」），浅色阅读面是上一阶段为长文阅读定的保护设计，用户现以统一氛围优先。

**Consequences:** 全站底座、品牌、边框、深色外壳与深色阅读面全部对齐取色板。受影响像素基线 8 张全变（底座全改），按 ADR-0012 `--update-snapshots all` 强制重拍并逐张人工审 diff（深色整站统一、浅色米白卡片、暖橙强调均确认；深色基线顶部白色长条为动态时间戳 mask 产物、非真实元素）。`docs/PROJECT.md` 四态能力表「统一视觉系统」证据、`apps/web/IMPLEMENTATION.md` §4.3/§11、`CONTEXT.md` 同步。浅色主色对比度披露的取舍、难度色/边色独立语义保持不变。
