# 本地运行与控制

## 产品结果

用户可以安全启动或复用本机 Collector，配置模型和联网能力，查看脱敏运行记录，并在刷新、重启或任务失败后恢复已经保存的工作。

## 主责概念与动作

- **本地启动与实例控制**：loopback 服务、动态端口、实例复用、版本核对和受控关闭。
- **本机认证**：启动器配对、会话 Cookie 和接口访问边界。
- **模型供应商与用途路由**：模型档案、凭证、能力发现、连接测试和按用途选择。
- **任务调度与恢复**：稳定任务身份、取消、重试、幂等和重启恢复。
- **持久化与数据控制**：SQLite、本地文件、迁移、数据目录独占和删除事务。
- **本地运行记录**：模型、搜索、耗时、用量、重试、错误和脱敏导出。

## 运行契约

- 服务只监听 `127.0.0.1`，启动器选择端口并完成首次浏览器配对；一次性入口和令牌不进入 URL 或浏览器持久化。
- 同一数据目录同一时刻只有一个服务进程拥有写权限。无法验证旧实例身份或安全退出时，不并行启动第二个服务。
- 构建与实例匹配时复用服务；需要替换且旧实例支持受控关闭时先自然关闭，再启动当前版本。
- WebUI 只经统一 HTTP 和渐进事件客户端访问业务能力，不直接读取 SQLite、文件或凭证。
- 用户输入和稳定身份先持久化，再启动后台任务。重复请求、取消、重试、恢复和服务重启不得复制节点、消息、版本或关系。
- 数据库记录、文件资源和派生索引通过稳定 ID 关联；高影响删除在明确领域事务中执行。

## 模型与观测契约

- 用户可以保存多个供应商档案、测试连接、发现模型并按任务用途选择；供应商适配不改变产品权限、证据权威或上下文范围。
- 本地语义模型由用户明确安装和移除，不因启动或首次搜索自动下载。模型资产使用固定版本、大小与校验清单；下载代理只影响模型资产网络出口，不扩张其他联网权限。
- API Key 留在专用凭证边界。界面、普通业务数据和运行记录只显示配置状态或经过遮盖的标识。
- 运行记录可以关联界面动作、任务、模型调用和联网搜索，并保存脱敏提示摘要、响应元数据、工具、耗时、用量、费用、重试和错误。
- API Key、认证头、Cookie、会话令牌、启动控制凭据和供应商错误中可能回显的私密输入不得进入普通日志、导出或 Agent 回传。
- 运行记录是诊断能力，不是产品进度、事实证据或用户记忆。

## 数据与兼容

- 当前处于开发数据期，研究内容和派生索引可以清理并重建，不为旧开发数据增加兼容分支。
- 清理开发研究数据时必须保留供应商配置、API Key、模型路由和用户设置；只有用户明确授权才删除这些配置。
- 迁移必须可从受支持的历史 schema 顺序重放；索引和缓存失败不能损坏正文与稳定业务对象。
- 本地数据、日志、构建、测试结果和缓存不进入 Git。

## 不负责

- 不决定研究节点、正文、知识关系、来源或用户适应的产品含义。
- 不把运行记录自动写入长期记忆、画像、RAG 或研究地图。
- 不允许浏览器、供应商适配器或模型绕过领域服务直接修改业务数据。

## 跨模块交接

- 为其余模块提供认证、持久化、模型调用、任务与可观测基础设施。
- 删除和恢复动作由拥有产品语义的模块提出，本模块保证事务、安全和数据一致性。
