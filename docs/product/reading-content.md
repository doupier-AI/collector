# 阅读与内容操作

## 产品结果

用户可以连续阅读 AI 回答和导入材料，选择具体文字进行引用、追问、深入研究或标记，并从任何引用或标记准确返回原内容。

## 主责概念与动作

- **正文呈现**：把一条 AI 回答或一份导入材料作为连续可读内容展示。
- **导入材料与内容快照**：保存用户导入的原文件、可读正文和稳定版本。
- **完整 Markdown 与章节**：从同一正文解析阅读结构和导航。
- **稳定位置与语义范围**：支撑选择、引用、搜索、章节和来源返回的派生位置。
- **选区动作**：引用、在此追问、深入研究、标记与笔记。
- **来源返回**：回到原内容和可达到的最精确位置。

## 内容契约

- 正文是唯一可读事实源。轮次卡片、章节、语义范围、切片、搜索单元和高亮只是呈现或派生位置，不形成正文副本。
- 一条 AI 回答或一份导入材料始终是一份完整内容；普通回答连续呈现，长文可以按真实 Markdown 标题或旁路章节标签导航。
- 完整 Markdown 从同一文档语法与源码位置派生标题、列表、表格、代码、公式和稳定范围。解析失败时保留可读源文本，不吞正文。
- 一条 AI 回答或一份导入材料对应一张轮次卡片，卡片不是内容边界。多轮内容可以用轮次导航定位；长文可以同时使用章节导航，二者在窄屏收敛但不改变正文结构。
- Markdown 代码不执行；不开放 raw HTML、MDX、脚本、iframe、主动嵌入、模型 `data:` 图片或可执行 SVG。公式和复杂结构失败时显示可复制的源文本。
- 卡片边界不等于语义范围；检索和引用可以按需要使用更小的稳定范围。
- 派生数据绑定内容版本。版本不匹配、内容变化或定位失败时，必须降级到粗粒度位置和保存的原文说明，不能猜测错误位置。

## 导入与阅读

- 当前输入范围是 TXT、Markdown、DOCX 和文本型 PDF，单文件上限 20 MiB。
- 本地解析先提供可读正文；AI 章节解析是可选增强，失败或无模型时退化为原文结构或规则锚点，不阻塞阅读。
- 扫描 PDF、OCR、图片理解、HTML、PPTX、XLSX、音视频和网页摄取不属于当前输入范围；新增格式必须单独确认产品与资源边界。
- 导入材料删除时清理其派生内容和资源；不得为定位或检索暗存第二份可写正文。

## 选区与返回

- 用户选中文字后出现轻量操作入口。只有明确点击“引用”才进入输入框引用态；手动选择本身不自动创建引用或 AI 任务。
- “在此追问”留在当前节点；“深入研究”把选区和来源位置保存后创建子节点。
- “标记”立即保存选区，可选择附加笔记，不依赖模型；标记可以查看、编辑、删除并返回来源。
- 来源返回是只读定位，不创建选区记录、不自动进入引用态，也不重开选区操作入口。
- 精确定位成功时，高亮持续到用户下一次有效框选；新框选解除旧高亮并正常显示选区操作。定位失败说明原因并保留可打开的粗粒度来源。

## 不负责

- 不决定 AI 最终回答、上下文预算或旁路生成策略。
- 不拥有来源身份、引用健康、联网、RAG 索引或证据选择。
- 不拥有图谱关系、关联提示或融合状态。
- 不把导入材料自动写入用户画像、长期记忆或已掌握知识点。

## 跨模块交接

- 从研究工作空间取得稳定节点、消息和导入容器。
- 向来源与证据提供内容版本和可达到的稳定位置；来源与证据负责出处与健康。
- 选区生长请求交给研究工作空间创建节点，生成内容交给 AI 回答与生成。
- 向研究地图与知识关系提供稳定节点内位置，不提供正文副本。
