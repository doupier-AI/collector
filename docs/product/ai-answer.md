# AI 回答与生成

## 产品结果

用户从问题获得符合当前任务、逐步可读、可以暂停和恢复、来源诚实的回答。模型、搜索、工具和个性化可以协作，但不会把工作过程、推理记录或控制协议混入正文。

## 主责概念与动作

- **任务理解与回答计划**：根据当前问题、用户明确要求、可用上下文和能力授权形成派生计划，决定回答需要完成的内容操作、组织方式、证据需要和完成条件。
- **最终写作**：唯一有权生成用户正文的阶段。
- **生成任务**：普通回答、长文、深入研究和其他形成正文的可恢复任务。
- **生成控制**：暂停、继续、停止、重试、重新生成和消息版本查看。
- **统一上下文装配**：按任务决定候选的准入、作用域、冲突、预算、脱敏和供应商转换。
- **旁路增强**：引用、弱标记和章节候选等绑定正文版本与稳定范围的派生信息。
- **推理呈现**：供应商通过独立 reasoning 通道明确返回的思考过程可以流式展示并本地保存；未返回时只显示运行状态。

## 正文与生成契约

- 正文是一份自然、连续的 Markdown 字符串，是唯一可阅读、复制和普通导出的回答事实。
- 回答的组织方式、长度、标题、列表、表格和论述深度服从当前任务与用户明确要求；产品不把解释、比较、规划、诊断、总结、改写和研究综合统一写成同一种固定文体。
- 已准入的显式格式设置由最终写作落实为正文结构：编号步骤使用阿拉伯数字步骤，项目列表使用 Markdown 项目符号，表格使用 Markdown 表格，连续正文不使用标题、列表或表格；内部格式代码不进入正文。
- 搜索和工具只能产生可追溯证据；需要工具的流程在取证完成后由独立最终写作形成正文。普通非工具回答本身即最终写作。
- 搜索草稿、工具 JSON 和内部控制串不得进入正文、普通消息持久化、搜索、模型上下文或普通导出。供应商独立 reasoning 通道返回的思考过程作为独立记录保存，不属于正文或证据，也不得进入搜索、后续模型上下文或普通导出。
- 只有供应商通过独立通道明确返回的思考过程可以展示；供应商未提供时，界面只显示运行状态，不得由产品或另一个模型猜测、补写或重写来冒充思考过程。
- 深度思考是当前研究节点的输入偏好，首次默认关闭。普通发送按 `chat` 实际路由、深入研究按 `research` 实际路由判断能力；只有已知支持的实际模型可以切换。模型不支持、身份未知或能力读取失败时入口置灰并说明原因。
- 节点保存的是用户偏好，任务保存的是入队时按实际路由校验后的有效值。偏好开启后切到不支持模型不会被清除，只会让实际请求关闭；切回支持模型后自动恢复。任务的回答规划、正文、长文大纲与分节、深入研究和联网后的最终写作沿用该任务有效值；标题、抽取、引用归因、融合等后台任务固定关闭。
- 正文先渐进保存和展示。暂停保留已写内容与断点；继续从断点恢复；停止保留已写内容但不自动重试。
- 回答计划使用跨领域的任务目标、明确约束、必要内容操作、证据需要、不确定性和完成条件表达，不保存领域专属模板，也不要求所有回答具有相同章节。长回答可以据此分段续写；截断检测、继续请求和段落去重必须有界，恢复不得重复正文或无限续写。
- 重新生成保存旧回答版本；重新编辑用户问题会替换对应回答。只读旧版本不能参与新的选区、标记或派生计算。
- 内容质量评分不能阻塞或改写正文。派生增强失败只减少增强，不影响正文可读和恢复。

## 上下文契约

- 每次模型调用声明任务用途，并只接收完成该用途所需的最小信息。
- 回答计划是低于用户本轮明确要求的派生上下文：它不能改写用户目标、补造用户身份、赋予事实权、自动开启联网或覆盖安全规则；规划失败时使用有限回退，不能阻断正常回答。
- 行为规则、事实证据和用户适应是三个独立通道。程序负责权限、优先级、预算、去重和采用理由，供应商适配只转换已选择结果。
- 用户明确设置的回答方式与要求可以作用于全局或项目；本轮明确要求优先于当前项目设置，项目设置优先于全局设置，均不能覆盖产品硬边界、任务硬契约、事实证据和安全规则。
- 项目身份只限定项目级上下文的适用范围。项目材料、节点内容和会话历史仍是保持原归属的事实候选，不因同属项目而自动整包注入，也不升级为用户画像或长期记忆。
- 当前问题、用户明确选择的核心材料和最低回答空间受保护，不能被低权重历史或个性化静默挤出。
- RAG、联网搜索和工具保持独立上游，只在证据候选交接处汇合；不同上游的分数不能直接横向当作事实权威。
- 存在个性化、历史召回、重要降级或冲突时，可以提供克制的本轮上下文类别说明；不得暴露系统提示、隐藏推理或敏感候选内容。
- 所有现行模型用途都必须经过统一装配，不能长期保留绕过入口或双发调用。

## 旁路增强契约

- 引用、弱标记和章节候选只绑定当前生成尝试、正文版本和稳定文字范围。
- 段落闭合后可以逐步产生增强，全文完成后复核；增强不得回写或重排正文。
- 暂停可以保留已验证增强；未完成候选在恢复或重启后重算。旧正文版本不得借用新版本增强。
- 引用旁路取代正文中的来源控制串；弱标记旁路取代正文中的标记控制串；章节旁路允许自然标题或锚定真实段落的标签，不强制固定标题模板。
- 没有可用增强时保持干净正文并如实缺省，不通过兼容双写维持两套协议。

## 弱标记与术语预览

- 弱标记只提示理解当前论述仍需解释的短范围，包括知识概念、命名实体、缩写、符号和技术标识；对象类别不表示每次出现都必须标记。
- 标记以低注意力方式出现。研究深度 0–1 时，每段首次出现且理解当前论述所需的重要对象通常标记 2–4 个，概念密集时可以更多；深度 2–3 时整篇最多标记 4 个关键新对象；深度 4 起停止产生新标记。
- 祖先节点已经充分展开的主题和对象可以在正文中自然提及，但不重复标记或重复解释；只标记当前回答真正新引入的对象。标记只接受与当前正文范围和回答内身份一致的旁路结果，不使用词法补标冒充模型判断。
- 同一研究节点内，只有经过语境核验的同名提及才共享语义实体和一份预览；不同节点各自生成结合本节点上下文的预览，身份不跨回答自动继承。
- 悬停提及时渐进生成简短预览；点击使用用户实际点击的提及位置，并复用该预览作为新子节点的第一条内容。预览失败不影响手动选区和普通生长路径。

## 能力依赖

- 任务自适应回答依赖统一上下文装配保持用户要求、事实证据和用户适应的独立语义；供应商转换不能重新解释这些权限。
- 引用、弱标记、章节和来源图片依赖稳定正文版本与文字范围；增强失败不能回写或阻塞正文。
- 学习适应、可追溯 RAG 和联网证据只提供受控候选，继续复用同一任务理解、上下文准入和最终写作链。
- 丰富 Markdown 呈现和稳定位置依赖同一完整文档解析结果，不建立专供模型或引用使用的第二份正文。

## 不负责

- 不拥有会话、项目、节点生命周期或知识关系。
- 不拥有来源抓取、RAG 解析、索引、召回、重排和来源健康。
- 不拥有用户画像、长期记忆或已掌握知识点的形成与删除。
- 不允许用户覆盖安全、来源诚实和工具协议的原始 system prompt。
- 不在非文本成果拥有独立生成、版本、删除和恢复生命周期前引入统一多模态消息协议。
