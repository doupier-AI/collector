# Collector 产品模块

Collector 是本地优先的 AI 研究与学习工作空间。用户通过统一对话或导入材料形成研究内容，在阅读中追问和显式生长，通过来源与研究地图回到证据、发现联系，并在明确控制下获得适应性的回答。

本目录只保存低频、稳定的产品契约。它不描述代码位置、实现进度、日期、Issue、提交或测试数量。

## 七个产品功能模块

| 模块 | 用户结果 | 唯一主责 |
| --- | --- | --- |
| [研究工作空间](research-workspace.md) | 持续组织一次研究及其生长路径 | 项目、会话、研究节点、消息容器和生命周期 |
| [AI 回答与生成](ai-answer.md) | 从问题获得可读、可控、可恢复的回答 | 最终写作、生成控制、上下文准入与旁路增强 |
| [阅读与内容操作](reading-content.md) | 阅读、选择、引用、标记并准确返回内容 | 正文呈现、导入材料、稳定位置和阅读动作 |
| [研究地图与知识关系](knowledge-map.md) | 观察研究脉络、发现关联并确认融合成果 | 地图观察、永久关系、关联提示和融合生命周期 |
| [来源与证据](evidence.md) | 判断回答依据并返回可达到的原始位置 | 来源身份、引用、搜索/RAG 候选、健康与失效 |
| [学习适应](learning-adaptation.md) | 在用户控制下获得更合适的解释 | 用户画像、长期记忆、已掌握知识点及其生命周期 |
| [本地运行与控制](local-runtime.md) | 安全启动、配置和管理本地 Collector | 启动、认证、凭证、模型路由、任务与运行记录 |

模块按用户结果划分，不等同于代码目录。一个用户路径可以跨模块，但每个产品概念和长期规则只有一个主责模块；其他模块只描述交接，不复制规则。

## 跨模块不变量

- 产品只有统一对话空间，不分“聊天模式”和“研究模式”，也不扩张为通用 Agent。
- 会话和项目是组织容器，不是知识关系边界；普通追问留在当前节点，只有用户显式生长才创建子节点。
- 正文是唯一可阅读、复制和普通导出的内容事实源。工具过程、搜索草稿、原始推理和控制标记不属于正文。
- 正文版本、语义范围、切片、章节、搜索索引、引用位置和地图投影均为派生或稳定定位层；失败不能改写或阻塞正文。
- 定位精度下降时如实降级，不伪造精确引用、来源或关系。
- 搜索、RAG 和工具只提供证据候选；AI 回答与生成负责上下文准入和最终写作，供应商适配不能扩大权限。
- 永久知识关系只有父子关系和融合来源。普通关联提示是临时观察，不升级为永久边，也不触发融合。
- 用户画像、长期记忆和已掌握知识点相互独立，只作低权重用户适应，不拥有指令权、不进入研究地图，也不改写证据结论。
- 输入先保存，再启动任务；取消、重试、恢复和重启不得重复产生业务结果。
- 联网、持久删除、记忆形成和敏感信息使用服从明确的程序边界，不能由模型推断用户已经授权。
- 产品契约与当前实现必须分开判断。契约中的目标没有代码和测试证据时，不得宣称已经实现。

## 交接方向

```text
本地运行与控制
        ↓ 提供安全运行、模型和任务能力
研究工作空间 ──→ 阅读与内容操作 ──→ 来源与证据
        │                    │              │
        └──────→ 研究地图与知识关系         │
        │                                   ↓
        └────────────→ AI 回答与生成 ←── 学习适应
                              ↑
                         证据候选交接
```

- 研究工作空间创建并保存内容容器。
- 阅读与内容操作呈现正文、材料和稳定位置。
- 来源与证据发现、保存并交付候选证据，不决定最终答案。
- AI 回答与生成按任务准入证据与用户适应，并且只有最终写作能写正文。
- 研究地图与知识关系引用节点身份和证据位置，不复制正文。
- 学习适应只提供受控的用户信息，不读取或写入 RAG 索引。

未明确确认的设想只保留在当前活动任务中，不能进入模块契约或据此实施。历史讨论、替代方案和已经关闭的任务从 Git 与 GitHub Issues 查询。
