# 来源与证据

## 产品结果

用户能够判断回答依据来自哪里、当前是否可用，并在能力允许时返回原始位置；没有来源、未请求联网、检索失败或定位不精确时，产品如实说明。

## 主责概念与动作

- **来源身份与版本**：网页、导入材料、研究内容及工具结果的可追溯出处。
- **证据候选**：可能与当前任务相关、尚未获得进入模型调用权利的事实材料。
- **引用**：正文实际采用的来源与陈述之间的稳定关联。
- **按需联网**：供应商原生联网和 Agent 搜索循环。
- **可追溯 RAG**：对已获准本地内容进行解析派生、索引、召回、重排和定位。
- **健康与失效**：来源删除、重解析、链接失效、部分抓取和定位降级。
- **来源图片**：来自实际引用证据、带说明与来源入口的派生增强。

## 来源与引用契约

- 搜索、RAG 和工具只产出证据候选，不拥有最终上下文选择或最终写作。
- 候选保留来源身份、内容版本、可达到的位置、完整性、授权范围、健康状态和撤销语义。相关性或排序分数不赋予事实权。
- 回答只显示实际参与陈述的引用；完整搜索与工具轨迹可以在本机脱敏留痕，但不能冒充底部引用列表。
- 无来源、未请求、失败、来源失效或只有粗粒度位置时必须如实呈现，不伪造引用和精确回跳。
- 来源内容变化或删除会使旧引用失效或降级；不得借助缓存暗中保留用户已经永久删除的原文。

## 联网契约

- 联网由用户逐次开启，默认关闭；关闭时不调用供应商原生联网或 Agent 搜索。选区分析始终不联网。
- 供应商原生联网与 Agent 搜索是两条独立路径。原生路径只有明确成功、结构化最终文本和可追溯来源同时成立时，才能交给最终写作；否则诚实失败或切换获准的取证路径。
- 联网结果默认不自动进入 RAG、用户画像、长期记忆或已掌握知识点；只有用户明确保存或导入后，才进入相应本地摄取流程。
- 公网 URL、DNS 和每次重定向都要校验；请求时间、响应字节、抓取深度和文件资源必须有界。

## 可追溯 RAG 契约

- RAG 只处理用户获准且已摄取的本地内容，正文仍是唯一可读事实源；结构化文档元素、块和索引是派生数据。
- RAG 拥有解析派生、索引、召回、重排、权限、来源删除、重建与失效；AI 回答与生成拥有候选采用和预算。
- 索引可以删除和重建，不反向写回正文。解析、嵌入或检索部分失败时，无 RAG 的正常回答仍可用并明确降级。
- 研究地图的语义搜索服务于节点发现，不能冒充回答侧 RAG；二者可以复用技术能力，但保持产品目的和数据契约独立。
- 表格、公式、图片的独立证据身份，以及解析后端和部署形态，需要由当前解析验证任务形成明确证据后再确认；未确认前不得扩张现行输入范围或引入第二套常驻应用栈。

## 来源图片契约

- 只有回答实际引用的联网证据图片，或正式解析能力从用户材料中取得的图片资源，才可作为来源图片。
- 图片绑定正文版本、稳定位置和来源记录，通过同源受控预览呈现；失败只丢失图片增强，文字说明和来源入口仍可用。
- 必须限制 URL、重定向、实际 MIME、下载字节、解码像素和内容策略，并保留可访问说明、作者与许可原文。
- 普通 Markdown 图片、装饰图、模型提供的任意远程链接和 AI 原创图不属于来源图片。

## 不负责

- 不决定最终回答措辞、上下文优先级或个性化使用。
- 不拥有正文、会话、节点或图谱关系。
- 不把来源自动转成长期记忆、画像、掌握成果或永久知识关系。
- 不在缺少正式解析边界前承诺 OCR、扫描件、网页、PPTX、XLSX 或音视频摄取。

## 跨模块交接

- 从阅读与内容操作取得内容版本和稳定位置。
- 向 AI 回答与生成交付结构化候选，不交付最终选择。
- 向研究地图与知识关系提供融合来源和关联范围的可用性，不拥有关系状态。
- 来源删除通知研究工作空间、阅读派生物和知识关系执行各自失效或清理语义。
