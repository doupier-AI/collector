# Collector 项目现状

本文件是 Collector 的唯一现行事实入口。历史决策见 `docs/adr/`，领域术语见 `CONTEXT.md`，代理规则见 `AGENTS.md`，技术边界见 `docs/ARCHITECTURE.md`。节点系统迭代以 `docs/NODE_SYSTEM_ITERATION.md` 为产品专题入口，以 `docs/NODE_SYSTEM_IMPLEMENTATION_PLAN.md` 为分阶段实施入口，现行产品边界由 ADR-0022 至 ADR-0026 固定；这不表示目标功能已经实现。

## 怎么使用本文件

- **想开始实施**：对本项目代理说"读 `docs/PROJECT.md`，开始下一张任务"。它会从"Issue 状态与阻塞"找到当前主线和依赖顺序。
- **想查看进度**：看下方"四态能力表"——`已实现并验证 / 部分实现 / 未实现 / 待产品决定`，或直接问代理"项目现在做到哪了"。
- **想做个模糊的新决定**：先用 `/grill-with-docs` 聊清楚，决策写进 ADR，能力变化回写本文件。
- **怀疑文档与现实不符**：说"对照当前代码，核对一遍 `docs/PROJECT.md` 有没有漂移"。本文件必须与代码保持一致；功能改动或决策作出后，在同一任务内回写本文件或新增 ADR，不允许拖延。

## 产品定义与核心用户路径

Collector 是具备自然普通对话能力的研究与学习工作空间（不是通用 Agent）。用户打开即进入一个统一对话空间；研究节点保留多轮思路，用户的显式生长动作形成父子脉络，全部未进入回收站的现存节点共同构成研究地图的全局数据范围，归档不改变归属。

核心用户路径：

```text
统一对话空间提问/粘贴/导入文档 → 连续正文阅读（流式弱标记随行显示）
→ 悬停弱标记看预览 / 点击生长子节点，或手动选区引用后追问、深入研究、标记笔记
→ 节点保留来源关系 → 研究地图（专注/全局模式）回看学习路径与跨节点关联
→ 多来源节点经核验后融合为独立增量节点
```

多轮对话始终在同一节点；只有显式生长动作（深入研究、选区生长、弱标记生长）才创建子节点。

- 确认式融合（#31）与自动融合（#32）已实现（ADR-0013 / ADR-0014）；现行“保留关系”路径在未融合时仍创建 `semantic-related` 旧实现边。自动融合的边界：自动扫描只在节点页挂载触发（开关在其他标签页变更不实时生效，已打开页不重扫）；自动融合失败（可回溯来源不足等）回退为逐条确认弱提示；低置信（类比/对比）提议始终逐条确认。
- 融合节点无父链（`parentNodeId` 为空，来源关系全由 `fused-from` 边表达）；融合正文为原子生成（流式融合列为后续增强）；来源回读诚实降级（不可回溯来源跳过、不足两个拒绝建节点）。
- 节点系统迭代已完成 T01 至 T06，并先交付 T09 当前字段的现场恢复核心：`/map/focus/:nodeId` 由服务端按启用的父子/融合来源关系返回完整连通分类；未连通节点和边留在原位，关系全关只突出焦点。每个地图 history entry 独立保存关系开关、坐标、缩放和平移，地图到节点正文及节点内连续导航只携带返回标记；刷新、浏览器前进后退和“返回图谱”恢复来源 entry，直接打开节点则安全进入默认图谱专注页。现场只存在浏览器当前历史条目，不进入知识事实、URL、localStorage 或业务库。#68 仍需在 #66 交付后纳入项目、时间与生命周期筛选再完成整票。现有候选扫描仍只看同一会话，融合提议按节点对唯一，融合节点归入某个来源会话，彻底删除来源会话会删除触及其节点的边与提议。后续目标是跨会话搜索与范围筛选、跨范围桥接、跨会话发现、多来源且按“新综合”区分的提议、独立且确认后固定的融合成果，以及来源删除后的证据缺失状态；完整差距、恢复入口和工程验证范围见 `docs/NODE_SYSTEM_ITERATION.md`。
- **待确认（#66 时间与范围筛选）**：现行事实源没有“时间”的产品口径。候选一是按节点创建时间筛选（日期边界按本地日换算为半开区间，结果稳定，推荐）；候选二是按最近活动筛选，但需另行定义节点或会话活动如何推动时间。项目筛选是否允许单独选择“未分类”，以及生命周期最后一项关闭时的行为，也尚未确认；确认前不把预埋 `updatedFrom/updatedTo/includeArchived` 字段当成既定产品语义。
- **待确认（#67 跨会话搜索）**：ADR-0023 要求“记得含义、不记得原词”仍可检索，但尚未确认本票是否必须使用语义向量、向量在本地还是外部生成、不可用时如何降级，以及搜索事实源是否包含标题、用户消息和导入正文。只做关键词 LIKE/FTS 会缩窄已确认的语义目标，静默把全部正文送给远程模型又会扩大隐私与成本边界，因此确认前不实施。
