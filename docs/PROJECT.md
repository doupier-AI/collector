# Collector 项目现状

本文件是 Collector 的唯一现行事实入口。历史决策见 `docs/adr/`，领域术语见 `CONTEXT.md`，代理规则见 `AGENTS.md`，技术边界见 `docs/ARCHITECTURE.md`。

## 怎么使用本文件

- **想开始实施**：对本项目代理说"读 `docs/PROJECT.md`，开始下一张任务"。它会从"唯一活动父 Issue"找到当前主线和依赖顺序。
- **想查看进度**：看下方"四态能力表"——`已实现并验证 / 部分实现 / 未实现 / 待产品决定`，或直接问代理"项目现在做到哪了"。
- **想做个模糊的新决定**：先用 `/grill-with-docs` 聊清楚，决策写进 ADR，能力变化回写本文件。
- **怀疑文档与现实不符**：说"对照当前代码，核对一遍 `docs/PROJECT.md` 有没有漂移"。本文件必须与代码保持一致；功能改动或决策作出后，在同一任务内回写本文件或新增 ADR，不允许拖延。

## 产品定义与核心用户路径

Collector 是具备自然普通对话能力的研究与学习工作空间（不是通用 Agent）。用户打开即进入一个统一对话空间；对话中被显式生长出的结构构成研究地图。

核心用户路径：

```text
统一对话空间提问/粘贴/导入文档 → 连续正文阅读（流式弱标记随行显示）
→ 悬停弱标记看预览 / 点击生长子节点，或手动选区引用后追问、深入研究、标记笔记
→ 节点保留来源关系 → 研究地图（专注/关联模式）回看学习路径与跨节点关联
→ 多来源节点经核验后融合为独立增量节点
```

多轮对话始终在同一节点；只有显式生长动作（深入研究、选区生长、弱标记生长）才创建子节点。

## 当前限制与待产品决定

当前限制：
- 弱标记由后置词法检测产生，可能拆分多词概念；中文多字术语、中英混排误标记待修订。
- 正文唯一事实源迁移已完成（ADR-0008）：模型自由写连续正文，切片由确定性派生 + 小模型事后标注；旧"模型返回 slices[]"契约已彻底移除。切片按节派生：标题块并入随后正文（标题作切片 title），无标题正文一段一切片；切片 content 逐字等于正文。小模型事后抽标题失败时对应卡片只显正文（不消失）；历史 provisional 切片仍不显示卡片（与迁移前一致），重派生另排。
- 长文生成的有界可靠性（#38，ADR-0010）：断流/截断/空节/超时/连接失败均为**确定性可检测失败面**，只做契约安全修复；不引入任何内容质量评分/门槛。重试与续写计数有界（退避最多 3 次、节续写 ≤3 次、空重问 ≤2 次），达到上限后节降级为 `[本节生成失败：<标题>]` 标记入正文，绝不静默丢节；断流续传保留已写部分、从断点继续，修复后的正文派生为新版本（不改动被引用的稳定版本）。
- 确认式/自动融合未实现；融合提议只建语义相关边。
- 专注模式的祖先链以图投影深度为界（`maxDepth=2`，约两级祖先）；整树浏览 UI 已被专注脉络取代。
- 父子筛选被关闭时，「打开父节点」安全出口仍保留显示（读原始投影的父节点，不过滤）——是否改为跟随筛选为待产品决定。
- 真实供应商原生联网验收当前停止。
- 基线迁移期：master 落后，节点分支未合入。
- 文本型 PDF 只提供正文快照与页码锚点，不复原版式。
- 历史遗留（非本次引入）：`tests/sqlite-store.test.ts` 有 5 个迁移测试在干净基线即失败（v28/v30 等回滚重放路径），与本阶段无关，待独立排查。
