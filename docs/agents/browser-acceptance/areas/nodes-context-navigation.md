# 专项：节点生长、上下文与导航

## 范围

覆盖节点创建、多层父子关系、来源线、节点内追问、父链上下文、弱标记生长、节点命名和当前版本的导航形态。

## 重点路径

1. 从根节点创建并列子节点，再从子节点创建孙节点，关系符合实际来源；
2. 子节点返回到直接来源节点，不错误跳回根节点；
3. 在此追问留在当前节点，节点生长产生新结构；
4. 当前版本启用父链上下文时，深层回答理解祖先主题且不过度重复；
5. 当前版本启用弱标记时，标记低打扰、悬停预览只生成一次、点击复用内容创建节点；
6. 当前版本启用 AI 节点名时，导航显示稳定名称，失败时有确定性回退；
7. 使用当前版本实际导航形态完成定位、进入相邻节点和返回当前节点；退役的面包屑、树或网状步骤不得继续沿用。

## 增量选择

只测本版本实际启用的节点能力。父链、弱标记、命名和导航可以分别专项；共享节点关系或迁移变化时增加三层关系与刷新恢复冒烟。

## 共同检查

- 多层、并列、孤立或旧数据节点；
- 键盘导航、屏幕阅读语义和非颜色关系提示；
- 节点数量增加后的可读性、性能与视口；
- 任务失败、重试、刷新和服务重启；
- 来源关系与显示标签不会因模型失败丢失。

## 完成证据

记录受测导航形态、节点关系样本、父链深度、生成／命名状态、键盘路径和关键截图。未来 Issue 中的功能在进入当前版本前不纳入通过结论。
