# 专项：设置、本地观测与数据安全

## 范围

覆盖模型设置之外的配置入口、运行记录查看与导出、清理行为、本地数据边界和敏感信息保护。只测试当前版本已经提供的入口。

## 当前版本边界

模型设置、运行记录查看和当前筛选范围的脱敏 NDJSON 导出均已实现，应按现役步骤复验；这些能力尚没有当前版本的人类拟真稳定证据。清理操作只测试界面当前真实提供的范围，不通过手工删除数据目录代替产品验收。

## 重点路径

1. 模型设置入口可发现，新增 / 编辑 / 启用 / 停用 / 获取模型和任务分配的成功与失败状态清楚，刷新与服务重启后保持；
2. API Key 输入默认暗文，眼睛按钮只改变当前组件显示；列表、普通网络响应、URL、浏览器存储和控制台不出现原始 Key；
3. 从主导航进入运行记录，按界面现有的时间、类型、状态和关联条件筛选模型调用、搜索、耗时、重试与错误；
4. 详情中的模型、任务、切片数量、来源和错误分类对应真实本地记录，敏感字段已经脱敏；
5. 导出只包含当前筛选范围，NDJSON 含格式版本、筛选条件和完整性尾行；空结果不创建文件；
6. 导出文件、页面、网络、控制台和普通日志不出现 API Key、认证头、Cookie、会话令牌、控制令牌或带敏感参数的 URL；
7. 清理研究数据、运行记录或设置时，只使用产品当前提供的入口；范围与不可恢复影响明确，不误删应保留的模型配置。

## 增量选择

设置表单变化只测对应设置及一次消费结果；运行记录查询变化测筛选和详情；脱敏或导出变化必须增加带伪敏感值的安全样本，不重复无关研究流程。

## 共同检查

- 空数据、大量记录、失败记录和损坏数据；
- 分页／游标、加载反馈与窄屏；
- 导出仅在本机发生，不自动上传；
- 清理操作的确认、结果与刷新后状态；
- 安全问题至少提升一个验证级别。

## 完成证据

记录当前版本实际存在的入口、筛选条件、导出文件结构、脱敏断言、清理前后数量和必要截图。任何真实凭证都不得进入证据。
