# 专项：设置、本地观测与数据安全

## 范围

覆盖模型设置之外的配置入口、运行记录查看与导出、清理行为、本地数据边界和敏感信息保护。只测试当前版本已经提供的入口。

## 当前版本边界

运行记录查看器和脱敏导出尚未实现时，不在界面中寻找占位入口，也不把缺失当作当前版本缺陷；对应能力合入后更新本专项的现役步骤。

## 重点路径

1. 当前设置入口可发现，保存成功与失败状态清楚，刷新后保持；
2. 当前版本提供运行记录时，按时间、类型和状态查看模型调用、搜索、耗时与错误；
3. 详情中的模型、任务和来源关系对应真实本地记录；
4. 当前版本提供导出时，只导出用户选择的范围，文件包含版本和生成时间；
5. 清理研究数据、运行记录或设置时，范围与不可恢复影响明确，不误删应保留配置；
6. 页面、网络、控制台、导出文件和普通日志不出现 API Key、认证头、Cookie、会话令牌或控制令牌。

## 增量选择

设置表单变化只测对应设置及一次消费结果；运行记录查询变化测筛选和详情；脱敏或导出变化必须增加带伪敏感值的安全样本，不重复无关研究流程。

## 共同检查

- 空数据、大量记录、失败记录和损坏数据；
- 分页／游标、加载反馈与窄屏；
- 导出仅在本机发生，不自动上传；
- 清理操作的确认、结果与刷新后状态；
- 安全问题至少提升一个验证级别。

## 完成证据

记录当前版本实际存在的入口、筛选条件、导出文件结构、脱敏断言、清理前后数量和必要截图。任何真实凭证都不得进入证据。
