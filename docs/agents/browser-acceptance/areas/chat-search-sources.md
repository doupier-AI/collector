# 专项：Chat、联网搜索与来源引用

## 范围

覆盖开始页提问、节点内追问、流式回答、刷新恢复、失败重试、联网请求、来源引用和外链预览。

## 当前版本边界

开始页、节点页和阅读页的主动提问都提供逐次联网开关，默认关闭。关闭时不得执行供应商原生联网或 Collector Agent 搜索；开启时才允许当前模型与搜索配置执行联网。每次提交独立保存本次选择，不从上一轮隐式继承；选区分析始终不联网。当前已配置供应商不支持原生联网，真实供应商原生联网验收保持停止，不能把确定性假来源写成真实联网证据。

## 重点路径

1. 从开始页提交问题，确认用户输入先保存、AI 状态持续可见、完成后内容稳定；
2. 在节点页和阅读页分别提交一次追问，确认逐次开关可发现且每轮选择独立；
3. 关闭联网后提交，网络面板中不出现供应商原生联网或 Agent 搜索请求，运行记录明确为“未请求联网”；
4. 开启联网后提交，只允许当前配置支持的路径运行；不支持、失败或没有可核验来源时诚实降级；
5. 生成中刷新、离开后返回、失败后重试，不重复消息、任务或联网授权；
6. 行内来源角标、来源预览和外链只引用实际取得的来源；
7. 搜索与引用变化时，验证中英查询、单页失败、超时和替代来源不会让整轮界面失去反馈。

## 增量选择

模型流式协议变化时重点测生成与恢复；搜索适配变化时重点测联网状态、来源和错误；Markdown 或引用渲染变化时增加选区偏移跨区冒烟，不重复模型设置全流程。

## 共同检查

- 等待、搜索、降级和完成状态是否清楚；
- 引用编号、陈述和来源详情是否对应；
- 外链使用安全新窗口策略，不携带本地令牌；
- 控制台、网络、重复请求、超时和取消；
- 真实模型轨道才评价事实质量，确定性轨道只评价交互。

## 完成证据

记录使用的轨道、问题样本、联网是否实际请求、来源数量、降级状态、关键截图与网络摘要；不得把模拟来源写成真实搜索证据。
