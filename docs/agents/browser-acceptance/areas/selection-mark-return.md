# 专项：选区、引用、标记与来源返回

## 范围

覆盖节点页和阅读页的文字选区、浮动胶囊、引用态、标记与笔记、右侧标记列表、来源返回、锚点恢复和降级。

## 重点路径

1. 鼠标、触摸或键盘选中有效文字，浮动胶囊定位正确且不遮挡正文；
2. 单字选区有效，跨块或超长选区按当前规则提示；
3. 点击【引用】后聚焦输入框、输入文字和原生选区坍缩都不丢失引用；
4. 在此追问不创建节点，深入研究创建带来源的子节点；
5. 点击【标记】立即保存，笔记输入、自动收起、固定位置和外部点击保存符合当前版本；
6. 标记列表展示原文、笔记、来源与时间，点击后回到正确内容位置；
7. 来源返回的高亮时长、浮动操作和 URL 行为以受测版本当前规格为准；
8. 重复文字、Markdown、行内来源角标、刷新和服务重启下锚点不漂移；无法精确恢复时诚实降级。

## 增量选择

锚点、Markdown、引用角标或公共正文组件变化时，节点页和阅读页必须同时进入范围。只改笔记样式时，不重复完整节点生长，但保留一次保存后返回的最短冒烟。

## 共同检查

- 320px 窄屏钳制、上下翻转、滚动与缩放；
- Tab、Enter、方向键和当前版本定义的 Escape 行为；
- 焦点回归、减弱动效、淡入淡出；
- 重复点击的幂等与无模型路径；
- 页面文字与保存的 exact／prefix／suffix 是否指向同一处。

## 完成证据

每个受测来源类型保留返回前后截图、目标文本、实际 URL、刷新结果和是否精确恢复；降级不能记为精确通过。
