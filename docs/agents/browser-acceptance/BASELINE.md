## 更新规则

每次主动触发的人类拟真测试完成后，只更新实际受测功能区：

- 最后通过日期与提交；
- 版本增量／专项／全量模式；
- 确定性演示或真实模型轨道；
- 覆盖的用户路径和跨区冒烟路径；
- 状态：稳定、需专项复验、部分验证、未验证；
- 未关闭风险和对应 Issue。

没有实际运行的功能区不得因“看起来没问题”升级为稳定。
