# Collector 产品与交付计划

版本：0.3
日期：2026-06-11
状态：可信知识整理闭环实施中

## 1. 产品目标

Collector 用于低摩擦捕捉分散知识，并在保留来源证据的前提下，帮助用户审慎地整理、关联和融合内容。

知识空间不是固定链路：新内容可能相关、补充、支持、冲突、重复或独立。系统不得为了自动整理而强行制造连接。

当前核心闭环：

```text
捕捉 -> 原始内容持久化 -> 廉价预检 -> 来源解析 -> Fragment 引用
-> 知识抽取 -> 历史检索 -> 关系/主题建议 -> 用户审核 -> 正式知识
```

后续闭环：

```text
正式知识 -> 目标与能力建模 -> 学习任务 -> 学习反馈 -> 局部计划调整
```

## 2. 产品原则

1. **来源优先**：原始内容先保存，生成内容必须可回到 Fragment。
2. **事实分层**：来源原文、AI 推断和用户观点分别存储与展示。
3. **建议后确认**：AI 只能创建 ReviewProposal，不能直接修改正式知识。
4. **允许独立**：无可靠关系的内容保留在智能收件箱，不强制归类。
5. **价值门控**：根据用户意图、可解析性、新颖度、引用质量和成本决定 L0-L3。
6. **增量与可撤销**：接受建议后创建版本化记录，撤销不删除历史。
7. **本地优先**：当前面向单用户 Windows 本地部署，云模型调用必须显式授权。
8. **评测先于自治**：没有固定样本与回归结果，不扩大 Agent 权限或来源范围。

## 3. 当前里程碑

本阶段实现：

- Chromium 网页选区与整页正文快照采集；
- Windows 悬浮窗文本、URL 和文件采集；
- SQLite 持久化和旧 JSON 自动迁移；
- 文本、Markdown、文本 PDF 和安全 URL 解析；
- DeepSeek/Fake 模型网关与结构化知识抽取；
- 六类关系与主题建议；
- 用户接受、拒绝、暂缓和撤销；
- Topic 工作台和证据对比；
- 本地配对鉴权、成本与 AgentRun 记录。

本阶段不实现：

- 学习计划；
- 视频、音频和 OCR；
- 自动外部研究；
- 完整阅读器、RSS 或 Newsletter；
- 通用可视化知识图谱；
- 多用户同步与协作。

## 4. 入口要求

### 浏览器扩展

- 选中文字后右键立即采集；
- 保存 URL、标题、上下文、DOM 路径和文本偏移；
- 未选中文字时提交清理后的整页正文快照；
- 网络失败时保留相同 `clientCaptureId` 重试；
- 配对后才能访问本地数据 API。

### Windows 悬浮窗

- 用户主动粘贴，不读取或监听剪贴板；
- 支持文本、URL、TXT、Markdown、PDF 和图片拖放；
- 图片首版只保存 Artifact，不执行 OCR；
- `Esc` 隐藏并保留草稿，成功持久化后才清空；
- Key 和模型调用不进入 Renderer。

## 5. 处理等级

- `L0 Store Only`：只保存原始来源与元数据。
- `L1 Lightweight`：本地解析、checksum、规则和重复检测。
- `L2 Standard`：结构化抽取、历史关联和审核建议。
- `L3 Deep`：冲突分析或复杂跨来源综合，需预算满足或用户授权。

默认策略：网页选区进入 L2；文章和文件先 L1；重复内容停止升级；无字幕转写、视觉理解和外部研究属于 L3。

## 6. 可信知识规则

正式关系类型：

```text
related extends supports contradicts duplicate independent
```

- 语义相似不等于同一概念；
- 每条 AI 主张和关系建议必须引用已有 Fragment ID；
- 非法 JSON、空响应或无效引用不得进入知识层；
- 接受建议创建 `Relation` 和 `UserDecision`；
- 撤销把 Relation 标记为 `revoked`，不删除建议、决策和来源；
- Topic 页面只把已接受且未撤销的关系显示为正式知识。

## 7. 安全与隐私

- 只有健康检查、静态工作台壳和一次性配对交换可以匿名访问；
- 数据 API 需要 Bearer Token 或 HttpOnly 本地会话；
- 配对码五分钟失效、只能使用一次并限制失败尝试；
- Token 只保存 hash；Electron 主 Token 使用 `safeStorage`；
- DeepSeek Key 不进入 SQLite、日志、导出、Renderer、源码或 `.env`；
- 首次 AI 处理前展示云端发送授权，每条 Capture 可禁用 AI；
- URL 解析限制超时、大小和重定向，并在每次跳转后阻止私有地址。

## 8. 分阶段交付

1. **工程基线**：Git、项目 Skill、构建、测试和隔离实例。
2. **存储与安全**：SQLite、JSON 迁移、配对与本地会话。
3. **来源解析**：文本、Markdown、PDF、网页快照和安全 URL。
4. **模型整理**：Fake/DeepSeek、Schema 校验、AgentRun 和成本。
5. **审核知识层**：Relation、UserDecision、撤销和证据约束。
6. **Topic 工作台**：主题、成员、来源和正式知识视图。
7. **验收**：离线回归、真实 GUI/扩展链路、经授权的真实模型调用。

完成以上阶段后，才评估引用问答、视频门控、外部研究和动态学习计划。

## 9. 当前验收标准

- 旧 JSON 完整迁移，失败时原文件不变，成功后生成只读备份；
- 未配对客户端无法读取或写入知识库；
- 文本、网页、Markdown 和文本 PDF 生成稳定 Fragment；
- 禁用 AI 的 Capture 不产生模型请求；
- 模型错误或无引用输出不污染知识层；
- 接受建议创建正式 Relation，撤销后历史仍存在；
- 每次模型处理可查看模型、提示词版本、token、成本、延迟和错误；
- `npm test`、安全测试、迁移测试和隔离 GUI smoke 通过。
