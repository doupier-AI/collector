## 状态说明

- `prepared`：交出方正在准备；
- `pending`：等待接收；
- `accepted`：接收方已经开始工作；
- `superseded`：已由后续交接替代；
- `blocked`：接收方无法继续。

## 维护规则

- 新交接追加一行，不重写历史事实；
- 接收时只更新对应行状态；
- 后续交接生效后，上一份已经完成作用的交接改为 `superseded`；
- 详细命令、文件和问题放入对应交接文件，不扩展本索引；
- 查历史时按编号打开单个文件，不批量阅读全部交接。
