## 6. 已知问题与风险

1. **Playwright WebServer 收尾不退出**：12 个场景全部完成后停在第一套 API 测试进程终止阶段。影响是自动化命令不能给出正常退出码，不影响场景断言。KIMI 3 在 `api-harness.mjs` 处理 SIGTERM/SIGINT，关闭 server/store，并在移除 Vite preview 后复跑确认自然退出。
2. **静态文件当前整文件读入内存**：当前最大 JavaScript 约 264 KiB，风险可接受；未来出现大型前端资源时由 GPT-5.6 改为流式文件响应或增加上限。
3. **正式启动依赖已完成构建**：`npm.cmd start` 不自动构建；缺少 `index.html` 时会明确报错。开发者可使用会先构建的 `npm.cmd run dev:api`，后续启动器负责打包完整产物。
4. **打包目录布局尚未定案**：当前默认目录适合仓库运行，`COLLECTOR_WEB_ROOT` 为打包预留；最终启动器打包时由 GPT-5.6 固化资源位置。
