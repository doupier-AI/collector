## 6. 已知问题与风险

1. **终态确认后消息内容不回填（已修复）**：SSE 全程中断回退轮询时，`GET /v1/research-tasks/:id` 只含任务状态不含消息内容，已显示文字无法补齐。修复：`useResearchSession` 在任务到达终态后重新 `GET` 会话视图对齐（防过期、失败静默保留已显示内容）。建议 GPT-5.6 知悉此交互模式；若后续在任务契约中附最终消息可简化前端。
2. **会话创建无幂等键**（H-001 已列阻塞）：前端经路由 state + 在途 Promise 复用规避，网络结果不确定时不盲目重建；极端断网时序下理论上仍可能产生重复空会话，等待后端幂等契约。
3. **e2e"首次打开空状态"用例依赖执行顺序**（workers=1 + 文件字母序 + 每次运行新数据目录）：顺序变化会使该断言失效；如需彻底解耦，可为该用例准备独立数据目录。
4. **控制台断言范围**：从配对完成后开始收集；配对前的未授权探测 401 会被 Chromium 记为资源加载错误，属预期流程。
5. **错误响应无 `requestId`**：基线 6.5 要求服务错误显示请求 ID（后端提供时）；当前接口未返回，前端文案暂不含请求 ID。
6. **假模型分段延迟**（首段 400ms、段间 250ms）是 e2e 观察窗口，真实模型首片延迟仍等于完整云响应时间（基线 10.10）。
