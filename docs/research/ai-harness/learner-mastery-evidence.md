# 学习者知识建模与费曼式掌握证据

> 对应：[Issue #113：研究学习者知识建模与费曼式掌握证据](https://github.com/doupier-AI/collector/issues/113)
> 状态：研究结论；**不是产品决定，也不代表功能已经实现。**
> 范围：为「AI 回答与学习适应蓝图」提供学习者模型的证据与取舍，不改变现有研究节点、关系或正文事实源。

## 结论先行

Collector 应把“用户已经会了什么”建模为**可质疑、可撤销、带来源和时间的掌握假设**，而不是从一次对话、一次自我声明或模型印象直接写成永久事实。第一阶段不应试图训练一个黑箱“学习者分数”：先收集少量、用户可见且能纠正的学习证据（例如独立作答、解释、迁移题、置信度和时间），再把下一步回答调整为“少重复已证实内容、明确暴露不确定处、给出可选复习/练习”。

这与长期记忆是两条不同的数据线：

| 维度 | 长期记忆 | 知识掌握假设 |
| --- | --- | --- |
| 回答的问题 | “用户希望系统持续记住什么？” | “在特定知识范围内，用户此刻能否独立解释、应用或迁移？” |
| 典型证据 | 用户明确保存的偏好、目标、约束或纠正 | 可定位的作答、解释、迁移表现、置信度、复习后的表现 |
| 写入方式 | 用户主动保存为主；候选需审阅 | 默认只形成待验证假设，不能由闲聊自动升级 |
| 失效方式 | 用户编辑/删除或范围结束 | 新的反证、时间衰减、概念版本变化、用户纠正 |
| 对本轮回答的作用 | 个性化表达与任务约束 | 调整解释深度、复习建议和诊断提问；不能假装已经掌握 |

因此，“费曼学习法”在产品中更适合作为**一种产生可验证学习证据的活动**，不是把“用户能讲一遍”当作掌握的充分判定。自我解释能促进理解，但效果、迁移和信心之间都需用独立任务复核。[Chi 等人的原始研究](https://doi.org/10.1207/s15516709cog1803_3) 发现被提示自我解释的学生相较只重读的对照组获得更大增益；但这不等同于任意一段 AI 对话都能可靠测出学习。

## 证据：可用模型各自能证明什么

### 1. BKT：解释性强的“小步、单技能”掌握假设

Corbett 与 Anderson 的知识追踪工作把每条规则的已学会概率随每次应用机会和表现更新，并用该估计指导补救教学。[原始论文](https://escholarship.org/uc/item/0873k1nz) 的对象是有明确规则和可判对错步骤的编程辅导环境，而不是开放式聊天。

对 Collector 的启示是：如果有**已定义的概念/技能、可评分的练习和连续机会**，可以用“掌握概率 + 证据记录”来表达不确定性；这比一句“用户懂了”更诚实。它也同时划出边界：没有稳定技能定义、没有可验证答案的自由讨论，不应伪装出 BKT 意义上的数值掌握度。

候选的最小记录单位应是“一个证据针对一个明确知识范围”，而非给整个人贴“懂/不懂”的标签：

- `scope`：概念、命题、程序或材料片段的稳定定位；
- `evidence`：题目/解释提示、用户回答、评分依据、发生时间；
- `observation`：正确、部分正确、错误、无法判断，外加置信度（如用户愿意提供）；
- `hypothesis`：当前暂定掌握级别和不确定性，而不是不可解释的总分；
- `provenance`：谁产生、由何种规则或人工/模型评估、能否被用户查看和推翻。

### 2. IRT：把“题目难度”和“个人能力”分开，但依赖测量设计

项目反应理论（IRT）的基本优势是把题目的区分度、难度（及部分模型中的猜测）与学习者能力区分开；知识追踪综述指出，IRT 类模型通常还需要题目—技能映射（Q-matrix）等侧信息。[知识追踪综述的 IRT 章节](https://doi.org/10.1145/3569576) 与 [Lord 三参数逻辑模型的说明](https://www.rasch.org/rmt/rmt181b.htm) 都体现了这一前提。

这意味着 IRT 适合未来有一组反复使用、已校准练习题的学习路径，不适合把每次聊天提问都当成等价测题。对 MVP 的正确借鉴是：**记录题目和材料的难度/形式，也记录评估置信度**，避免把“答对一道提示很强的题”误读为“全面掌握”。是否建立正式 IRT 标定池是后续的独立产品和数据治理决定。

### 3. DKT：预测能力可能更强，但不应作为早期用户可解释事实源

[DKT 原始论文](https://proceedings.neurips.cc/paper_files/paper/2015/hash/bac9162b47c56fc8a4d2a519803d51b3-Abstract.html) 用循环神经网络从交互序列预测后续表现，优点是不要求事先手工编码所有领域结构。代价是状态难以向用户解释；而 [“How deep is knowledge tracing?”](https://arxiv.org/abs/1604.02416) 也显示，扩展后的结构化模型在其比较中可达到与 DKT 难分高下的预测表现。

Collector 早期不应把黑箱隐状态写进用户画像、记忆或回答上下文。未来若为离线评估使用序列模型，仍应把它限制为**排序/复习候选信号**，并保留可检查的证据、校准和用户纠错通道；用户可见层只表述“系统基于哪些练习做出这个暂定判断”。

## “解释得出来”应怎样成为证据

### 自我解释，而不是复述

Chi 等人的研究显示，提示学习者解释文本可提高理解，且高自我解释者更可能形成正确心智模型。[原始研究](https://doi.org/10.1207/s15516709cog1803_3) 还以复杂问题和隐含功能推断衡量理解，说明好的证据不只是关键词复现。

据此，Collector 可以在用户愿意时提供低摩擦的“用自己的话解释”入口，并把下列行为区分记录：

| 证据等级（候选） | 可观察表现 | 对掌握假设的意义 |
| --- | --- | --- |
| 接触 | 阅读、收藏、让 AI 解释 | 只证明接触过；不增加掌握结论 |
| 识别 | 在提示或选项中辨认概念 | 弱证据，易受线索和猜测影响 |
| 回忆 | 不看材料答出关键命题 | 较强，但仅覆盖该命题 |
| 自我解释 | 说明因果、条件、例外和与已知知识的关系 | 可检验理解结构；仍要核实正确性 |
| 应用/迁移 | 在新情境选用并说明规则 | 更强的掌握证据，须与原题不同且有评分依据 |

所谓“费曼式”不应变成让模型代写讲解后再把它归功于用户。合格活动至少要求：用户先独立输出；系统明确指出不确定或错误处；用户可查看判定依据；失败不会被羞辱性标记；用户能拒绝保存该次学习记录。

### 迁移与反例：防止“在原题上答对”的错觉

检索练习通常优于重读，但迁移不是自动发生的。[Endres 与 Renkl 的原始实验](https://doi.org/10.3389/fpsyg.2015.01054) 复现了测试效应，并指出需要投入实质心力；[Pan 与 Rickard 的四项实验](https://pubmed.ncbi.nlm.nih.gov/28358548/) 则发现，相对重读，跨术语—定义方向的正迁移最多很小，重复练习条件更有利。

产品上，这要求“已掌握”至少能被拆成具体声明，例如“能在本材料定义中回忆”与“能在新例子中应用”不可混为一项。系统可以提议一个新情境小题或让用户举反例，但应允许跳过，不能把不答当成不会。

### 置信度不是准确率；两者要同时记录

置信度与正确性的一致程度（calibration）是元认知监控的一个可测维度；[Fleming 与 Lau 的方法论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4097944/) 明确区分了偏差、敏感性和效率，不能只用相关系数或单次自评。纵向研究也发现较好的算术置信度校准与之后的表现增益相关，但这仍是关联和特定任务的证据，[Rinne 与 Mazzocco 的研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4079261/) 不能直接推广为通用人格判断。

可选做法是让用户在练习后以粗粒度选择“很确定 / 不确定 / 猜的”，将其与独立评分分开保存。系统应优先用“你上次对这一类题很有把握，但其中一个关键条件没满足；要不要看反例？”这类可复核表述，而不是暗中判定“过度自信”。

## 时间、遗忘和误解：为什么假设必须会过期

Ebbinghaus 的早期实验将记忆保持作为可测量现象，[原著数字版](https://psychologie.lw.uni-leipzig.de/wundt/opera/ebbing/memory/GdaechtI.htm) 是遗忘研究的重要起点；但其无意义音节、自我实验和特定条件不能被产品简化为对每个用户都适用的固定“遗忘曲线”。后续复现与分析也指出原实验的呈现速度、方程与结果解读存在条件差异。[复现分析](https://pmc.ncbi.nlm.nih.gov/articles/PMC4492928/)

因此：

- 时间经过应降低**置信度或提醒复核**，不是把用户标为“忘了”；
- 有新的独立正确表现，可更新和强化假设；有明确错误、反例或用户纠正，应降级或撤销；
- 材料版本、概念边界改变时，应使旧证据“需复核”，而不是静默复用；
- “误解”是一个针对具体命题的可反驳假设，绝不能成为用户身份标签或用于无关场景。

## 用户纠正与隐私边界

掌握记录会涉及学习轨迹、失误、信心和潜在敏感主题，风险高于普通偏好记忆。NIST Privacy Framework 把控制、沟通、保护与可分离处理列为隐私风险管理的功能，[官方框架](https://www.nist.gov/privacy-framework/privacy-framework) 也明确提到最小化、限制可观察性/可关联性与选择性收集/披露。[Core 参考材料](https://www.nist.gov/system/files/documents/2024/10/29/Day1_PM_combined.pdf)

据此，任何候选实现至少应具备下列产品约束：

1. 默认不从普通闲聊自动永久保存掌握结论；对敏感领域更不自动推断。
2. 每条用户可见的掌握假设显示范围、证据时间、依据和当前不确定性；用户能改正、删除、暂停个性化并要求重新评估。
3. 删除掌握假设时，同时删除其用于后续上下文装配的可检索投影；审计记录应最小化，且不得保留足以绕过删除的正文副本。
4. 不把“未作答”“中断”“不同意被记录”解释成低能力；不将掌握假设用于画像、推荐以外的用途或跨项目扩散。
5. 模型评分是可错的辅助信号：一旦用户纠正，用户的明确纠正优先；系统应标明是否由模型评估，并提供重新检查入口。

这些是候选安全边界，具体本地存储、同步、保留期和法律适用范围仍需后续决策，不能在本研究中默认落地。

## 对 Collector 的分阶段建议（候选）

### 阶段 0：先能“不重复讲”，不宣称诊断

- 用户可手动标记“我已了解 / 想复习 / 这里不确定”，可按项目或话题撤回；
- 回答侧只把它作为低到中等权重上下文，优先问一句简短校验问题或提供“跳过基础 / 先回顾”选择；
- 不创建掌握分数，不自动从聊天吸收，不改变节点语义。

### 阶段 1：显式学习活动产生证据

- 提供自我解释、短回忆题、应用题和反例题等可跳过活动；
- 每条证据绑定知识范围、材料定位、评分依据、时间、用户置信度和可见结论；
- 回答风格据此调节，但永远允许用户说“不要假设我会/不会”。

### 阶段 2：基于证据的复习与迁移建议

- 用低风险、可解释的规则先推荐复核（时间、证据强度、置信度与正确性不一致、概念版本变更）；
- 再评估是否值得为有稳定题库的特定领域引入 BKT/IRT；
- DKT 或其他黑箱模型只在独立评估证明增益、校准与治理可接受后，才讨论是否进入产品。

## 可验证的原型建议

为避免“模型听起来像老师”的假阳性，原型至少应比较：

1. **证据忠实性**：每条掌握假设是否能回跳到具体用户表现；抽样检查是否存在模型编造的证据。
2. **纠错可达性**：用户能否在两个操作内查看、降级、删除或关闭后续使用；删除后下一轮上下文不再引用它。
3. **校准**：按知识范围分别计算预测/自评与后续独立表现的差距；不以总体平均掩盖“高置信错误”。
4. **迁移区分**：原题复现与新情境应用分别报告，避免把提示下识别当成迁移掌握。
5. **时间有效性**：对一段时间未复核的假设，检查系统是否以“不确定/建议复习”而非“已忘记”表述。
6. **公平与敏感性**：比较不同材料语言、题型和用户选择不记录时的行为；审核是否把沉默、网络中断或拒绝采集变成负面结论。

## Issue #117 必须裁决的事项

以下均为待确认决策，不能由本研究自动定案：

1. 掌握假设的最小范围是什么：概念、命题、技能、材料片段，还是允许多者并存？如何稳定定位与版本化？
2. 哪些事件可成为证据？用户手动声明、独立回答、模型判分、外部测验各自默认权重和升级条件是什么？
3. 何时允许从“待审阅候选”升级为“回答可用的掌握假设”？是否需要用户确认或独立复核？
4. 用户纠正、删除、项目归档、时间衰减和材料更新分别如何影响主记录、派生索引与本轮上下文？
5. 是否展示置信度/校准，怎样避免将其做成评判人格或制造压力的分数？
6. 敏感主题、未成年人、健康/职业等高影响学习场景采用什么默认禁区和同意机制？
7. 回答侧在掌握信号与用户当前明确请求冲突时的优先级是什么？“不要预设我会什么”是否是全局即时覆盖？
8. 第一阶段的成功标准是什么：减少重复解释、用户主观控制、答题迁移、校准还是留存？哪些失败会阻止扩大采集？
